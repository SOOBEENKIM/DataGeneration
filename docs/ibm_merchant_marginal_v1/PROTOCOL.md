## 1. 부품 보정 (가맹점 부품의 두 가지; 새 학습 0, 표·가중치는 train만)

- **R1 재방문 강도(`sticky`)**: 반복 가지 p(m) ∝ w_{c(m)} · [λ·빈도(m) + (1−λ)·최근성(m)], c(m) = 가맹점의 업종(train 최빈). w는 업종별 양수 가중치 ~110개로, train 고객(추정용 90%)의 반복 행에서
  빈도 커널의 조건부 로짓 최대우도로 추정(`_RARE_`는 w = 1 고정, 평균 로그 가중치 0으로 정규화). λ는 w를 넣은 뒤 hold-out 10% 로그가능도로 다시 고른다.
  **선택 규칙**: hold-out 반복 행 로그가능도가 기존 커널(−3.055)보다 **.05 nats/행 이상** 좋아질 때만 채택.
- **R2 업종 먼저(`novelcat`)**: 정상 행의 새로움 가지에서 먼저 업종을 train 표 P(업종 | 정상, 처음 방문)로 고르고(과거 마스크 후 backbone 질량이 0인 업종은 제외·재정규화), 그 업종 안에서는
  마스크된 backbone 분포로 가맹점을 고른다. `_RARE_`는 자기 몫 P(`_RARE_` | 정상, 처음 방문)을 갖는 별도 범주. 사기 행의 새로움 가지(사기 풀 혼합)는 그대로.
- 게이트·사기 풀·전이표·간격 표·가맹점 속성 일관성(`attr_all`)은 그대로. 생성 스택 = 현재 모델 + `attr_all` + 보정.

## 2. 가장 가까운 선행

| 요소 | 선행 | 겹침 | 차이 |
|---|---|---|---|
| 항목별 재소비 강도 | Anderson et al. WWW 2014: 재소비 모형에서 최근성 가중과 항목 품질(quality) 항의 결합 | **구조 동일**(최근성/빈도 × 항목 고유 가중) | 우리는 항목이 아니라 업종 수준 가중(110개)으로 줄이고 합성 생성기의 부품으로 씀 |
| 소비열 생성 | Benson et al. WWW 2016 | 반복 소비의 생성 모형 | 라벨 상태·다른 열 결합 없음 |
| 위계적 선택 | 중첩 로짓(McFadden 1978), 위계 softmax | "종류 먼저, 그 안에서 항목" | 표준 기법; 새로움 주장 없음 |
| 이 연구 | ibm_merchant_memory_v1 커널(λ = .75) | 보정 대상 | 업종 무관 커널의 한계를 진단으로 확인 |

**새로움 주장 없음** — 기존 부품의 보정이며, 근거는 진단(업종별 재방문 5–15배 차)이다.

## 3. 가설과 사전 판단 (fit 2 × 생성 2 평균)

- **M1 (구조).** `both`에서 표준 업종 TV 바닥 배 ≤ 3(현재 3.25), 가맹점이 함의하는 업종 TV .178 → ≤ .135(25% 이상 감소), 상위 10개 업종의 (고객, 가맹점)당 방문 수 순위가 실제와
  Spearman ≥ .6(현재 평평).
- **M2 (효용).** `both`의 등록 탐지기 효용 ≥ .425(`attr_all` .455 − .03): 해치지 않을 것. 이득은 요구하지 않는다(+.04 이상이면 기록).
- **M3 (ablation).** `sticky`는 반복 TV를, `novelcat`은 처음 방문 TV를 주로 줄여야 한다.
- **M4 (대조).** 라벨 과정 동일; 가맹점 구조(사기·정상 새 가맹점, 고객당 가맹점 수, 공유 풀)·간격 구조·속성 일관성(정상 일치 ≥ .99) 유지; 모든 표준 지표 ≤ 3배.
- **채택 규칙.** M1·M2·M4를 모두 충족하는 팔이 있으면 그 스택(가맹점 속성 일관성 + 보정)을 모델로 채택한다. ibm_merchant_attr_v1의 공식 판정(보류)은 그 단계 기록으로 남고, 채택은 이 단계의
  판정으로 한다. M1 미달이면 남은 오차의 위치(처음 방문/반복/희귀)를 기록하고 채택 보류를 유지한다.

## 수정안 1 — R1 비채택, R2에 위치 구간 추가 (2026-11-10, 추정 결과 후·생성 전)

- **R1(`sticky`) 비채택 — 등록 선택 규칙.** 업종 가중 w를 넣은 커널의 hold-out 반복 행(99,963행) 로그가능도 −3.019, 기존 커널 −3.029(코드 공간, λ = .75 동일) → 이득 **+.011 nats < .05**.
  추정된 가중도 약하다(통행료·송금·식료품·주유 1.39–1.42, 최저 .54; 학습 NLL 2.5145 → 2.5088). 즉 **실제 반복 선택은 "지금까지의 방문 횟수 비례"로 이미 잘 설명되고 업종 고유의 추가
  재방문 강도는 없다.** `sticky`·`both` 팔은 생성하지 않는다(추정물은 `CALIBRATION_first_fit_sticky.json`으로 보존).
- **그러면 업종별 방문 수 차이는 어디서 오는가(추가 진단 `DIAG_INTRO_ORDER.json`, train·dev·기존 생성).** 처음 방문 중 고빈도 업종(식료품·주유·송금·통행료) 비중이 위치에 따라
  train .26 / .19 / .14 / .08 / .04 / .04, dev .31 / .27 / .16 / .10 / .05 / .06(위치 0 / 1–4 / 5–19 / 20–99 / 100–499 / 500+)로 **초반에 몰려 있다**. 등장 구간별 평균 방문 수는
  실제 101 / 68 / 39 / 16 / 4 / 2. 일찍 등장한 가맹점이 횟수 비례 강화로 방문을 쌓으므로, "어떤 종류가 일찍 등장하는가"가 업종별 방문 수를 만든다. 현재 모델은 고빈도 업종 비중이
  .17 / .17 / .16 / .12 / .10 / .07로 평평하고 초반 등장 가맹점의 방문 수가 65 / 57로 낮다(RTF는 .38 / .26 / .19 / .12 / .08 / .08, 92 / 70).
- **R2 변경.** 등록한 위치 무관 표 `novelcat`은 그대로 실행하고, **`novelcat_pos`** = P(업종 | 정상, 처음 방문, **위치 구간**)(게이트와 같은 6구간; 사전분포 = 위치 무관 표 10행)을 추가한다.
  나머지(업종 안에서는 마스크된 backbone, `_RARE_` 별도 범주, 사기 행 불변)는 같다.
- 팔: `novelcat`, `novelcat_pos`(각 4 생성). M1–M4와 채택 규칙은 그대로이며 "`both`"를 "`novelcat_pos`"로 읽는다. M3은 "위치 무관 표는 순서를 못 만들고 위치 구간 표가 만든다"로 바뀐다.
