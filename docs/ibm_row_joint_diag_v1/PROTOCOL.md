# ibm_row_joint_diag_v1 — ARGN의 행 단독 탐지 격차 진단 (등록 2026-11-10, 실행 전; 진단 전용)

사용자 지시(2026-11-10): "진단 먼저"(모델 고정·최종 확인 전에). 모델 변경 없음, 새 fit·새 생성 0, CPU. train·dev·기존 생성물만 사용, 봉인 test 미읽음.

## 0. 관측

등록 탐지기(`stable` HGB)의 **행 단독** TSTR(특징: 금액·간격·가맹점 반복 여부·위치·업종·채널, 이력 특징 없음) AUPRC: 실제 상한 .458, RTF+전이표 .337,
ARGN 현재 모델(`table_kind`) .109. ARGN의 모든 라우팅 변형이 .09–.11(문맥 치환 유무 무관: `routed_table` .091, `routed_subst_table` .098)이고 AUROC는 .97로
높다. 사기 행의 주변분포 지표(사기 업종 TV·금액 W1·온라인 비율)는 ARGN이 RTF와 비슷하거나 낫다. 즉 격차는 주변분포가 아니라 (a) 사기 행 안의 열 결합,
(b) 정상 행의 열 결합(실제 정상 행이 사기로 오인되는 영역), (c) 사기 행의 위치·가맹점 반복 여부 중 어디에 있다.

## 1. 실험

대상: ARGN `table_kind` 4 생성, RTF `rtf_table` 4 생성, 실제 train 부분표본 240명 × 4(seed 20261108+i). 평가는 dev.

- **A. 특징 묶음별 TSTR(행 단독).** 묶음: 금액 / 간격 / 업종 / 채널 / 가맹점 반복 / 위치 단독, 업종+채널, 업종+금액, 채널+금액, 업종+채널+금액, 전체에서 하나씩 뺀 것,
  전체. 어느 묶음에서 ARGN만 상한에서 멀어지는지 본다.
- **B. 열 교체(oracle substitution).** ARGN 생성물의 일부 행·열을 **실제 train**의 같은 라벨 행에서 뽑은 값으로 바꾼 뒤(공여 행은 seed 고정 무작위, 여러 열은 같은 공여
  행에서 함께) 행 단독·이력 탐지기를 다시 학습한다. 교체: 사기 행의 {금액}, {간격}, {업종}, {채널}, {업종+채널}, {업종+채널+금액}, {업종+채널+금액+간격};
  정상 행의 {업종+채널+금액}, {업종+채널+금액+간격}; 사기·정상 모두 {업종+채널+금액+간격}. 가맹점 열과 라벨·위치는 건드리지 않는다.
  이것은 생성 모델이 아니라 **원인 위치를 찾는 진단용 가상 데이터**이며 결과물로 보고하지 않는다.

## 2. 사전 판단

- ARGN 행 단독 AUPRC .109와 상한 .458의 차이 .35 중 **절반(.175) 이상**을 닫는 가장 작은 교체를 "위치가 확인된 원인"으로 적는다.
  사기 행 교체가 닫으면 (a), 정상 행 교체가 닫으면 (b), 사기+정상 전체 교체로도 못 닫으면 (c)(위치·가맹점 반복·라벨 배치)로 적는다.
- A에서 ARGN과 RTF·상한의 차이가 가장 큰 묶음이 B의 결과와 일치하는지 대조한다. 불일치하면 그대로 기록한다.
- 원인이 특정되면 그에 맞는 부품은 **별도 등록**(선행 비교 포함) 후에만 구현한다. 이 단계에서 모델을 바꾸지 않는다.

## 추가 등록 C — 가맹점 → 업종·채널 일관성 확인 (2026-11-10, A·B 결과 후; 실행 전; 진단 전용)

A·B 결과(RESULTS.md §1–2): 신호는 업종 × 채널 결합에 있고(업종+채널 묶음: 실제 .375, RTF .358, ARGN .097), ARGN **정상 행**의 {업종+채널+금액}을 실제 train 정상 행으로
바꾸면 행 단독 .109 → .317, 이력 .334 → .468(사기 행 교체는 ≤ .144). 가설: ARGN 정상 행에서 "가맹점 → 업종·채널" 함수 종속(실제 정상 행 일치 .999 / 1.000,
[ibm_merchant_memory_v1 수정안 4 진단](../ibm_merchant_memory_v1/RESULTS.md))이 깨져, 실제에서는 사기에만 나타나는 조합(대면 업종·가맹점의 온라인 거래)이 정상 행에도 생긴다.

- **C1. 측정.** 실제 dev / ARGN `table_kind` / RTF `rtf_table`의 정상·사기 행별: 채널 = 가맹점 train 최빈 채널 비율, 업종 = 가맹점 train 최빈 업종 비율, `_RARE_` 행 비율,
  정상 행 온라인 비율, "최빈 채널이 대면인 가맹점에서의 온라인" 비율, 업종 × 채널 결합분포의 TV(dev 대비).
- **C2. 가상 재구성(what-if; 생성 모델 아님).** ARGN 생성물에서 (i) `fd_normal`: `_RARE_`가 아닌 가맹점의 정상 행 업종·채널 := 그 가맹점의 train 최빈값;
  (ii) `fd_normal+rare`: (i) + `_RARE_` 정상 행의 (업종, 채널)을 train의 희귀 가맹점 정상 행에서 함께 재표집; (iii) `fd_all`: (ii) + 사기 행 업종 := 가맹점 최빈 업종,
  사기 행 채널 ~ 채널 표 P(온라인 | 사기, 새/반복)(.757 / .952). 각각 행 단독·이력 탐지기 재학습.
- **사전 판단.** C1에서 ARGN 정상 행의 채널 또는 업종 일치가 실제보다 .05 이상 낮고, C2 (ii)가 B의 정상 행 교체 이득(행 +.21, 이력 +.13)의 절반 이상을 내면 가설을
  채택하고 "가맹점 속성 일관성" 부품을 별도 등록 대상으로 올린다. 아니면 가설을 기각하고 금액·다른 결합을 본다.
