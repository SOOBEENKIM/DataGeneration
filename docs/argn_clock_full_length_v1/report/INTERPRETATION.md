# 전체 길이 학습 대조: 후반 개선, 전체 정상 품질 비용으로 미채택

같은 보정식을 전체 optimization 거래열로 학습하면 후반 시간 오류는 감소한다.
그러나 직전 clock_prefix보다 전체 정상 시간 및50–499 구간이 나빠져 교체하지 않는다.
사용자 요청에 따라 이번 실험은 GitHub에 push하지 않으며 직전 commit과 모델을 유지한다.
실패를 반복하지 않도록 이 로컬 폴더의 근거만 보존한다.

## 완료한 대조

- 기존1024 학습의48평가/최종 계수 재현과 simulator 세 점의 metric 차이0 확인.
- 같은619고객의 첫 gap 제외513464→815664거래로 학습 범위만 확장.
- 보정식, 두 계수, GMR, 실제 과거 입력, 최적화 예산/목적 가중치/초기 noise 고정.
- 새 보정1fit, 재현1fit, 새 native ARGN학습0회.
- 같은2부모×4draw=8개 전체 자유 생성,1581756행. 모두 exit0.
- 원본 labels/길이 완전 일치, native 연결2회, 원본 buffer/파일 hash 보존 확인.
- raw 주요 지표8개 출력 독립 검산, 이전 구간 지표144개 수치 재현.
- 최종 test 미사용. GPU0 반환 확인. 다른 사용자의 GPU1/2/3 작업은 유지.

## 확인한 것과 확인하지 않은 것

학습 길이 제한은 선택된 보정과 후반 오류에 영향을 주었다. 기존 a=.044445,b=.260902에서
전체 길이 a=−.008190,b=.339948로 바뀌었다. 이 보정식은 시간이 지나면 a에 수렴한다.
전체 길이 적합에서는 후반에도 남던 양의 위치 이동이 사라지고 해당 구간 오류가 줄었다.
동시에 중간 위치와 전체 정상 분포의 비용이 커졌다. 따라서 **전체 길이 학습만으로
직전 후보의 장점을 유지하며 모든 시간 구간을 개선한다는 가설은 지지되지 않는다.**

실제 과거를 입력한 전체 optimization 정상 W1도 이전 .06324에서 .02770으로 감소했다.
별도 internal validation의 전체 정상 W1은 .08444→.04146이다. 반면 자유 생성 전체
정상 W1은 악화했다. 실제 과거에서의 개선을 자유 생성 성공으로 대체할 수 없다.
이 결과는 조건 입력과 반복 생성의 차이를 더 구분할 근거이며, 그 자체로 유일한
구조적 원인이나 특정 대안의 성공을 증명하지 않는다.

둘 다48평가 예산을 소진했다. 이 비교는 같은 제한된 최적화 예산의 대조다.
모든 최적화된 full-length 방법에 대한 실패, 독립 training seed 전체의 통계적 유의성,
최신 생성기 대비 우위, 신규 방법의 기여 확정을 주장하지 않는다.

## 유지 상태

활성 연구 기준은 이전 `clock_prefix`와 원래 GMR 비교군 그대로다. 기존 코드/모델/
등록문서는 처음부터 덮어쓰지 않았으며 git reset이나 원본 삭제를 하지 않았다.
새 결과는 artifacts 아래에만 남기고 commit/push하지 않는다.
새 아키텍처나 추가 학습은 이 대조에 이어 자동 시작하지 않는다.
