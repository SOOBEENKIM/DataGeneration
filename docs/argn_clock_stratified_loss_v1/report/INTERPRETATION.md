# 200+ 손실 세분화: 전체·후반 개선 확인, 초반 비용으로 교체 보류

**실험과 독립 검증을 완료했다.** 개인 속도 모델에서는 기존 개선본보다 전체 정상
시간 오류가37.1%, 1024+ 오류가76.2% 감소했다. 두 부모의8개 같은 난수 생성 모두에서
전체 오류가 감소했다. 다만 초반6–49 오류가 커지고 한 부모에서 개인 대비 사기 금액
비용이 남아, 미리 정한 자동교체 조건은 통과하지 못했다. 기존 clock_prefix를 유지하고
새 후보와 모든 결과는 로컬에 보존한다. commit/push는 하지 않았다.

## 실제 실행

- 시간 보정 계수4회 적합. 모두 정해진 Powell 수렴 조건으로 종료했다(94/89/333/752평가).
- 기존 native ARGN 부모2개×동일4draw×4팔=32개 전체 생성,6,327,024행.
- native ARGN backbone 새 학습0회. 같은 팔에서는 구조·가중치·자료·noise·예산을 고정했다.
- 200+ 손실만200–499/500–1023/1024–2047/2048+ 조건부 W1로 분해했다.
- 초기 두 구간과200+ 전체의 바깥 비중, 원래 행·고객 질량, 다른 손실항을 유지했다.
- 비교 대상의 사기 순서·고객별 길이 exact parity,32개 원시 파일의 독립 지표 재계산,
  head/backbone/source 보존,8worker 정상 종료를 확인했다. 최종 test는 읽지 않았다.
- 유휴 확인 후GPU0, 이후GPU1에도 배정했다. 현재 우리 GPU 작업은 모두 종료됐다.

## 같은 모델에서 손실만 바꾼 효과

각 값은 기존2부모×4draw 평균이다. W1은 낮을수록 좋다. 1024+는 같은 위치와
고객 지원집합으로 비교했다. 기존 손실과 새 손실의 절대 목적값을 섞어 비교하지 않았다.

|같은 모델|전체 정상: 이전→세분화|1024+ 정상: 이전→세분화|
|---|---:|---:|
|거래 균등·두 계수|0.117875→0.104132|0.147493→0.159193|
|고객 균등·두 계수|0.130526→0.135092|0.389746→0.398468|
|위치6계수|0.188522→0.087800|0.412996→0.085269|
|위치×개인 속도6계수|0.170024→0.052838|0.501507→0.079196|

단순 두 계수에서는 일관된 동시 개선이 없었다. 구간별로 보정을 달리할 수 있는
두 모델에서는 전체·후반이 모두 개선됐다. 기존 모델의 더 낮은 pooled 손실만으로
구간별 품질을 판단하면 중요한 오류를 놓칠 수 있다는 근거다. 각 팔의 상세 결과는
[paired 결과](PAIRED_RESULTS.md), [부모별 차이](paired_parent_differences.csv)에 있다.

개인 속도 모델의 고객 균등 정상 marginal은 같은 모델의0.198378→0.220775로
악화했다. 보존 모델의0.267697보다는 좋다. 따라서 모든 고객 지표가 개선됐다고
해석하지 않는다. 고객 균등 marginal W1은 고객별 W1의 산술평균과 다르다.

전체 정상 오류는 두 부모에서 각각0.082067→0.049547,0.085869→0.056129다.
일반 이력 모델의 평균0.093009와 GMR0.137295보다도 낮다. 그러나 현재 직접 비교한
이 모델들에 관한 결과이며 TabDiT 등 최신 생성기 전체 대비 우월성은 아니다.

초반6–49 비용은 두 부모에서0.234498→0.329334,0.237605→0.332735로 반복됐다.
같은 personal_six의 기존 손실0.284870과 비교해도 세분화 후0.331035로 나빠졌다.
사기 금액은 첫 부모0.153630→0.150904로 좋아졌지만 두 번째는0.067116→0.077571로
증가해 미리 정한+.01 허용치도 조금 넘었다. 평균만 보고 이 비용을 생략하지 않는다.
전체 사기 간격과 개인 관계의 평균 비용도 작지만 존재한다.

정상 업종TV는0.067370→0.067718, 고객별 고유 가맹점 중앙값 평균은538.375→537.750이다.
사기율·고객별 사기 구성·거래 수는 동일 경로로 고정되어 정확히 같다. 이번 실험이
사기 발생·종료 모델 자체를 개선한 것은 아니다.

## 원인 해석의 범위

실제 과거 조건의 최적화 자료에서 위치 모델의2048+ 오류는0.430657→0.068779로
줄었다. 독립 내부69고객×2noise에서도0.43788→0.05897로 감소했다. 개인 속도
모델도 내부2048+가0.24672→0.12146으로 줄었다. 자유 생성의1024+ 개선까지
동반되었으므로 실제 과거에서의 손실 상쇄가 이번 후반 문제의 한 원인이라는
가설을 지지한다. 모든 오류의 유일한 원인이나 최적화의 전역 최적성을 증명한 것은 아니다.

이 진단의 구간별 W1은 원래200+ 고객 가중치를 제한한 measure다. 구간 안에서
고객 균등 가중치를 다시 만든 다른 표의 값과 혼용하지 않는다.
개발 자유 생성의1024+ 지원은 평균50.625고객,2048+는4.75고객으로 작다.
2048+ 극단 꼬리 결과만을 대표 개선으로 내세우지 않는다.

## 선행 중복과 기여 판단

[조건부 Wasserstein(JMLR2025), 공개v3 §3 Proposition1](https://arxiv.org/html/2403.18705v3)는
조건을 유지하는 coupling과 조건부 거리의 기댓값을 연결한다. 이번 목적은 그 이산
위치 조건 적용이다. 구간 세분화·spline·GMR·고객 균등 자체를 새로운 이론으로 주장하지 않는다.
2026년 시간 의존성 문헌과 적용 제한은 [실행 전 protocol](PROTOCOL.md)에 기록했다.

현재 얻은 연구 근거는 **같은 질량·용량에서 위치별 손실의 해상도가 반복 생성의
개인 시간 출력에 큰 영향을 주며, 개인 속도를 함께 쓰는 후보가 전체·중후반 오차를
더 줄일 수 있다는 결과**다. position_six와 personal_six는 같은6계수지만 서로 다른
basis이므로 clock 입력 하나만의 완전 nested 제거실험으로 해석하지 않는다.
이것만으로 신규 기여·논문 채택 가능성·최신 방법 대비 우위를 확정하지 않는다.

## 보존과 다음 범위

기존 개선본을 덮지 않았다. 새 personal_six는 유망한 로컬 후보로 보존하되 자동교체하지 않는다.
새로운 가중치나 구조를 이번 결과에 끼워 넣어 재학습하지 않았다.
다음 원인 확인 대상은 **새 후보의 전체·후반 개선을 고정한 상태에서 초반6–49 오류가
실제 과거 조건에서도 남는지, 생성된 초기 개인 속도에서 커지는지**다. 필요하면
속도 이력이 충분하지 않은 구간과 충분해진 구간을 진단으로 구분하되, 곧바로 또 다른
손실 세분화나 가중치 변경을 해결책으로 확정하지 않는다. 이 후속 진단·학습은 아직 실행하지 않았다.

이번 개발세트는 반복적인 연구에 사용됐으며,8draw를8독립 학습으로 보아 통계적 확증을
과장하지 않는다. 봉인한 test와 가까운 최신 생성기 직접 비교는 최종 주장 전에 필요하다.
