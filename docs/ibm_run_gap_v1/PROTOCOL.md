진단(새 생성 0; `docs/fraud_structure_v1/ibm/DIAG_GAP_BY_ROW_KIND.json`, 간격 = 분, 행 종류 = 직전 라벨 → 현재 라벨):

| 행 종류 | 실제 train (n) | 실제 dev (n) | ARGN 현재 모델 | ARGN + 가맹점 부품(`full`) | RTF+전이표 |
|---|---:|---:|---:|---:|---:|
| 진입 (정상 → 사기), 중앙값 | 146 (490) | 168 (169) | 77 | 82 | 74 |
| 지속 (사기 → 사기), 중앙값 | **36** (813) | **25** (318) | **98** | **106** | 50 |

- 실제 구조: 사기 구간은 **평소와 비슷한 간격으로 시작**(진입 146–168분, 정상 221–242분)해 **구간 안에서는 몰아서**(지속 25–36분) 일어나고, **구간 직후의 정상
  거래는 평소보다 빨리** 온다(복귀 124–127분).
- ARGN 현재 모델: 사기 행 전체에 같은 분포를 낸다(진입 77 ≈ 지속 98). 사기 전용 출력층은 "사기인가"로만 라우팅되므로 진입 490행과 지속 813행의 **혼합**을
  배운다 — 진입은 너무 짧고 지속은 너무 길다. 복귀 행은 정상 출력층이 내므로 평소 간격(268)이다. 바닥 배: 구간 내 간격 W1 5.0–5.3, 구간 후 간격비 2.6–2.8,
  1단계 사기 간격 2.3–2.6, 구간 시간폭 5.1–5.5.
- 효용과의 연결: 등록 탐지기 특징에 `log_gap`, `gap_vs_med20`이 있다. 효용 이득은 **가설**이며(H2), 이전 단계에서 간격 관련 변경이 IBM 효용을 올린 적은 없다.

## 2. 부품 (동결 ARGN + 현재 모델 위, 새 학습 0)

현재 모델 = `native_{fit}` + 전이표(라벨 먼저) + `routed_subst` 사기 출력층 + 가맹점 부품 `full`. 간격 열은 102구간 binned 범주(`gap__bin`)로 생성된다.
행 종류 k ∈ {진입, 지속, 복귀}에서 간격 구간 분포를 다음 중 하나로 바꾼다(정상 → 정상 행과 고객의 첫 행은 그대로).

- **표 추정(train만)**: 그 fit의 ARGN 인코딩 자료(내부 학습 + 내부 검증 = train 고객 전체)에서 행 종류별 구간 빈도. 평활: 사전분포 = 기준 분포(진입·지속은 사기
  행 전체, 복귀는 정상 → 정상 행), 강도 10행.
- `table_kind`: 진입·지속·복귀 행의 출력을 표 P(구간 | 행 종류)로 **대체**.
- `ratio_kind`: 출력층 확률에 P(구간 | 행 종류) / P(구간 | 기준)을 곱해 재정규화(**보정**; 출력층의 고객·이력 조건부 정보를 유지).
- `table_pooled`(대조): 사기 행의 출력을 P(구간 | 사기)로 대체(행 종류 구분 없음, 복귀는 그대로) — "표냐 head냐"와 "행 종류 조건화"를 분리.
- `table_fraud`(ablation): `table_kind`에서 복귀 행 개입만 뺌.

사기 출력층의 라우팅 hook 뒤에 적용한다(사기 행에서는 사기 출력층의 출력을 받아 대체/보정). backbone·출력층 가중치, 라벨 과정, 가맹점 부품은 그대로.

## 3. 가설과 사전 판단 (fit 2 × 생성 2 평균; 바닥 = 기존 바닥 재사용)

- **H1 (구조).** `table_kind` 또는 `ratio_kind`에서 구간 내 간격 W1 바닥 배 ≤ 3(현재 5.3), 구간 후 간격비 ≤ 3 유지(현재 2.6), 행 종류별 중앙값이 실제 방향을
  따른다: 지속 < 진입, 지속 중앙값 ≤ 60분(현재 106), 복귀 중앙값 < 정상 중앙값. 둘 다 충족하면 구조 지표 합이 작은 쪽을 택한다.
- **H2 (효용, 등록 탐지기).** 선택 팔의 효용 − `full`(.306) ≥ +.04(생성 간 표준편차 .038 이상)이면 "효용 부품"으로 채택. −.03 초과 +.04 미만이면 "효용 중립, 구조
  부품"으로 채택 여부를 H1·H4로만 정한다. ≤ −.03이면 채택하지 않는다. 보조 탐지기 3종은 분해 보고용.
- **H3 (ablation).** `table_pooled`은 지속/진입 구분을 만들지 못해야 한다(지속 중앙값 > 60분, 구간 내 간격 > 3배) — 그래야 이득이 "행 종류 조건화"에서 온다.
  `table_fraud` 대 `table_kind`로 복귀 개입의 몫을 본다.
- **H4 (대조; 수정안 1 기준).** 라벨 과정 지표 동일, 표준 지표 바닥 배 ≤ 3, 가맹점 구조(사기·정상 새 가맹점, 고객당 가맹점 수) ≤ 3배 유지. 전체 사기 간격 W1은
  Sparkov에서처럼 상쇄 소실로 나빠질 수 있으므로 단독 판정 기준으로 쓰지 않고 행 종류별 값과 함께 보고한다.
- 실패 시: H1 미달이면 원인(평활·구간 해상도·하류 이력)을 기록하고 재시도 없이 종료. 봉인 test는 읽지 않는다.
