## 3. 판정

- **H1 충족 → `table_kind` 선택.** 구간 내 간격 5.33 → 1.16배, 구간 후 간격비 2.65 → 1.02배, 지속 35분 < 진입 142분, 지속 ≤ 60분, 복귀 141분 < 정상 258분.
  함께 구간 시간폭 5.5 → 1.1배, 1단계 사기 간격 2.6 → 0.97배(Sparkov에서 우려한 상쇄 소실은 일어나지 않음). `ratio_kind`도 기준은 넘지만 진입을 과보정
  (350분; 사기 출력층의 출력이 사기 행 주변분포가 아니라 조건부라 비율이 이중으로 걸림)해 구조 합이 더 크다.
- **H2: 효용 중립(구조 부품).** +.024로 4개 생성 모두 양(+)이지만 기준 +.04 미달, −.03보다는 큼. 보조 탐지기에서도 +.007–+.024로 작고 일관되게 양.
  **효용 부품으로 주장하지 않는다.**
- **H3 충족, 단 효용 해석에 주의.** `table_pooled`은 진입 61 ≈ 지속 67로 구분을 만들지 못하고 구간 내 간격 3.7배(> 3)다 — 구조 복구는 행 종류 조건화에서 온다.
  그러나 효용은 `table_pooled`(+.025)과 `table_kind`(+.024)가 같다: 작은 효용 변화는 행 종류 조건화가 아니라 "사기 행 간격을 출력층 대신 train 주변분포로 냈다"
  에서 온다(사기 간격 W1 2.6 → 1.16배). 복귀 개입(`table_fraud` → `table_kind`)은 구간 후 간격비만 고치고(2.67 → 1.02) 효용은 같다.
- **H4 충족.** 라벨 과정 지표 동일, 표준 지표·가맹점 구조 불변(간격 열만 바뀌므로 하류 영향이 거의 없음).

## 4. 결정

**구간 위치 조건부 간격 표(`table_kind`)를 구조 부품으로 채택한다.** 사기 구간의 시간 구조(평소 간격으로 시작 → 구간 안에서는 몰아서 → 직후 정상 거래는 빨리)를
학습 없이 3개 표로 복구했고(이전 학습형 head는 실패) 다른 축을 해치지 않는다. 효용은 +.02 수준으로 **중립**이며 주장하지 않는다.
모델(ARGN) = 동결 backbone + 전이표 + 라벨 라우팅 출력층 + 이력 참조 가맹점 생성 + 구간 위치 간격 표. 등록 탐지기 효용 .003 → .142 → .306 → .331(상한 .61).
