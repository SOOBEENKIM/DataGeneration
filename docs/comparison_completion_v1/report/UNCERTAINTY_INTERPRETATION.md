# 고정 후보의 개선·비용·불확실성

새 학습/생성 없이 이전 18개 전체 거래열의 원시 행을 다시 읽어 세 지표54개를
독립 재계산했다. 최대 차이9.02e-17, 이전590파일 해시 유지. 세 전체 독립 학습과
각 두 생성의 평균을 단위로 분석했다. 개발 데이터 재사용 후의 탐색 분석이다.

## 주요 지표: 개인 속도+위치 C 대 위치만 P6

오차 차이 C−P6에서 음수는 개선이다.

| 지표 | 평균 차이 | df=2 t 기반95% 구간 | 개선된 독립 학습 |
|---|---:|---:|---:|
| 정상 전체 log-gap W1 |−.003177|[−.011383,+.005028]|3/3|
| 사기 시작 개인 대비 W1 |−.001830|[−.028311,+.024651]|1/3|

정상 시간의 상대 개선은 기존3.25%와 일치한다. 학습 하나를 빼도 정상 차이는
−.004612~−.001372로 음수다. 하지만 세 학습뿐이어서 효과 크기를 좁혀 말할 수
없고, t구간은 학습 효과의 분포 가정에 민감하다. 8개의 정확한 부호 전환 대조에서
양측p는 정상.25/시작1.0이다. 이는 확인적 검정이나 유의성의 증명이 아니다.
생성6개를 독립 학습6개로 늘려 세지 않는다.

## 고객별 보조 분석: pooled W1과 다른 질문

147명 중 모든6대응 생성에서 실제/생성 정상 구간을 비교할 수 있는119명을
명시적으로 분리했다. 나머지28명은 구간이 없어 이 고객별 완전대응 평균을
계산할 수 없으며, 주 지표의 전체147명에서 제거한 것이 아니다.

- 고객별 정상 절대 간격 W1 평균은 C−P6 −.013993.119명 중92명 개선/27명 악화.
  고정 모델들을 조건으로 고객을 재표집한95%구간 [−.017816,−.010050].
- 고객별 정상 개인 대비 간격 W1 평균은 +.002124.119명 중11명 개선/108명 악화.
  같은 조건부 구간 [+ .001839,+ .002403].

따라서 평균 시간 개선이 한 고객에게만 생긴 것은 아니지만, 정상 개인 관계
비용도 넓게 반복된다. 고객별 W1 평균, 고객 동일가중 pooled W1, 사건가중 pooled
W1은 다른 통계이므로 서로 바꿔 설명하지 않는다. 고객 bootstrap 구간으로
새로운 독립 재학습의 일반화나 사기 시작 사건의 짝맞춤 예측을 주장하지 않는다.

결정: C/P6/H 및 기존init_only 모두 보존. 추가 보정식 학습 없음. 최신 전체
생성기와 충분한 CPAR 비교를 진행하며 이 비용을 계속 보고한다. 10%라는 이전
선별 기준은 논문 출판의 필요조건이 아니며, 이번 분석도 최종 기여 확정은 아니다.
