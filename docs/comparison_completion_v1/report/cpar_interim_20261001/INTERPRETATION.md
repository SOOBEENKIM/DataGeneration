# CPAR 완료분의 별도 비교 — MeLD 학습은 계속 진행 중

기존 통합 평가가 MeLD 종료를 기다리는 동안, 완료된 CPAR 및 고정 ARGN 출력
30개를 같은 평가 함수로 먼저 비교했다. 원래 평가 소스/계획/결과는 변경하지
않았으며, 출력은 이 별도 디렉터리에 저장했다. 최종 전체 비교 완료가 아니다.

각 모델3독립학습×2생성, 같은143고객 지원 범위의 평균. 오차는 작을수록 좋다.

| 모델 | 정상 간격 log-W1 | 사기 시작 개인 대비 W1 | 생성 평균 거래 수 |
|---|---:|---:|---:|
| CPAR native |.872977|.481936|26,883|
| CPAR + 동일 합성 길이 조건 |.881063|.484045|192,376|
| 이력 모델 H |.118333|.132165|192,376|
| 위치 보정 P6 |.096780|.138709|192,376|
| 개인 속도+위치 보정 C |.093852|.135836|192,376|

CPAR 추가 두 학습은 내부 검증으로 각각256/128epochs를 선택했다. 기존 학습의
128과 합쳐3독립학습이며, 세 시드 모두 같은 epoch로 고정했다고 하지 않는다.
길이 대조는 C의 이미 생성된 길이만 제공했다. 실제 미래 길이나 C의 라벨·금액·
간격은 제공하지 않았다. 이 대조를 공식 CPAR native 결과로 바꿔 부르지 않는다.

CPAR 길이 분포 오차는2.077901→.177790으로 낮아지지만, 두 주요 시간 지표는
개선되지 않았다. 짧은 거래열 차이만으로 이번 CPAR 시간 품질 차이 전체를
설명할 수는 없다. 이 결과는 선택한 학습량/적용 설정의 비교이며 최적 CPAR나
모든 최신 생성기 대비 우위를 입증하지 않는다. H/P6도 CPAR보다 낮은 오차이므로
큰 전체 차이를 개인 속도 보정 하나의 신규 기여로 돌리지 않는다.

이143고객에서 C는 P6보다 정상 시간과 시작 개인 관계 평균이 낮다. 사전 주요
147고객 결과와 혼합하지 않으며 기존 정상 개인 관계/중반 비용은 그대로 남는다.
다른 필드/지원 구간/전체147수치는 COMPARATOR_* 및 LENGTHS.csv에 별도 보존했다.

기존590해시 및 현재3backbone/9head/18output의30해시, CPAR12생성 기록 해시를
검증했다. 새 모델 학습/생성0, 테스트 읽기0, 모델 교체/push0.
MeLD는 이 보고 시점에도 VAE 학습 중이며 최종 생성 성능은 아직 없다.
