# 최종 테스트·다른 데이터 검증의 실행 조건

사용자는 이 후속 단계도 승인했다. 별도 사용자 허가가 필요한 것이 아니다.
현재는 비교군의 충분한 적용이 완료되지 않아 최종 평가 설정을 확정할 수 없다.
따라서 본 학습·적용 감사가 끝나기 전에 봉인한 최종 테스트를 자동으로 열지 않는다.

1. H/P6/C는 이미 고정했다. 개인 속도 효과의 주요 비교는 C 대 P6이며 정상
   시간·사기 시작 개인 관계를 계속 주 지표로 둔다. 보조 지표로 목표를 바꾸지 않는다.
2. CPAR는 native와 같은 합성 길이 조건 대조를 구분한다. MeLD의 학습 곡선,
   희귀 라벨 복원, 종료/길이, 공개 코드 적용 차이를 확인한다. 전부0사기인
   최신 모델을 충분히 적용한 최강 비교군으로 간주하지 않는다.
3. 실행·적용이 타당한 설정을 내부 검증으로 확정하고, 테스트 고객 정적 조건
   추출/생성/평가 파일 목록과 hash를 먼저 고정한다. 실제 테스트의 미래 거래
   수·라벨·간격은 생성기에 제공하지 않는다. 테스트 결과로 구조/학습을 바꾸면
   그 테스트는 이후 탐색 데이터가 됐다고 명시한다.
4. Berka는 ARGN 공식 재현을 보존하고 별도 전이 검증을 등록한다. 일 단위
   날짜/동일일 거래와 Sparkov 초 단위 간격의 해상도 차이를 먼저 명시한다.
   사기 라벨을 인위적으로 만들어 비교하지 않는다. 공통 정상 시간·개인 속도
   관계만 평가하고, Berka 결과로 사기 조건부 일반화를 주장하지 않는다.
5. 논문의 초점은 시간 출력 보정의 추가 효과와 비용이다. 충분한 강한 비교,
   제거 대조, 독립 학습, 최종/다른 데이터 결과에 맞춰 주장 범위를 확정한다.
   소폭 비용을 금지하지 않지만, 약한 비교군이나 알려진 효과만으로 신규성을
   확정하지 않는다. 개인정보 보호·탐지 유용성 주장이 필요하면 별도 평가한다.

이는 이후 실행의 조건·범위를 명시한 기록이며 최종 테스트 또는 Berka 확장
학습을 이미 완료했다는 뜻이 아니다.
