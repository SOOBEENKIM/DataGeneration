# 실행 중 원문 재대조 — 2026-09-27

프로토콜·학습·생성 설정 변경 없음. 아래는 대조 해석을 위한 추가 독해다.

[TabDiT v2](https://arxiv.org/html/2504.07566v2)의 Introduction 및 §4.2를
재확인했다. 길이를 내용과 독립적으로 뽑는 문제를 이미 지적하고, DiT가 padding
벡터까지 생성해 거래열 길이와 내용을 함께 생성하도록 한다. 따라서 이번
초기 상태–길이 결합분포의 개선만으로 신규성을 주장할 수 없다. 이번 대조는
ARGN 고정 출력 위에서 문제를 국소적으로 분리하는 작은 조건부 혼합분포다.
TabDiT 전체 구조와 같은 방법도, TabDiT의 이 현상에 대한 실패 증명도 아니다.
[공식 구현](https://github.com/fabriziogaruti/TabDiT)을 후속 직접 비교 대상으로
유지한다. 동일 Sparkov·라벨·고객 분할의 재학습 비교는 이 실험에서 실행하지 않았다.

2026 [TAT-CTGAN 논문](https://www.mdpi.com/2227-7390/14/7/1183)의
출판사 검색 원문에서 Introduction, 통합 pipeline 설명, Conclusions를 확인했다.
목적은 IEEE-CIS 사기탐지이며 CTGAN 사기 거래 증강 후 고객 키·시간으로
거래열을 다시 구성한다. 전체 고객 거래열의 자연 사기율/지속/금액 분포 재현과
동일한 실험은 아니다. 논문도 tabular-only 생성의 시간 일관성 및 더 강한 최신
비교군을 남는 과제로 적는다. 직접 페이지 열기는 오류였으므로 원문 전체·보충
코드를 정독/재현했다고 기록하지 않는다. Sparkov 순차 생성 baseline의 대체물로
채택하지 않고 목적이 다른 관련 연구로 구분한다.

[Seq2Synth v3](https://arxiv.org/html/2607.15606v3)는 시간 구조를 별도 평가하는
benchmark이며, 현재 논의의 직접 비교 목록에 TabDiT가 포함된다. 이를 근거로
ARGN·CPAR가 이 benchmark에서 실패했다고 말하지 않는다. 이번 연구가 주장할
관계에 맞는 직접 모델 비교가 필요하다는 판단을 유지한다.
