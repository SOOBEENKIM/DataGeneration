# 공동 관계 개선: 완료 결과와 채택 범위

**8개 작은 모듈 학습 실험, 36개 새 전체 거래열 생성, 총7,177,275행을 완료했다.**
부모 ARGN을 새로8번 학습했다는 뜻은 아니다. 이미 고정한 부모2개 위에서
길이/초기상태 모듈4개와 금액 출력 전문가4개를 학습했다. 최종 후보와 현재
기준은 각각 **2부모 학습 × 4생성 seed**로 비교했고 최종 test 거래는 읽지 않았다.

## 무엇이 원인이었나

1. 구간별 관계와 구간 구성은 다르다. 기존 변경 후 개인 대비 금액 전체 오차는
   악화했지만 시작/지속/관측 첫 시점부터 사기인 구간 각각에서는 좋아졌다.
   실제 구간 비중으로 표준화하면 방향이 바뀐다. 구성 변화가 전체 점수에 관여한다.
   이 표준화는 진단용이며 실제 생성 결과를 대신하지 않는다.
2. 현재의 단순 전환 모델은 거래 수가 많을수록 사기를 경험할 누적 확률을 크게
   높였다. 정상으로 시작한 고객의 학습 데이터 사기 경험률은 거래 수 집단별
   74–80%인데, 고정 모델의 계산값은 500건에서37.9%, 3000건에서93.5%였다.
   이것은 **우리 현재 전환 대조의 노출 처리 문제**다. ARGN 전체나 모든
   실제 금융 고객의 보편적 성질로 일반화하지 않는다.
3. 구성 개선만으로 끝나지 않았다. 사기가 처음 시작되는 거래는 실제 과거와
   현재 라벨·업종·간격을 줘도 지속 거래보다 금액 오차가 컸다. 자유 생성에서는
   조건 변화까지 겹쳐 더 악화했다. 따라서 이 부분을 별도 출력 대조로 확인했다.

## 어떤 변경이 효과를 냈나

- 초기 상태와 거래열 길이를 결합분포로 생성한다. 새 count head에 고객 context를
  추가한 복잡한 팔은 안정적인 추가 이득을 보이지 않아, 제거 대조를 선택했다.
  **ARGN 본체의 고객 조건까지 제거한 것이 아니다.**
- 첫 사기 발생은 학습 노출 우도로 추정한 `1-exp(-lambda_band/L)`로 생성한다.
  거래 진행도별 위험을 쓰며 L은 생성기가 뽑은 계획 길이다. 실제 고객의 미래
  길이나 정답 사기 순서를 입력하지 않는다. 사기 종료/재발은 고정 기준을 유지한다.
- 현재 라벨 사기, 직전 라벨 정상인 거래에서만 미세조정한 금액 전문가를 쓴다.
  업종·간격·기존 금액 출력은 고정한다. 같은 구조를 전체 사기 거래로 학습한
  대조도 실행해, 전문가를 하나 더 둔 효과와 시작 거래 집중 학습을 구분했다.

개인 대비 금액, 사기율의 오차 감소는 길이·발생 개선에서 두 부모 모두 새로운
생성 seed에서도 재확인됐다. 시작 거래 전문가까지 포함한 개인 대비 금액은
부모별로0.206793→0.150938, 0.153113→0.077322다.

시작 거래만의 개인 대비 금액 W1은 **결합 기준0.5064→전문가0.3523**,
금액 W1은0.6627→0.4505다. 신규 draw만으로도 각각0.4852→0.3323,
0.6391→0.4174였다. 전문가 추가 전후의 **고객별 길이와 전체 라벨열은
모든 대응 draw에서 정확히 같다.** 따라서 이 금액 개선은 사기 고객을 다시
배치하거나 전체 사기율을 조정해서 얻은 결과가 아니다.

초기 제거 대조에서 전체 사기 학습 전문가도 시작 거래를 개선했다(개인 대비
0.5276→0.4315). 시작 거래 집중 학습은0.3722까지 줄였다. 이 비교는 초기
4생성씩이며, 모든 추가 이득이 새로운 구조 때문이라는 주장으로 확대하지 않는다.
실제 과거 NLL은 두 번째 부모의 development에서 미세하게 악화하는 반면
분포 W1은 개선하므로, 모든 조건부 점수가 좋아졌다고도 하지 않는다.

## 남은 비용과 판단

사기 간격 W1은 원래 기준보다0.01358, 정상 금액 W1은0.00516 높다.
고객별 방문 가맹점 수 중앙값의 draw 평균은552.125→537.875(약2.58% 감소),
기존 가맹점 재방문 비율은0.63917→0.63293이다. 전체 가맹점 수693은 유지한다.
정해 둔 큰 비용 제외 기준은 넘지 않았으나 **기존 성능을 전부 그대로 보존한
것은 아니다.** 2부모와 같은147고객의 추가 draw는 다른 고객/데이터 일반화나
통계적 우월성 증명이 아니다. 희귀 셀 지지 표본 수와 남은 시작 거래 오차도 중요하다.

기존 기준은 삭제·덮어쓰기하지 않는다. 이번 결합은 재현 가능한 **개선 후보이자
강한 대조 모델**로 별도 고정한다. 바로 논문 신규성/최신 모델 대비 우월성을
선언하지 않는다. 조건부 수치 출력은 [TabCascade 2026](https://arxiv.org/html/2601.22816v3),
노출 전이 우도는 [2026 neural Markov models](https://link.springer.com/article/10.1186/s12874-026-02769-5),
길이와 내용의 공동 생성은 [TabDiT §4.2](https://arxiv.org/html/2504.07566v2)와
직접 겹친다. [구체적 대응표](PROTOCOL.md)와 [추가 원문 대조](REFERENCE_ADDENDUM.md)를
함께 보존한다. 다음 기여 판단은 이 강한 대조와 가까운 최신 방법을 같은
Sparkov 설정에서 비교하고, 여전히 남는 개인 행동 조건의 오류를 설명하는 데 둔다.

## 검증과 자료

14개 고유 단위 검증, 실제 native checkpoint의 온라인 상태/축소 batch 검증,
시작/지속/정상 routing의140개 token-position 완전일치, 고정 출력 가중치 hash,
모든 새 raw parquet의 독립 W1 재계산 및 라벨열 일치를 확인했다. 기존 검증된
cache는 hash로 고정해 재사용했다. 추가 seed의 생성 후 비교 경로 오류는
원본 로그·자료를 보존하고 [복구 기록](onset_output/RECOVERY_PROTOCOL.md)에 따라
재개했다. 학습 설정 변경/실패 결과 삭제는 없었다. 모든 생성·평가 완료 후 GPU2·3을 반환했다.
