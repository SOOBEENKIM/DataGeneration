# 추가 생성 seed 확인 — 2026-09-27, 추가 생성 전 등록

초기16개 생성 중 첫12개 결과를 확인한 시점에 등록한다. 원래 실험 조건은
변경하지 않는다. 초기 자유 생성의 작은 표본에 의존한 채 모델을 승격시키지
않기 위해, 사전 preservation screen을 **두 부모 seed 모두** 통과한 결합
후보 하나만 고정하여 새로운 생성 seed20261021/20261022로 확인한다.

선택 규칙: `count_hazard_no_context`가 두 부모에서 통과하면 더 단순한
그 팔을 선택한다. 아니면 `count_hazard`가 두 부모에서 통과하면 선택한다.
둘 다 통과하지 않으면 이 추가 확인은 실행하지 않고 기존 기준을 유지한다.
검증된 내부 validation NLL도 무조건부 head가 더 낮았으므로, 제거 대조가
좋으면 복잡한 고객 조건을 새 기여로 주장하지 않는 선택이다.

부모 seed2개 × 신규 생성 seed2개 × 고정 현재/고정 후보2개 = **8개 신규
전체 거래열**. 새 신경망 학습·확률 추정·development 비율 보정은 없다.
원래 현재 모델은 원래 episode_generation으로 실행한다. 후보는 원래
preservation_generation 및 확정 checkpoint로 실행한다. 추가 생성에도
같은147고객의 context만 공급하고 실제 미래 거래·길이는 제공하지 않는다.

판단은 신규 seed에서 **별도로** 같은 두 주요 오차의 방향 및 기존 비용을
확인하고, 원래 seed와 합산한 결과도 함께 제시한다. 신규 결과만 유리하게
선별하거나 기존 실패 팔을 지우지 않는다. 신규 두 seed에서 재현되지 않으면
안정된 동시 개선으로 승격하지 않는다. 완전한 최종 test나 다른 데이터셋의
일반화 검증을 대신하는 것이 아니다.
