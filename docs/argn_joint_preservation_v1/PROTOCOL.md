# 구성 변화와 조건부 출력의 분리 — 2026-09-27 등록

## 관측 근거와 고정 기준

기준은 `argn_gap_episode_v1/gap_and_transition`: 업종·금액·간격 출력과
고객별 episode/초기 길이 조건을 보강한 ARGN이다. 부모 학습 seed 2개,
생성 seed 각 2개의 기존 결과를 그대로 보존한다. 개인 대비 사기 금액 W1은
이전 업종+금액 기준 0.137138에서 현재 0.177797로 악화했고 사기율은
0.6064%에서 0.5411%로 내려갔다(실제 development 0.6438%).

이번 새 학습 전 진단에서 시작·지속·관측 첫 시점부터 사기인 구간 각각의
개인 대비 금액 W1은 모두 개선됐다. 실제 구간 구성으로 표준화한 진단 W1도
0.172630→0.151061이다. 반면 구간·고객 나이·업종을 모두 조건으로 두면
0.063950→0.089814로 악화한다. 따라서 구성 변화의 관여는 확인했지만
조건부 출력 문제가 전혀 없다는 결론이나 인과 분해로 해석하지 않는다.
표준화 값은 진단용이며 실제 생성 성능을 대신하지 않는다.

금액 출력은 실제 과거·현재 조건에서 development 상대 금액 W1
0.064445/0.023561을 보였다. 무조건 금액 출력을 다시 학습하기보다
초기 상태–길이–사기 시작 노출의 구성을 먼저 분리한다.

위 원문의 관련 본문을 확인했다. 모든 부록 증명·공식 코드 실행을 완료했다는 뜻은
아니다. 이 실험은 알려진 조건부 혼합분포/노출 위험으로 설명되는 개선을 분리하는
**강한 단순 대조**이며 새 방법의 기여로 등록하지 않는다. 최신 모델과의 동일 과제
직접 비교는 여전히 후속 필수 작업이다.

## 변경과 학습

- **L**: 고정 ARGN 고객 context embedding(256차원)에서 초기 라벨과 길이의
  결합분포를 학습한다. `p(y_first|context) p(L|y_first,context)`.
  라벨별 log1p 길이 GMM 3개, 32차원 tanh 은닉층, dropout 0.1.
  정확한 정수 구간 CDF 질량으로 고객별 joint NLL을 최소화한다.
  native 보호 범위 7–3106 유지. 실제 optimization 범위도 7–3106이고,
  development 최대3119는 이 기존 상한 밖에 있다. 경계 질량을 포함한다.
- **H**: 이전 거래 정상, 이전 사기 경험 없음인 risk set에서
  `p(onset_t)=1-exp(-lambda_b/L)`, `b=min(9,floor(10*t/L))`.
  optimization 실제 노출의 Bernoulli NLL + 약한 Gamma(shape1.5, rate1e-6)
  prior로 10개 lambda를 추정한다. 마지막 관측 뒤의 가상 종료/정상을 추가하지 않는다.
- 학습 때 L은 관측 전체 거래 수, 생성 때 L은 생성기가 뽑은 계획 거래 수다.
  실제 development 고객의 미래 길이를 공급하지 않는다. **전체 거래열 생성**의
  결합분포이며 online 사기 예측 모델은 아니다.
- 사기 지속/종료/재발 확률, 업종·간격·금액 head, native ARGN 가중치는 고정한다.
  생성 후 라벨 재배치·목표 사기율에 맞춘 행 재표본추출을 하지 않는다.

optimization 619명/816283행으로 초기화·학습·정규화하고 internal-validation
69명/100226행의 **고객 평균 joint NLL**로 checkpoint를 고른다.
초기 GMM(step0)도 후보. AdamW lr0.001, weight decay0.01, batch128,
최대1500step, 25step마다 평가, patience8, min_delta1e-5, clip1.
development 147명/177997행은 진단/평가용; 최종 test event는 읽지 않는다.

## 사전 판단 기준

모든 생성에서 간격·금액·개인 대비 금액·사기율·고객 구성·사기 지속/종료·
정상 품질·다양성·길이를 함께 평가한다. 두 부모 seed별 평균과 draw 범위도 보고한다.
개인 대비 금액과 사기율의 현재 오차가 **둘 다** 두 부모 seed에서 줄어드는지
먼저 확인한다. 이전 개인 대비 금액 0.137138 회복 여부는 별도 기준이다.

주요 fraud gap/amount W1, normal gap/amount W1, normal merchant TV는
고정 현재 기준보다 +0.05를 초과해 악화하면 채택 후보에서 제외한다.
사기 경험/전용 고객 수의 실제값 대비 오차는 각각 +5명 초과 악화 시 제외한다.
고객별 다양성 중앙값/방문 가맹점 비율이 5% 이상 떨어지는 경우도 제외한다.
이 허용치는 성공을 주장하기 위한 점수 조작이 아니라 큰 비용의 사전 제외 기준이다.
통과하더라도 **모든 악화 수치를 공개하고**, 기존 개선을 모두 유지했다고 자동
판정하지 않는다. 개인 대비 금액과 사기율을 모두 회복하지 못하면 기존 모델을
유지하고 실패 원인을 다음 근거로 쓴다. development 결과를 보고 이 실험의
checkpoint/확률을 재조정하지 않는다.

기여 판단은 별도다. 알려진 단순 대조로 해결되는 부분은 baseline에 포함하며,
최신 가까운 방법과의 비교·요소 제거·다른 조건의 효과 없이는 신규성을 주장하지 않는다.
