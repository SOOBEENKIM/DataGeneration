## 4. 연구 진행에서 바로잡을 점

### 4.1 최근 작업의 실제 범위

`benchmarks/argn_clock_regression.py::ClockRegression.forward`는 `base` 인자를 받지만 사용하지 않는다. 출력은 전환 phase와 strict-past20 간격 median인 clock으로 결정된다. 이후 위치 보정·초기 혼합·gain도 이 출력에 작용했다. **최근 작업은 동결 ARGN 위의 통계 시간 출력 개발이지, CS-SAF 전체를 새로 학습하거나 ARGN 이력 구조 전체를 바꾼 실험이 아니다.**

일반 신경 시간 출력은 이미 했다. `TimeDensity`는 ARGN base+phase+clock으로 혼합 확률·평균·분산을 예측했다. 3성분, hidden64, 최대2000step, phase 균등 minibatch와 macro-phase NLL 선택이었다. 그러므로 이를 다시 만들고 “처음 이력을 넣었다”고 주장하면 안 된다. 다른 목적/더 충분한 예산/rollout 학습을 적용한다면 무엇이 달라지는지 명시해야 한다.

GMR이 base를 무시한다는 사실만으로 성능 오류의 원인이나 신경 이력의 우위를 확정할 수는 없다. 실제 기존 일반 history는 일부 주요 관계에서 GMR보다 나빴다.

### 4.2 학습 목표가 좋아져도 원하는 관계는 나빠질 수 있었다

최근 손실은 전체·clock·후반 이득으로 중반 손실 증가를 보상할 수 있었다. 고객 균등 학습과 거래 균등 headline은 목표 모집단도 다르다. 고객 균등이 잘못된 것이 아니라, 두 목표를 구분하지 않고 “손실 감소=목표 개선”으로 읽은 것이 문제다.

다음에는 핵심 목표와 보호할 지표를 먼저 고정한다. 평균 합 하나만 최적화하고 이후에 실패한 구간의 가중치를 계속 바꾸는 절차를 끝낸다. 사후 모델 교체 screen 실패와 “논문 불가능”도 다른 판단이다.

### 4.3 실제 과거와 생성 과거의 차이

중반 재귀 재생에서 GMR의 clock만 실제 과거로 바꾸면 W1 .152997→.054459였지만 보정 clock만 바꾸면 .168459였다. 보정 제거는 저장 prefix에서 좋아졌으나 재귀적으로는 .298989로 악화했다. 입력과 출력은 함께 봐야 한다. 실제 clock을 제공한 수치는 원인 개입이며 배포 가능한 생성 성능이 아니다.

최신 gain은 GMR **성분 평균의 회귀 반응**만 바꿨다. clock에 따른 성분 선택 확률은 그대로였다. 따라서 oracle의 전체 효과를 구현한 실험도, 충분히 유연한 모든 시간 출력이 실패했다는 증거도 아니다. joint의 훈련 목적이 포함 관계인 scalar보다 나빴다는 최적화 문제도 남는다.

### 4.4 최신 비교를 후순위로 미뤘다

자체 head를 여러 차례 고쳤지만 LBDTPP 같은 가까운 최신 생성기의 동일 과제 직접 비교는 실행하지 않았다. 구현 가능성을 검토한 것과 학습/생성 비교를 끝낸 것을 구분해야 한다. **다음 제한된 개발 실험과 최신 비교를 같은 일정에 둔다.**

## 5. 한 가지 모델 후보로 정리

### 목표와 고정 범위

이번 방법 개발은 시간 출력 하나에 한정한다. 고객/길이/사기 전환/업종/금액의 기존 개선본은 비교를 위한 기반으로 고정한다. 시간 변경이 native 재귀 이력과 금액·가맹점에 미치는 간접 영향은 전체 생성으로 확인한다. 사기 발생 구성까지 이번 새 시간 구조가 개선했다고 주장하지 않는다.

다음 후보는 **생성 이력에서 계산한 clock과 다음 간격의 결합 관계를 학습하는 조건부 혼합 시간 출력**이다. 연구 이름·새 이론을 먼저 붙이지 않는다.

입력은 현재 ARGN에서 시간 생성 전에 이용 가능한 context/history `h`, 이미 생성한 현재 사기 라벨과 직전 라벨로 정의한 phase `s`, strict-past clock `c`, 유효 과거 수/valid, 거래 위치 `n`이다. 아직 생성하지 않은 금액·가맹점이나 실제 미래를 입력하지 않는다. 현재 순서를 바꿔야만 얻는 조건은 이번 변경에 섞지 않는다.

출력은 `z=log(1+gap)`의 작은 혼합분포다.

\[
q_\theta(z\mid h,s,c,n,v)=\sum_k \pi_{\theta k}\,\mathcal N(z;\mu_{\theta k},\sigma^2_{\theta k}).
\]

현재 강한 `init_only`의 조건부 분포를 기준 함수로 삼아, **한 작은 잔차 head가 mixture logits·location·log-scale을 함께 조절**하는 후보를 둔다. 잔차0이면 기존 출력으로 정확히 돌아가게 한다. 기존 보정식을 다시 재적합하면서 잔차도 동시에 바꾸지는 않는다. 초기1–5 분포는 첫 대조에서 고정한다. 시간 학습에서 이득이 확인되기 전 backbone/큰 공유 상태/diffusion/탐지기를 새로 붙이지 않는다.

핵심 가설은 “이력을 넣으면 낫다”가 아니다. **성분 평균만 움직이는 보정과, 조건부 분포의 형태까지 조절하는 출력이 실제로 다른 효과를 내는가**다. 이 가설은 아직 검증되지 않았다. 성분 확률/분산 변화가 불필요하면 더 단순한 출력을 선택한다. 최종 구조를 단순화하는 작업은 효과 확인 뒤 별도 변화로 검증한다.

### 학습 방식: 생성된 기준과 출력의 결합을 보존

실제 과거에서의 조건부 likelihood는 유지한다. 다만 rare phase를 더 자주 뽑는 것은 계산 배분이며, 무보정 4phase 균등 목적이 자연분포 likelihood와 같다고 해석하지 않는다. event-weight likelihood와 phase별 점수, importance weighting 여부를 명시한다.

다음 학습의 차이는 생성 이력에서 얻은 `(clock, next-gap)`의 **결합 분포**를 전환 phase·진행 구간별로 실제 학습 자료와 비교하는 데 둔다. 절대 gap과 개인 대비 gap을 따로 맞추는 것만으로 충분한지 대조한다. 구현 후보는 고정한 투영을 사용하는 2차원 sliced-Wasserstein(axes와 상대 차이 방향 포함)이다. 이것을 새로운 거리나 전체 거래열 법칙 일치의 증명으로 부르지 않는다. 투영·구간·가중·허용 비용은 optimization/internal 자료로만 정하고 fit 전 등록한다.

핵심 평가의 고객 가중을 학습과 맞추고, 거래 균등 절대 시간 품질은 별도 보호 조건으로 둔다. 학습은 허용 조건을 명시한 제약 목적/후보 선택으로 운영하며, 합산 손실 이득이 보호 지표의 큰 악화를 정당화하지 못하게 한다. “모든 조건을 정확히 0악화”가 아니라 개발 자료의 표본 변동 및 사전 정한 실질 비용을 기준으로 한다. 제약이 양립하지 않으면 허용 폭을 결과에 맞춰 늘리지 않고 절충 곡선을 보고한다.

생성 과거와 실제 다음 거래를 임의로 일대일 대응시켜 MSE를 최소화하지 않는다. 독립적으로 생성한 거래열의 조건별 분포를 비교한다. 단순히 생성 과거를 섞는 scheduled sampling을 새 해결책으로 주장하지 않는다. 기존 rollout 보정이 실패한 사실을 포함하며, 이번에는 **손실이 제어하는 결합 관계가 다른지**가 검증 대상이다.

시간 재생 학습의 gradient/샘플링/정수화 처리와 native ARGN history 갱신은 구현 시 수치 검증이 필요하다. 미분 가능한 연속 log-gap 학습을 쓰더라도 실제 정수 gap 생성의 평가를 대체하지 않는다. cached 실제 history를 사용한 재생은 완전한 자유 생성 학습이라고 부르지 않는다. native 전체 생성은 반드시 별도 수행한다. 아직 이 후보의 학습이 시작되거나 새 점수가 나온 것은 아니다.

## 6. 다음 실험은 고정된 순서로 제한

### A. 목적 변경과 구조 변경을 분리하는 2×2

다음은 실행 설계이며 완료 결과가 아니다. frozen `init_only`의 재평가를 공통 기준으로 둔다.

| 팔 | 출력 범위 | 학습 목표 | 질문 |
|---|---|---|---|
| A | 기존 제한된 평균 보정 | 기존 목적 | 이전 절차가 재현되는가 |
| B | A와 같은 출력 범위 | 결합 관계·보호 조건을 명시한 목적 | 구조 변경 없이 목적만 바꿔 해결되는가 |
| C | 혼합 확률·평균·분산 잔차 | 기존 목적 | 출력 유연성만의 효과는 무엇인가 |
| D | C와 같은 구조 | B와 같은 목적 | 함께 쓸 때 추가 효과가 있는가 |

A/B, C/D 안에서 초기점·데이터·예산·noise·선택을 같게 한다. A와 C는 용량이 다르므로 이 네 팔만으로 용량과 구조를 완전히 분리했다고 주장하지 않는다. B로 해결되면 그 결과를 강한 단순 기준으로 채택하고 불필요한 D 구조를 주장하지 않는다.

D가 유망할 때에만 일반 history 밀도에도 같은 새 목적을 적용한다. 일반 history+새 목적이 같거나 좋으면 GMR 기준 잔차 구조의 필요성은 기각한다. mean-only / mixture 선택 고정 / clock 입력 제거의 제거 대조는 최종 후보를 고른 후 필요한 것만 실행한다. 여러 실패 후보에 모두 대형 실험을 붙이지 않는다.

첫 비교는 한 부모의 4fit·각2draw로 기능/방향을 확인한다. 이 결과는 screen이다. 유망한 최대2팔과 강한 대조를 3독립 head fit seed·각3draw로 확인한다. head seed와 parent seed는 별도 표기한다. 최종 전체 모델 주장은 부모/기반 모듈의 독립 학습 반복도 포함해야 한다. 실제 시간 예측은 첫 fit의 측정 처리량 이후에 하며 GPU가 비었다는 이유만으로 중복 실행하지 않는다.

### B. 최신 비교는 A와 함께 준비·실행

1. **ARGN/충분히 조정한 CPAR:** 전체 혼합형 거래열 비교. 기존 CPAR128 update 단일 fit은 최적 성능이 아니다. RI/DE/HI4고객의 unseen-context 제외 문제는 모든 모델의 공통143명 표와 전체147명 표를 구분하거나, train-only unknown 처리로 전체 공통 과제를 새로 고정한다.
2. **일반 history-conditioned marked mixture:** 이미 했던 MLP를 충분히 학습하고 동일 목적을 적용한 강한 시간 비교군. IFL-TPP 및 mark-dependent LNM에서 알려진 설정이다.
3. **LBDTPP2026:** 첫 최신 직접 비교. `gap + mark=(label,category)`의 시간/상태 과제를 공통 horizon으로 정의한다. 첫 사건 drop·정답 horizon·자동 test loader 문제를 고친 runner를 따로 기록한다. 학습 없는 코드 점검을 재현 성능으로 쓰지 않는다. 금액·가맹점이 없는 공식 모델을 전체 거래 생성 점수에 그대로 섞지 않는다.
4. **TimeAutoDiff 최신 공개본:** 전체 혼합형 window 비교 후보. 공개 코드는 있다. 고정 window와 timestamp conditioning을 사용하는 모델이므로 정답 시간 조건부 결과와 시간까지 생성하는 결과를 분리한다. 후자의 경우 gap을 생성 feature로 두고 미래 timestamp를 쓰지 않는 적응을 명시한다. 48/200 길이 window 결과를 1024+ 자유 생성 성능으로 해석하지 않는다.
5. **MTDPP / SigTPP:** 각각 marginal과 dependence를 함께 다루는 대조, 경로 분포 학습 대조. 이 연구의 방법 주장에 가까우므로 적어도 하나의 적용 가능한 시간 대조를 포함한다. MTDPP의 정상성 보장을 비정상·다중 phase 거래열에 그대로 적용하지 않는다. SigTPP의 무표식 counting-path 결과를 모든 거래 필드 재현으로 해석하지 않는다.

TabDiT는 중요한 설계 reference로 유지한다. 9월29일 공식 repository tree도 17파일의 평가/생성된 자료 중심이며 Sparkov 새 학습 구현은 확인되지 않았다. 확보한 평가 코드를 학습 코드라고 부르지 않는다. 이를 기다리며 모든 최신 비교를 미루지 않는다. Seq2Synth는 benchmark이지 새로운 생성기 baseline이 아니다.

### C. 확인 실험과 최종 검증

Sparkov 고객 단위 split을 유지한다. 반복 개발에 사용한147고객 결과는 탐색 결과다. optimization619/internal69와 최종 미개봉 test를 구분하며 이 검토에서도 test를 읽지 않았다. 최종 구조·예산·선택 규칙을 고정한 뒤 test에서 한 번 확인한다.

독립 데이터는 **IBM/TabFormer 거래**를 우선 후보로 둔다. CPAR 금융 연구와 TimeAutoDiff가 사용하는 사기 라벨 있는 고객 거래열이라 과제 연속성이 있다. 이것도 합성 데이터이므로 Sparkov와 함께 성공해도 실제 금융 사기 일반화가 입증되는 것은 아니다. Berka에는 사기 라벨을 만들지 않고 개인 시간·금액 관계의 추가 일반화만 평가한다.

## 7. 무엇을 성능과 기여로 판단할 것인가

주 목표는 사기 시작의 개인 대비 시간 관계와 조건별 clock–gap 결합 품질이다. 보호/비용은 전체 정상 시간, 초반/중반/후반, 정상 금액, 개인 대비 사기 금액, 라벨·길이·가맹점 다양성이다. 비율이 같다는 이유로 관계가 보존됐다고 하지 않는다.

고객을 재표집하는 cluster bootstrap, 독립 fit 편차, 동일 고객 지원집합을 사용한다. 2048+는 평균4.75고객 수준이므로 그 구간만의 작은 수치를 주 증거로 삼지 않는다. 2부모×4draw를 8독립 학습으로 취급하지 않는다. real-vs-real 표본 변동을 함께 제시한다.

TSTR은 최종 utility 확인이다. 같은 split/특성·탐지기 예산에서 CatBoost 등 tabular 탐지기와 고정한 sequence 탐지기를 보조 비교할 수 있다. 사기율은 생성한 label 빈도로 직접 계산하고 탐지기가 예측한 비율로 대체하지 않는다. 탐지기 성능 하나가 생성기의 모든 관계를 검증하지 않는다.

아래 세 결과가 나오면, 사소한 비용이 남아도 방법 논문을 구성할 근거가 생긴다.

- 강한 최신/단순 모델에서 같은 목표 관계의 잔여 문제가 확인된다.
- 제안의 특정 요소가 그 관계를 독립 반복에서 개선하며 같은 목적의 일반 head와 제거 대조로 설명이 분리된다.
- 비용과 적용 범위가 명확하고, 미개봉 고객/다른 데이터 조건에서도 핵심 효과가 유지된다.

반대로 목적 정렬만으로 해결되거나 MTDPP/일반 history가 같은 결과를 내면, 그 해결을 우리 신규 구조의 발명으로 쓰지 않는다. 유용한 분석·벤치마크 연구로 구성할 수는 있지만, 방법 기여를 주장하려면 그 비교에서 남는 효과가 필요하다. 한 후보의 실패를 연구 전체 포기와 연결하지도 않는다.

**다음 행동의 우선순위는 새로운 보정 계수 추가가 아니라, 고정한 2×2와 최신 직접 비교다.** 원인을 근거로 좁힌 한 후보를 검증하고, 결과를 본 뒤 다시 목표를 이동시키지 않는다.
