# 2026-09-30 검증 설계와 선행의 관계

현재 실험의 학습·생성·평가 조건은 PROTOCOL.md에 고정했다. 아래 재확인은 조건 변경이나 새 실험 실행이 아니다.

- [Seq2Synth v3, §3–4, Appendix E.1/E.5](https://arxiv.org/html/2607.15606v3): 정적 품질과 시간·거래열 품질을 구분한다. 여러 지표의 순위가 다르다는 점 때문에 이번에도 전체 정상 시간과 개인 사기 시작 시간, 위치별 오류를 따로 보고한다. E.5는 TabDiT의 공개 생성 결과를 직접 사용했다고 명시한다. 이 논문의 TabDiT 비교를 Sparkov용 학습 코드 공개의 증거로 삼지 않는다. 같은 논문의 CPAR/ARGN 결과 역시 현재 Sparkov 재학습을 대신하지 않는다. [공식 프로젝트 페이지](https://seq2synth.github.io/)도 확인했다.
- [MoTPP v1, §4.2–5.1](https://arxiv.org/html/2609.21382v1): 이력 조건부 시간 혼합분포는 선행이며, 실제 과거를 사용하는 계산과 표본화한 연속 생성 평가를 구별한다. 보고된 continuation은 실제 잔여 사건 수를 horizon으로 사용한다. 따라서 동일 Sparkov 자유 생성 과제로 직접 비교하려면 종료/길이 조건부터 맞춰야 한다. 이번 `history_only`는 그 공식 모델 재현이 아니라 고정 ARGN 표현 위의 기존 조건부 혼합분포 대조다.
- [IFL-TPP, ICLR2020](https://arxiv.org/abs/1909.12127): log-normal mixture 시간 출력의 선행이다. 혼합분포나 이력 조건 자체를 본 연구의 신규성으로 주장하지 않는다.

이번에 검증할 차이는 기존 방법의 존재 여부가 아니라, **동일한 생성 환경에서 초기 개인 속도 형성과 위치·속도 보정을 고려한 현재 후보의 효과가 독립 시간 모듈 적합에서도 반복되는가**이다. 그 효과가 일반 이력 모델에 동일 처리를 준 대조로도 설명된다면 GMR 기반 구조만의 고유 이득으로 쓰지 않는다.

최근 전체 생성기의 충분한 적용과 CPAR 검증은 아직 별도 과제다. 이번 결과가 좋더라도 이 항목을 완료했다고 보고하지 않는다. 읽은 범위는 위에 표시한 방법·평가 절과 관련 부록이며, 모든 논문의 모든 부록을 새로 정독했다는 뜻은 아니다.
