# 전체 생성기 비교의 현재 범위

2026-09-30 실행 중인 시간 모듈 검증과 혼동하지 않기 위한 읽기 전용 재점검이다. 이 문서로 CPAR 또는 최신 전체 생성기의 새 학습을 실행한 것은 아니다.

## CPAR

기존 실제 산출물은 인접 checkout의 `research-argn-fraud-audit/artifacts/sparkov_argn_control_v2/runs/cpar_20260928`에 있다. FIT.json은 CPU 5,675.605초, 128 **epochs**를 기록한다. 128 update나 이번 회차의 새 학습이 아니다. 생성 비교 지원 고객은 기존 보고서대로 143명이며, 현재 시간 모듈 비교의 147명과 그대로 섞지 않는다.

저장된 history.csv에서 학습 손실은 epoch 120의 2.995806에서 마지막 127의 2.928601까지 감소했다. 이것은 추가 학습 예산을 검증할 이유이지, 추가 학습하면 생성 성능이 반드시 개선된다는 증거가 아니다. 내부 검증 기반 선택이나 학습 예산 대조가 없는 한 이 실행을 CPAR의 최적 성능이라고 부르지 않는다.

[SDV 공식 문서](https://docs.sdv.dev/sdv/modeling/sequential-synthesizers/parsynthesizer.md)를 다시 확인했다. 128 epochs는 기본값이다. `sample_size=1`, `segment_size=None` 역시 명시된 기본 설정이며, context는 거래열 안에서 변하지 않는 열이어야 한다. 따라서 기존 기본 설정을 사용했다는 이유만으로 실행 자체가 잘못됐다고 말하지 않는다. 문서의 현재 API와 기존 고정 버전의 코드는 별개이므로 재실행 전 버전을 고정해야 한다.

후속 전체 생성기 비교에서는 학습 예산/내부 선택과 함께 고객 지원 범위·길이 생성·정적 조건을 맞춰야 한다. 학습 손실만 보고 모델을 고르거나 실제 미래 길이를 한 모델에만 제공해서는 안 된다. 현재 7개 시간 모듈의 결과는 이 작업을 대신하지 않는다.

## 가까운 최신 방법

- LBDTPP의 기존 Sparkov 적용은 자유 생성 라벨 분포가 제대로 맞지 않았다. 완료된 실행 기록은 보존하되 검증된 강한 최신 비교군으로 사용하지 않는다.
- TabDiT는 기존 코드 검토에서 학습 구현 확보가 미완이었다. 이번에 재확인한 [Seq2Synth Appendix E.5](https://arxiv.org/html/2607.15606v3#A5.SS5)는 공개 TabDiT 생성 결과를 사용한다. 이를 새로운 Sparkov용 TabDiT 재학습 구현의 증거로 삼을 수 없다.
- [MoTPP §4.2–5.1](https://arxiv.org/html/2609.21382v1)은 실제 잔여 길이로 continuation을 평가한다. 현재 비교와 연결하려면 길이·조건·출력 필드 차이를 먼저 명시해야 한다. 이번 일반 이력 혼합분포를 MoTPP 공식 재현으로 이름 붙이지 않는다.

이번 연구 결론은 **현재 후보의 구성 요소와 시간 학습 반복성에 대한 검증**으로 제한한다. 이력이 일반 혼합분포에서도 같은 처리를 통해 개선되는지 확인한 뒤, 전체 생성기 비교는 별도의 고정 프로토콜로 이어가는 것이 다음 작업이다. 최신 모델 대비 우월성은 아직 확인되지 않았다.
