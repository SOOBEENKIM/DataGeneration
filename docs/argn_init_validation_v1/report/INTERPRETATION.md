# init_only 독립 시간 모듈 재학습·제거·강한 대조 검증 완료

완료: 2026-09-30 22:34:58 KST. **초기 처리와 보정의 효과는 반복됐지만, `init_only`의 GMR 구조가 일반 이력 모델보다 두 핵심 목표에서 우수하다는 주장은 이번 결과로 지지되지 않는다.** 같은 초기 처리와 보정을 제공한 이력 모델이 두 핵심 지표에서 더 좋았다. 다만 정상 거래의 개인 대비 속도 관계와 일부 위치 지표에는 별도의 비용이 있다.

## 실제로 실행한 범위

- 시간 학습 난수 3개 × 기존 ARGN 부모 2개 × 생성 난수 2개 × 7팔 = **84회 전체 생성, 16,896,495행**.
- 상태별 GMR/단순 혼합분포/초기 분포 총 27개 적합, 일반 이력망 6개 학습, 보정 9개 적합. 통계 혼합분포와 보정은 모두 각 알고리즘의 종료 조건을 충족했다. 전역 최적해를 보장한다는 뜻은 아니다.
- 이력망은 모두 내부 검증으로 100 step 가중치를 선택하고 700 step에서 조기 종료했다. 200 step 이후 검증 손실이 악화한 학습 곡선을 보존했다. 85,641개 파라미터의 한정된 설정이며, 모든 가능한 이력 모델 설정을 최적화한 것은 아니다.
- ARGN 본체 새 학습 0, CPAR 새 학습 0, 최신 전체 생성기 새 학습 0. 생성 이력을 정답 거래에 붙이는 새 학습도 0.
- 58개 준비·학습·생성 작업 모두 exit 0. 독립 평가가 84개 출력의 지표 420개를 재계산했고 최대 차이는 9.72e-17이었다. 모든 출력의 라벨·길이가 고정 기준과 일치하며, 42개 생성 worker의 native routing/strict-past/배치 재정렬 검증도 통과했다.
- 이전 파일 395개 해시 보존. 활성 모델 `clock_prefix`, 기존 `init_only/current/init_handoff`, 모든 새 가중치와 실패·비용 결과 보존. **모델 자동 교체·commit·push·최종 test 읽기 없음. 실행 중인 작업 없음.**

독립 학습 단위는 시간 모듈 난수 3개다. 통계 head는 부모 2개에서 공유된다. 생성 행 수나 부모·생성 조합 12개를 독립 재학습 표본 수로 세지 않는다. 이 결과는 반복 사용한 development 자료의 강건성 점검이며, 미사용 시험 자료에 대한 확증이 아니다.

## 같은 실험 안에서의 비교

오차는 모두 작을수록 좋다. 각 행은 새 학습 3개와 부모/생성 조합의 평균이다. 과거 2부모×4draw 평균과 섞지 않는다.

### 1. 초기 처리의 목표 효과는 반복됐다. 모든 지표 개선은 아니다.

초기 처리를 넣으면 6–49 오류가 .342188→.084596으로 줄었다. 세 학습 난수 모두, 12개 생성 조합 모두 같은 방향이다. 고객 동일 가중 정상 시간도 .220954→.194743으로 좋아졌다. 1024+ 오류는 .074017로 정확히 같았다.

반면 전체 정상 시간은 .050520→.063958로 12개 생성 모두 악화했다. 100–199 평균도 .080059→.099827로 악화했으며, 이 구간의 방향은 학습 난수마다 달랐다. 초기 처리만으로 사기 시작의 개인 관계가 개선된다는 일관된 결과도 없다. 전체 분포 점수와 위치별 품질을 같은 것으로 취급하면 안 된다.

### 2. 이후 보정도 실제 효과가 있다. 특정 위치의 비용은 남는다.

초기 분포를 유지한 채 보정을 제거하면 전체 정상 시간 .063958→.110182, 100–199 .099827→.550003, 1024+ .074017→.168004로 악화한다. 이 세 지표의 보정 이득은 12개 생성 모두 반복됐다.

그러나 500–1023은 보정을 넣으면서 .069562→.105789로 악화했다. 원래 GMR이나 상태별 단순 혼합분포와 비교한 이 위치의 비용 때문에 등록된 `init_only`의 전체 비용 screen은 통과하지 못했다. 이를 “한계 하나가 있으므로 논문 불가”라는 판정으로 해석하지 않는다. 특정 효과의 범위와 비용을 명확히 해야 한다는 뜻이다.

### 3. 같은 처리를 받은 일반 이력 모델이 핵심 비교를 바꿨다.

`history_init_cal`은 `history_only`와 동일한 신경 가중치를 사용하며, `init_only`와 같은 초기 분포 및 같은 6계수 보정 가족·목적·최대 평가 예산을 제공받았다. 모델 전체 파라미터 수와 적합 알고리즘까지 같은 것은 아니다.

`init_only` 대비 전체 정상 시간은 .063958→.052395, 사기 시작 개인 시간은 .120572→.080343으로 좋아졌다. **두 지표 모두 세 시간 학습 난수의 평균에서 개선**됐다. 부모별로 평균해도 두 부모 모두 개선됐다. 생성 조합별로는 각각 10/12, 11/12에서 개선됐고, 학습 난수×부모 단위에서는 각각 5/6, 6/6이다. 따라서 매 출력에서 무조건 개선됐다고 쓰면 안 된다.

일반 이력 모델에 처리를 제공하기 전후도 정상 .123082→.052395, 사기 시작 개인 .099052→.080343으로 좋아졌다. **보정과 초기 처리를 우리 GMR 후보에만 제공한 비교로는 고유 구조의 우위를 주장할 수 없다는 점이 실제로 드러났다.**

다음 비용을 함께 남긴다.

- 정상 유지의 개인 대비 시간 오류: `init_only` .006468 → 이력+처리 .035996. 12개 생성 모두 악화했다. 이 지표는 고객 동일 가중 분포 오류와 다르다.
- 초기 6–49 평균: .084596→.097851. 후반 1024+ 평균: .074017→.077573.
- 부모 20260930의 1024+ 평균은 .069061→.104726으로 악화했다. 전체 평균의 작은 차이가 이 비용을 가린다. 다른 부모에서는 .078972→.050420으로 개선됐다.
- 개인 대비 사기 금액은 .101970→.105156, 정상 금액은 .063151→.064108로 소폭 악화했다. 평균 가맹점 TV와 다양성 변화는 작았다. 개별 생성의 비용은 ALL_DRAWS.csv에 모두 있다.

정상 유지 개인 시간은 사전에 보고하도록 정한 보조 지표다. 이 결과를 본 뒤 원래 두 주지표를 바꾸어 `init_only`가 승리했다고 재정의하지 않는다. 동시에 두 주지표의 승리만으로 모든 관계가 보존됐다고 해석하지 않는다.

## 이번 결과로 바뀐 연구 판단

1. **초기 개인 속도 형성과 이후 시간 출력의 보정은 검증할 가치가 있는 효과였다.** 제거 실험과 독립 시간 적합에서 목표 위치의 효과가 반복됐다. 여태 보존한 개선이 모두 허상이었던 것은 아니다.
2. **GMR 기반 `init_only`가 일반 이력 모델보다 정상 시간과 사기 시작 개인 시간을 함께 더 잘 보존한다는 주장은 현재 성립하지 않는다.** 동일 처리를 준 이력 모델이 더 강했다. 과거 한 설정의 순위를 고정된 결론으로 삼지 않는다.
3. `init_only`와 `history_init_cal`을 장단점이 다른 검증된 후보로 보존한다. 이력+처리 모델을 강한 비교 기준에 포함하되 활성 모델을 자동 교체하지 않는다. 정상 개인 관계·부모별 후반 비용을 숨기지 않는다.
4. **다음 제한된 검증은 이력 모델에서 초기 처리만/보정만을 분리하는 제거 대조다.** 현재 이력 대조는 둘을 함께 받았기 때문에 어느 요소가 핵심 두 지표의 이득과 정상 개인 관계 비용을 만드는지 아직 분리되지 않았다. 같은 가중치와 예산을 고정하고 이 구분을 먼저 해야 한다. 이 추가 대조는 이번 회차에 실행하지 않았다.
5. 가까운 전체 생성기와 충분히 적용한 CPAR 비교는 별도 고정 프로토콜로 이어가야 한다. 생성 이력 학습이나 또 다른 보정식을 지금 결과와 섞지 않는다. 그 학습은 정합한 prefix/조건/목표 정의가 갖춰진 별도 실험으로 남긴다.

이 단계는 GMR 고유 구조의 신규성 확정도, 최신 모델 대비 우월성 확정도 아니다. **어떤 처리가 반복되는 효과를 만들고, 그 효과가 어느 생성기에서도 설명되는지를 더 정확히 좁힌 검증 결과**다. 선행과의 중복 및 전체 생성기 적용 범위는 LITERATURE_CHECK.md와 WHOLE_GENERATOR_COMPARISON_STATUS.md에 명시했다.

## 표본과 해석 제한

학습의 사기 시작 433건, 내부 선택의 사기 시작 48건이다. 최종 개인 onset 지표의 실제 지원은 102건/102명, 생성 지원은 draw에 따라 104–111건/102–110명이며 모든 비교군에 동일하다. 동일 고객·동일 위치의 실제 사기 사건을 예측한 정확도가 아니라 **각 모집단에서 사기 시작 시 개인 대비 간격 분포를 보존한 정도**다. 표본을 생성 행 수만큼 늘려 유의성을 주장하지 않는다.
