# 이번 독립 재학습에서 고정한 것과 바꾼 것

등록 프로토콜과 실행 소스를 설명하는 보충 문서다. 결과를 보고 학습 조건이나 채택 기준을 변경하지 않는다.

## 검증하는 모델

현재 `init_only`는 기존 ARGN 기반 거래 생성기의 **거래간격 출력 모듈**이다. ARGN 본체나 CS-SAF 전체를 새로 학습하는 실험이 아니다. 고객/길이/사기 상태 생성과 기존 업종·금액 출력은 고정하고, 시간 모듈만 다시 적합한다. 생성된 시간이 이후 입력에 들어가므로 시간 외 값까지 정확히 같다고 가정하지 않고 실제 비용도 평가한다.

시간 모듈은 다음 순서로 작동한다.

1. 직전/현재 사기 라벨로 정상 유지·사기 시작·정상 복귀·사기 지속을 구분한다. 현재 라벨은 생성 과정에서 앞서 뽑은 값이다.
2. 현재 거래를 제외한 최근 최대 20개 거래간격의 중앙값으로 개인 속도를 계산한다. 사용 가능한 과거 간격이 5개 미만이면 학습 자료의 고정 대체값을 사용한다.
3. GMR은 상태와 개인 속도를 조건으로 다음 `log1p(거래간격)`의 3성분 혼합분포를 계산한다. 이것은 알려진 Gaussian mixture regression이다.
4. 정상 유지 상태에서는 거래 위치와 개인 속도에 따른 6계수 위치 보정을 더한다. 거래 위치 기준점은 25/350/2500이고, 보정량은 ±0.35로 제한한다.
5. 정상 유지 상태의 첫 다섯 간격은 별도로 학습한 초기 간격 혼합분포로 출력한다. 첫 거래 자체에는 이전 거래와의 간격이 없으므로 기존 처리를 유지한다.
6. 실제 생성에서는 방금 생성한 간격을 과거 기억에 넣고 다음 거래를 생성한다. 평가할 때 실제 과거 속도를 대신 주지 않는다.

초기 출력과 보정은 과거에 이미 만들어 둔 구조다. 이번에는 이 구조가 독립 적합에서도 유지되는지 확인한다. 시간마다 다른 공식을 추가하는 개발 실험이 아니다.

## 비교군이 구분하는 설명

| 비교 | 검증하는 내용 |
|---|---|
| `init_only` 대 `no_initial` | 초기 다섯 간격을 따로 학습한 효과가 이후 개인 속도 형성에도 남는가 |
| `init_only` 대 `no_calibration` | 초기 분포만으로 충분한가, 이후 위치·속도 보정의 효과가 필요한가 |
| `init_only` 대 `gmr` | 기존 GMR에 초기 처리와 보정을 더한 실제 이득과 비용은 무엇인가 |
| `init_only` 대 `phase_gmm` | 개인 속도를 쓰지 않는 상태별 시간 분포만으로도 같은 목표를 달성하는가 |
| `init_only` 대 `history_only` | 일반 이력 조건부 혼합분포보다 목표 관계가 잘 보존되는가 |
| `init_only` 대 `history_init_cal` | 일반 이력 모델에도 같은 초기 처리와 같은 보정 목적·계수 수·최대 평가 예산을 주어도 차이가 남는가 |

`history_only`는 1,322차원 입력을 받는다. 이는 정적 조건 256 + 과거 LSTM 표현 832 + 이미 사용 가능한 현재 열 조건 234이다. 모두를 과거 정보라고 부르면 부정확하다. 이 모델은 알려진 조건부 혼합분포를 고정 ARGN에 적용한 대조이며, MoTPP 공식 재현이나 최신 전체 생성기 자체가 아니다.

보정 가족·초기 분포·목적·예산은 맞췄지만 GMR과 신경 이력 모델의 파라미터 수나 적합 알고리즘까지 같은 것은 아니다. 이 비교를 동등한 전체 모델 용량 실험이라고 하지 않는다.

## 학습과 생성의 범위

- 시간 모듈 적합 난수 3개. GMR·초기 분포·보정은 매번 새로 적합하며, 이력망은 기존 부모 2개 각각에서 새로 학습한다.
- GMR 계열 시간 모듈은 부모 2개에 공유된다. 따라서 부모/생성 난수 조합 12개를 독립 학습 12회라고 세지 않는다.
- 이력망은 실제 과거와 실제 다음 간격을 짝지어 우도 학습한다. 보정도 실제 과거를 조건으로 뽑은 간격을 사용한다. 자유 생성에서는 자체 생성 과거를 사용한다.
- 생성 이력에 임의의 실제 다음 거래를 정답으로 붙이는 학습은 이번에 하지 않는다. 학습/생성 입력 차이를 해결했다고 주장하지도 않는다.
- 내부 검증은 체크포인트를 고르는 데 사용한다. 개발 자료 147명은 전체 생성 평가에 쓰지만, 이미 반복 사용한 자료이므로 미개봉 시험 자료에 대한 일반화 검증이 아니다.

## 해석의 경계

독립 적합·제거 실험은 효과의 반복성과 구성 요소의 필요성을 확인한다. 그것만으로 새로운 이론이나 최신 전체 생성기 대비 우월성이 입증되지는 않는다. CPAR의 충분한 적용, 가까운 최신 생성기의 정상 작동 확인, 다른 자료와 미사용 시험 자료의 검증은 별도로 남는다.

정상 시간, 사기 시작 시 개인 대비 시간, 위치별 시간, 금액·가맹점 비용을 함께 보고한다. 특정 지표 하나가 악화됐다는 이유만으로 논문이 불가능하다고 결론 내리지 않으며, 반대로 평균 하나의 개선으로 모든 관계가 보존됐다고 결론 내리지 않는다.
