# 평가 범위와 지표 해석

이 연구는 생성 모델을 평가한다. `event_is_fraud`는 원본의 관측 라벨을
다른 거래 필드와 함께 학습하고 생성하는 열이다. 별도 사기 탐지기의 예측을
생성 라벨로 덮어쓰거나, 정상·사기 비율을 사후에 맞추지 않는다.

- 고객 이력: 직전 거래의 category/label, 해당 고객에게 이미 등장한 가맹점인지,
  직전 최대 20회 거래의 금액 중앙값과 현재 금액의 비율을 사용한다. 중앙값은
  최소 5개 과거 거래가 있을 때만 계산하며 현재/미래 거래를 포함하지 않는다.
  이것은 전체 이력의 모든 의미를 검증했다는 뜻은 아니다.
- 시간: 첫 거래를 제외한 거래간격(초)을 평가한다. 절대 시각, 요일, 위치는
  이번 모델 필드에 없으므로 그 관계를 보존했다는 주장은 하지 않는다.
  `positive_gap_le_5s`는 정확히 0<gap<=5초다. 같은 시각의 gap=0 거래는
  train 12건/validation 2건(모두 정상)이며 gap 분포와 `gap_bin=0` 집계에
  포함된다. 첫 거래의 간격 없음(`gap_bin=-1`)과 구별한다.
- 금액: 원단위 평균/중앙값/p90/p99, KS 거리, Wasserstein 거리, log1p 거리와
  학습 자료에서 고정한 분위 구간을 함께 사용한다. KS 검정의 IID p값은 사용하지 않는다.
- 가맹점: 개별 가맹점 빈도와 merchant/category 결합분포, 고객별 재방문을 평가한다.
  사기 표본만 나눈 merchant 지표는 희소하므로 실제 학습 고객 재표집 오차와
  함께 해석한다. 가맹점 ID를 숫자 크기의 관계로 모델링하지 않는다.
- 라벨: 전체 비율, 직전 정상/사기 조건부 비율, 간격/재방문/금액 이력 조건부
  비율, 사기 거래 내부의 관계를 따로 본다. 사기 시작(onset)과 지속도 구분한다.
- `class_*_gap_category_amount_history_tv`는 간격 구간, category, 금액 구간,
  재방문, 개인별 금액비 구간의 결합 TV다. 이 고차원 지표와 라벨별 merchant
  지표는 원단위 금액 문제가 발견된 후 평가 보완으로 추가했다. 희소성이 크며
  고객 ID별 원본 거래의 일대일 복제를 요구하는 지표가 아니다.

TV는 두 이산분포 차이의 절댓값 합을 2로 나눈 값(0~1)이다. 큰 값은 차이가
크다는 뜻이지만 유한 표본·고차원 희소성도 값을 키운다. 학습 고객 147명을
복원추출하는 12회 비교는 표본/분할 차이의 참고 범위이며, 이 범위가 이론적
최저 오차나 유의성 기준은 아니다. 실제 고객을 재사용하므로 개인정보보호
성과로 해석하지 않는다.

조건부 비율의 95% 구간은 고객 전체를 500회 재표집한 백분위 구간이다.
한 생성 결과 내부의 고객 변동을 나타내며 독립 학습 반복의 불확실성을
대신하지 않는다. 고객 10명 미만 또는 사기 20건 미만 조건은 근거가 약한
기술통계로 표시한다. 특히 개발 검증 자료의 5초 이내 조건은 45건 중 사기 1건이다.

전처리 roundtrip은 원본 값을 encode→decode하여 모델 학습 전의 손실을
분리한다. 생성 모델이 원본 행을 그대로 복제해야 한다는 실험이 아니다.
구간화가 어떤 정보를 학습 전에 지우는지, 라벨과의 관계를 바꾸는지 확인한다.
원본 값이 잘 복원되는 설정도 학습 후 생성 품질이 좋아진다고 보장하지 않는다.
