# 시간 출력 반영 강도 대조: 학습·내부 검증 완료, 전체 생성 대기

2026-09-28. 이 문서는 GPU 전체 생성 전의 결과다. 네 가지 계수 적합과 내부 검증은 완료됐지만 새 native 전체 생성은 아직 0회다. 전체 생성 후의 `RESULTS.md`, `MODEL_DECISION.json`과 구분한다.

## 이번에 실제로 한 일

- init_only의 초기 출력, GMR mixture, 기존 보정과 native ARGN 가중치를 동결했다.
- 정상 유지의 중반 위치에서 GMR 성분 평균의 개인 속도 반영 강도와 기존 보정 강도를 조절했다. clock 입력 자체, mixture 선택 확률, 분산은 같은 입력에서 유지된다. 따라서 실제 clock을 대입한 지난 oracle 진단 전체를 재현하는 변경은 아니다.
- correction_gain, regression_gain, joint_gain, 같은 2계수의 output_gain_shift를 같은 학습 목적과 최대 예산으로 비교했다.
- optimization 619고객, 815,664개 관측 간격, 최대 3,106거래의 자기 생성 이력을 사용했다. 네 적합 모두 Powell 종료 조건을 만족했다. 목적 평가 호출은 31/17/59/58회, 총165회이며 중복 계수의 캐시 호출도 포함한다. 전역 최적해 보장은 없다.
- 내부69고객×2noise에서 기준+4후보의 시간 재생10회를 마쳤다. 이 단계는 실제 라벨·길이를 고정한 시간 출력 진단이며, 전체 native 거래 생성의 성능이 아니다. 내부 검증으로 모델을 고르거나 계수를 다시 조정하지 않았다.

## 학습 점수가 좋아져도 중반이 나빠진 이유

`training_objective_terms.csv`는 등록된 목적값을 독립적으로 항별 분해해 정확히 재현한다. 보정 강도만 조절한 경우 훈련 목적은 .142270→.137330으로 낮아졌지만, 100–199 간격 오류는 .212056→.316785로 커졌다. 세분화한 중반 손실의 가중 기여는 .032349→.045589로 악화했지만, 전체 정상·후반·clock 항의 이득이 이를 상쇄했다. 개인 관계 hinge는 그 경우 활성화되지 않았다.

따라서 이번 훈련 목적의 최저값이 곧 중반 목표 개선이라는 뜻은 아니다. 이것은 다른 구간의 개선과 목표 구간 악화가 목적함수 안에서 교환되는 관측이다. 간격 출력 자체의 기여나 안정성을 입증한 결과가 아니다.

joint의 선택된 훈련 목적은 단일 보정 대조보다도 약간 나빴다. joint는 단일 대조를 포함하는 함수 집합임을 수치 검증했으므로, 이 차이는 표현력의 한계를 증명하지 않는다. 제한된 Powell 탐색의 선택 결과다. 이번 결과로 결합 구조가 원천적으로 불필요하다고 결론내리거나, 반대로 결합의 추가 효과를 주장하지 않는다.

## 보존·진행 상태

`POST_FIT_AUDIT.json`: 기존 head tensor 정확 보존, 이전350개 artifact SHA256 일치, NumPy/Torch 최대 오차1.78e-15, identity 재생 일치, 중반 개인 지표의 독립 SciPy 검산 통과. 원형 ARGN 새 학습0회, 모델 교체/commit/push0회, 최종 test 미사용.

전체 생성은 등록대로4팔×2기존 부모×4draw=32회를 예약했다. 2026-09-28 23:38 KST 확인 시점에 GPU0–3 모두 외부 작업이 사용 중이어서 아직 시작하지 않았다. `PIPELINE_STATUS.json`, `STATUS.json`이 실시간 상태다. `continue_pipeline.py`가 빈 GPU를 확인하는 dispatcher와 독립 evaluator를 차례로 실행한다. 대기 중 임의로 기존 모델을 교체하지 않는다.

기존 개선의 유지 여부와 이번 후보의 최종 판단은 전체 생성 평가 후 별도로 기록한다. 다음 학습을 새로 한다면, 먼저 목표 구간 악화를 전체 이득으로 상쇄하도록 허용하는 목적과 GMR의 성분 평균/mixture 반응을 구분해야 한다. 이번 결과를 보고 가중치·경계·판정 기준을 바꿔 같은 실험의 성공으로 보고하지 않는다.

## 선행과 주장의 범위

[F-LLM2026 §4–5](https://arxiv.org/html/2602.12756v1)의 입력 민감도·feedback 관점을 참고했지만 observer나 Lipschitz 제약을 구현한 것은 아니다. 그 논문의 수축 가정을 확인하지 않았으며 안정성 보장은 주장하지 않는다. [Calinon2016 §5.1 식14–16](https://publications.idiap.ch/downloads/papers/2016/Calinon_JIST_2015.pdf)에 따라 GMR 성분 평균과 mixture 확률의 반응은 구별했다. 이 알려진 조절 자체를 새 기여로 주장하지 않는다. 이전 진단과 이번 실험을 원형 ARGN의 일반적 한계로 확대하지 않는다.
