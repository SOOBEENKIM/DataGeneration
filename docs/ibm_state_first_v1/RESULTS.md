## 3. 판정

- **M1 기각(두 backbone 모두).** 학습 상태 과정은 24h 구간 수를 줄이지만(ARGN 10.6→10.8 변화 없음, RTF 4.74→2.55 절반) 지속률(0.60→1.72 /
  0.38→1.60)과 고객당 구간 수(3.17→5.13 / 1.93→3.34)를 **악화**시켜 "둘 다 절반·다른 축 1.5배 이내" 기준에 못 미친다. 효용은 동일
  (.132 vs .142, .455 vs .448). teacher-forced log-loss가 같은데 자유 생성 배분이 나빠지는 이유: 분류기가 since_last_fraud·position에 의존
  (중요도 .58/.57)하는데 자유 생성에서 그 특징은 생성된 라벨에 좌우돼 전이표의 (직전 라벨, 나이) 조건보다 노출 편향에 약하다.
  → **상태 과정은 저차원 전이표로 충분하며, 더 많은 이력 특징은 자유 생성에서 득이 없다.**
- **M2 기각(기준 미달, 방향은 긍정).** 2-상태 head는 사기 온라인 비율 1.52→0.50, 구간 시간폭 5.08→2.12로 개선하지만 사기 간격 W1
  2.32→2.18(기준 ≤ 1.5 미달), 효용 +.003(기준 +.03 미달). → **출력 분리는 라벨 2값으로 충분.** 진입 head는 val 사기 진입 행 39개로 얇아
  gap은 epoch 1이 최적(학습 안 됨)이었음을 기록.
- **M3 미달.** ARGN 최선 .148 < .20. RTF `rtf_learned` .455 ≥ .45는 충족하나 M1이 기각이므로 "원리의 일반화"로 쓰지 않는다.
- **M4 충족.** 모든 팔 표준 지표 변화 ≤ .01, 정상 행 출력 동일.

## 4. 결정

State-First 원리의 **최소 인스턴스(전이표 + 라벨 2값 라우팅 head)가 시험한 일반화 둘보다 낫거나 같다.** 더 복잡한 상태 과정과 더 세분된
라우팅은 효용을 올리지 못했고 배분 축을 일부 나쁘게 했다. 제안 모델은 최소 인스턴스로 고정하고, 이 단계는 **ablation**("단순한 형태로
충분")으로 보고한다. 모델 주장은 "State-First Generator = 동결 backbone + 전이표 상태 과정 + 라벨 라우팅 사기 전용 출력층"이며, 논문
형식은 문제(A) → 평가(B) → 모델(C) → baseline 비교 → ablation.
