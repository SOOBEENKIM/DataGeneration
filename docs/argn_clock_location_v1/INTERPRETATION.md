# 실행 결과: 개인 관계를 보존한 시간 위치 보정과 남은 비용

**기존 GMR에 실제 과거로 학습한 위치 보정을 더한 `clock_prefix`가 이번의
가장 균형 잡힌 후보다. GMR 대비 정상 시간·사기 시작 개인 관계·정상 개인 관계를
두 부모 모두 개선했다. 다만 한 부모에서 일반 history 밀도보다 정상 시간 오류가
높고 후반 구간 비용도 남아, 등록한 전체 채택 기준을 통과했다고 하지 않는다.**

## 완료한 작업

ARGN 기반 거래 생성기의 시간 출력 하나를 바꿨다. 전환별 진행 GMM4개와
두 계수 보정4개를 적합하고,5팔×2개 기존 부모×4개 GPU 생성 seed의
**40개 새 전체 거래열,7,908,780행**을 만들었다. 부모마다 새로 학습한40개
ARGN이 아니며 새 통계 head들은 부모 간에 공유한다.

기존4개 비교군을 포함한72개 matched GPU 결과를 직접 비교했고 이전 다른
비교까지96개 결과를 보존했다. 모든 새 출력의 고객 길이와 전체 정상/사기 순서는
대응 고정 기준과 정확히 같았다. 세 수치/상태 단위검증,10개 실제 native routing,
checkpoint/첫 gap/배치 축소·재정렬/원본 head 보존 및 raw 지표 독립 검산을 통과했다.
모든 이번 GPU worker는 종료했다. 최종 test는 읽지 않았다.

| 기존 GMR + 반복 생성 위치 학습 | .12558 | .09700 | .10302 | .00600 | .28162 |

`clock_prefix`는 기존 GMR 대비 정상 오류 약39%, onset 개인 오류 약17%,
정상 개인 오류 약45%를 낮췄다. 전체 사기 gap도 두 부모 각각에서 줄었다.
기존 GMR의 조건부 성분 가중치/개인 clock 회귀/분산을 바꾸지 않고 정상→정상
시간 위치만 `a+b*exp(-event_index/50)`로 보정했다. 자유 생성에서는 생성한
과거로 clock을 갱신한다. 실제 과거를 생성 시점에 제공해서 얻은 점수가 아니다.

그러나 개인 대비 사기 금액은 .10459→.11037로 소폭 악화했다. 정상 금액 평균은
.06181→.06157이며 부모별로는 증가/감소가 다르다. merchant 다양성 평균은
538.25→538.375다. 이 비용들은 등록한 보존 범위 안이다. label 순서가 같으므로
사기율이나 고객별 사기 발생 구성의 개선을 이번 효과로 주장하지 않는다.

일반 history보다 정상 오류 평균은 낮지만, 부모20261001에서는 history .07302,
clock_prefix .08587이다. 다른 부모에서는 .11300→.08207이다. 따라서 '두 부모
각각에서 history보다 정상 오류도 낮다'는 등록 조건은 한 부모에서 실패했다.
두 부모 모두 채택 screen을 통과했다고 평균으로 덮지 않는다.

## 구별 실험에서 배운 점

1. 진행 시점 입력으로 GMM 전체를 다시 적합하면 정상 개인 관계/사기 gap 비용이
   늘었다. 실제 과거 조건 진단에서도 비용이 있어 반복 생성만의 문제는 아니다.
2. 기존 GMR의 조건부 법칙을 유지하고 작은 위치 변화만 학습하면 GMR이 얻은
   개인 관계를 유지하면서 정상 주변 시간까지 개선할 수 있었다.
3. 이번 설정의 반복 생성 학습은 실제 과거 학습보다 추가적인 정상 시간 이득을
   주지 못했다. 더 복잡한 학습이 더 낫다는 가설은 지지되지 않는다. 일부 fit은
   고정48평가 예산을 소진했으므로 충분히 최적화한 모든 rollout 방법의 실패로
   확대하지 않는다.

## 남은 오류 위치까지 확인

같은 장기 고객 집합에서 초반6–49 gap 중앙값은 실제25675초, GMR15399초,
clock_prefix29116초다. 500–999에서는 실제15958초, GMR15222초,
clock_prefix18107초다. 평균 clock의 초반 대비 변화는 실제−.422,
GMR약0, clock_prefix−.388이다. 변화 방향을 회복했지만 수준은 다소 높다.

추가 matched-position 사후 진단에서 정상 gap W1은 다음과 같다. 이 표는
전체 주변분포 표와 다른, 같은 위치 지원집합의 조건부 평가다.

| 거래 index | GMR | clock_prefix | history |
|---|---:|---:|---:|
| 6–49 | .84338 | .23605 | .42738 |
| 50–199 | .61709 | .19120 | .32668 |
| 500–1023 | .06690 | .12863 | .07195 |
| 1024–2047 | .16288 | .32141 | .08875 |
| 2048 이후 | .46379 | .60394 | .24065 |

**전체 평균이 좋아진 것이 모든 진행 구간이 좋아졌다는 뜻은 아니다.** 초반 개선과
후반 비용이 함께 있다. 보정은 처음1024거래만으로 학습했고, 장기 고객 구성과
속도 수준도 영향을 줄 수 있다. 이 기술 진단만으로 학습 길이 하나가 유일한
원인이라고 확정하지 않는다. 구간별 고객 구성도 달라질 수 있다.

## 결정과 다음 개발 범위

원래 고정 후보와 GMR을 보존하고 `clock_prefix`를 **개선 효과가 확인된 후속
후보**로 남긴다. 전체 등록 screen의 완전 통과나 최종 모델 교체는 하지 않는다.
진행 GMM 재적합과 현재 반복 생성 보정은 선택하지 않는다.

다음 구별 대상은 기존 GMR의 개인 조건부 법칙을 유지한 채 **초반 개선을 보존하고
후반 시간 수준의 과도한 증가를 줄이는 보정**이다. 먼저 같은 두 계수/같은 목적에서
처음1024거래와 전체 학습 거래를 사용한 차이를 구분해야 한다. 그 후에도 남으면
진행 시점의 보정 형태와 고객별 속도 구성의 영향을 따로 비교한다. 현재 보정의
상수항 때문에 후반까지 같은 수준 변화가 남는다는 구현 사실과, 그것이 통계적
오류의 유일한 원인이라는 주장은 구분한다. 추가 full-length 적합은 이번에 실행하지 않았다.

GMR/진행 조건/분포 보정은 알려진 방법이다. 이번에 확보한 것은 더 좋은 균형의
출력 후보와, 전체 평균 개선 속에 가려지는 초반·후반의 충돌을 분리한 근거다.
새 기여가 확정됐다고 하지 않는다. 가까운 최신 전체 생성기의 같은 과제 비교,
독립 추가 학습과 다른 데이터/최종 test 검증은 계속 남아 있다.
