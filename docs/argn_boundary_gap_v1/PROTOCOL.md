# 하나의 변경: 사기 구간 경계의 간격 출력 — 2026-09-27

## 관측과 가설

고정 최종 후보의 development 147고객에서 실제 과거/현재 label/category를
줘도 onset gap W1 1.221, 정상 복귀 gap 1.383이다(2부모×4조건부 draw).
전체 사기 gap 0.137만 보면 놓치는 조건부 오류다. 정상 금액 전체 비용은
주로 일반 정상 거래에 남으므로 이것을 경계 간격 수정으로 해결한다고 가정하지 않는다.

가설: 정상/사기별 균형 학습에서도 드문 **전환 조건 내부**의 학습 부족이 남는다.
기존 gap head를 경계 거래에 맞춰 학습하는 최소 변경으로 해결되는지 확인한다.
이 실험은 공유 상태 구조를 구현하거나 새 구조의 기여를 선언하는 단계가 아니다.

## 선행과 구별

- [Waghmare et al., CIKM 2022, 최신 원고 v2 §3.2 식5](https://arxiv.org/html/2210.15294v2):
  과거/현재 mark 조건의 간격 분포는 이미 선행한다. ARGN도 이미 현재 label/category를
  gap에 입력한다. label을 처음 추가하는 것이 아니며 새 TPP 분해라는 주장도 하지 않는다.
- [LBDTPP 2026 §IV-A 식23–25](https://arxiv.org/html/2606.24982v1):
  시간과 mark를 latent에 함께 표현하고 시간 MSE/mark CE로 복원한다. 블록 생성의
  문제와 우리가 실제 과거에서도 관측한 경계 출력 오류는 구분한다. 아직 직접
  실행하지 않은 LBDTPP가 같은 오류를 보인다고 주장하지 않는다.
- [OmegaSDS 2026 §2 식2](https://arxiv.org/html/2605.06315v1):
  상태/출력 결합 자체는 선행한다. 이 작은 출력 대조를 먼저 통과하지 못하면
  더 복잡한 공유 상태 학습을 원인 해결책으로 가정하지 않는다.

## 고정 조건과 대조

부모 seed 20260930/20261001, 기존 최종 onset_fit을 공통 기준으로 둔다.
라벨·길이·가맹점·금액·기존 gap head·encoder를 모두 동결한다. 단, 바뀐 gap이
이후 이력과 금액 입력을 바꿀 수 있으므로 자유 생성의 비용을 측정한다.

새 head는 동일 gap regressor/predictor를 복제하고 동일 초기값/용량으로 시작한다.
두 팔 모두 현재 생성 label과 직전 생성 label이 다른 위치(첫 거래 제외)에서만
새 gap head를 사용한다. 추가 head 초기화가 native RNG를 바꾸지 않도록 복구한다.

| 팔 | 학습 자료 | 생성 시 적용 |
|---|---|---|
| frozen | 추가 학습 없음 | 현재 최종 모델 |
| all_label_fit | 전체 후속 거래, 현재 label별 50:50 | 두 label 전환에서만 |
| boundary_fit | 정상→사기/사기→정상 각50:50 | 같은 두 전환에서만 |

두 학습 팔은 AdamW lr1e-4, decay1e-3, batch256, 최대1000step,
50step마다 내부 validation 경계별 평균 NLL의 평균으로 선택한다. step0 후보 포함,
patience5, min_delta1e-5, gradient norm1. 같은 선택 기준을 적용하며 development로
checkpoint/학습량을 선택하지 않는다. 두 부모×두 팔 = 작은 head4학습이다.

생성 seed 20261011/12를 공통 적용해 8개 전체 거래열을 생성한다. 기준은 이미
보존된 같은 seed의 최종 onset_fit 4개다. 금액과 간격의 teacher 진단을 자유 생성
성능과 구분한다. native model에서 첫 거래/양방향 전환/지속/축소 및 순서변경
batch의 실제 routing logits를 검증하고, 자유 생성의 전체 label열/고객 길이가
대응 기준과 정확히 같은지 확인한다.

## 판단 조건

주지표는 시작/복귀 gap log-W1의 평균, 두 항목 각각과 부모별 결과도 보고한다.
동일용량 all_label_fit보다 boundary_fit이 나은지 확인한다. 전체 사기/정상 gap,
개인 대비 사기 금액, 정상 금액, 업종·가맹점·다양성·run span의 비용을 함께 보고한다.
단순한 전체 사기 gap W1만으로는 경계와 지속의 반대 오차가 상쇄될 수 있다.

탐색 채택 조건은 두 부모에서 경계 평균 W1 감소, 최종 기준 대비 개인 대비
사기 금액 W1 증가≤0.02, 정상 금액/정상 gap W1 증가≤0.02, 전체 사기 gap W1
증가≤0.05, 정상 merchant TV 증가≤0.02, 고객당 merchant 다양성 감소≤5%다.
이는 탐색 screening이며 통계적 비열등성/허용 가능한 운영 비용의 증명이 아니다.
통과 시 새 생성 seed20261021/22의 확인을 별도 등록하고, 실패 시 기준을 유지한다.
전체 사기 gap 비용이 생기면 구간별 오차 상쇄를 먼저 분석하고 기준을 소급 수정하지 않는다.

기여 후보는 경계 관계 보존이며, 같은 현상이 최신 직접 비교군에도 남는지와
단순 phase 조건 분포로 설명되지 않는 추가 이득은 후속 검증 사항이다.
최종 test는 열지 않는다. 원본/실패/비용을 모두 보존한다.
