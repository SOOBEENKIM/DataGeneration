# 원문·실제 구현 대조에 따른 연구 판단 — 2026-10-01

사용자 요청: 근거 없이 다음 수정을 반복하지 말고, 선행논문이 어떤 문제를 어떤 구조·학습으로 해결하고 무엇을 기여로 입증했는지 공부해 현재 연구 판단을 정리한다.

이번 작업은 문헌·코드 검토다. 새 학습·생성·GPU 실험·test 조회·commit·push·모델 교체는 없다. 이전 결과를 새 성능처럼 보고하지 않는다. 활성 checkout의 AGENTS.md와 RESEARCH_DECISIONS.md를 읽고 최신 완료 보고서를 우선했다. 아래 판단은 기존 프로토콜을 소급 변경하지 않는다.

## 1. 바로잡을 판단

**작은 출력 변경이나 알려진 구성 요소의 결합이라는 이유만으로 논문 기여가 불가능한 것은 아니다.** 문제의 중요성, 가장 가까운 기존 방법과의 구체적 차이, 반복되는 효과와 비용, 필요한 요소를 분리하는 근거로 판단해야 한다. 반대로 원문에 평가가 없다는 이유만으로 선행 모델이 실패했다고 단정할 수도 없다.

**history_calibration_only는 외부 논문에서 완성된 형태로 가져온 baseline이 아니다.** 알려진 조건부 혼합분포를 ARGN에 연결한 이력 모델에, 이 연구에서 개발해 온 위치·개인 속도 보정을 옮긴 대조다. 따라서 그 모델이 GMR 기반 init_only보다 좋다는 결과는 GMR/초기 처리의 필수성을 약화하지만, 보정 방법의 효과까지 기각하지 않는다. 구현의 출처와 방법의 학술적 신규성은 별개다. 우리 코드라는 이유로 보정 자체가 새로운 발명이라고 주장하지 않는다.

## 3. 현재 모형을 논문 단위로 정확히 기술하기

현재 검토할 후보는 새로운 거대 생성기가 아니라 **ARGN 기반 생성기 위의 시간 출력 보정 방법**이다. 이것은 기존 코드의 기술이며 새로 학습한 구조가 아니다.

1. ARGN과 기존 희귀 상태/업종/금액 처리를 유지한다.
2. 알려진 이력 조건부 시간 혼합분포가 다음 log1p(간격)의 가중치·위치·척도를 출력한다.
3. 정상 유지 상태에 한해, 과거 거래 수와 strict-past 최근 20간격 중앙값으로 계산한 6계수 보정량을 모든 혼합성분 위치에 더한다. 범위는 ±0.35다. 가중치와 척도는 그대로다.
4. 보정된 시간은 실제 생성기의 다음 입력으로 돌아간다. 생성할 때 원본 과거 시간을 제공하지 않는다.

식으로는 정상 유지 상태에서 `mu'_k = mu_k + clip(b(n, s)^T theta, -0.35, 0.35)`다. `n`은 현재까지의 거래 수, `s`는 생성된 strict-past 속도다. 사기 시작/지속/복귀의 조건부 시간 법칙을 직접 보정하는 식은 아니다. `history_only`의 base 1322차원에는 정적 256, 과거 LSTM 832, 현재 사용 가능한 열 234가 들어간다.

학습도 구분해야 한다. 이력망은 실제 prefix–실제 다음 간격의 우도로 학습한다. 보정은 실제 prefix에서 뽑은 조건부 간격을 사용해 고객 가중 및 위치 구간별 분포 손실을 최소화한다. **완전한 자유 생성 이력을 미분하며 공동 학습한 방법이 아니다.** 그 과정의 onset/fraud 조건부 손실은 보정 파라미터에 대해 상수이므로, 자유 생성 onset 이득은 직접 최적화의 증거가 아니다. 생성 과거·분모·표현 변화가 함께 영향을 줄 수 있다.

## 4. 지금 남는 주장과 폐기할 주장

**남는 관측:** 같은 이력 모델에서 보정 없음→우리 보정으로 전체 정상 시간 0.123082→0.052605, 개인 대비 사기 시작 시간 0.099052→0.079223. 기존 시간 학습 시드 3개 평균 모두 같은 방향이다. 이는 직전 완료 연구의 결과이며 이번 새 결과가 아니다.

**동시에 남는 비용:** 정상 유지의 개인 대비 시간은 0.033969→0.036049, 기존 GMR init_only는 0.006468. 한 부모의 후반 오류도 GMR보다 크다. 보정만 모델은 기존 등록 screen에서 초반 비용으로 실패했다. 원래 기준을 소급 완화하거나 모든 관계 보존 완료로 바꾸지 않는다.

**폐기/보류:** GMR이 필수라는 주장, 초기 처리와 보정을 결합해야만 주 이득이 난다는 주장, 전역 모델 구조의 일반적 한계를 해결했다는 주장. 성과가 없는 구성 요소를 기여 수를 늘리기 위해 남기지 않는다.

**검증할 수 있는 방법 후보:** '거래열 생성기의 시간 출력을 거래 진행과 개인 과거 속도로 보정해, 정상 시간 분포와 사기 시작의 개인 대비 시간 관계를 개선하는 방법.' 이것은 현재 효과에 맞춘 후보 서술이다. 새 이론·보편적 보장·최신 방법 우위·완성된 기여는 아니다. 초기/GMR이 필수가 아니라는 제거 결과를 감추지 않고, 현재 보정의 설명 가능한 효과를 연구 대상으로 삼는다.

## 5. 무기한 수정 대신 한 번의 판별로 좁히기

다음 실험은 새로운 보정식을 발명하는 단계가 아니라, **현재 고정 보정의 추가 가치를 판별하는 비교**여야 한다. 아래는 설계 판단이며 실행 protocol/새 학습으로 위장하지 않는다.

| 구분 | 고정할 것 | 비교할 것 | 무엇을 알 수 있는가 |
|---|---|---|---|
| 단순 보정으로 충분한가 | 같은 이력망, 데이터, 위치별 목적, 난수, 내부 선택 | 무보정 / 전역 이동 / 위치만 / 현재 위치×개인속도 | 단순 분포 이동으로 설명되는지, 개인 조건이 추가로 필요한지 |
| 개인 입력의 효과인가 용량인가 | 보정 범위와 적합 예산 | 개인축 계수를 같게 묶는 직접 제거 + 별도의 6계수 위치 대조 | 직접 제거는 용량이 줄고, 동용량 위치 모델은 해상도가 다름을 모두 공개 |
| 생성기 전체로 의미가 있는가 | 공통 고객 지원·정보·길이 과제·평가 | 원형 ARGN, 충분히 학습한 CPAR, 재현 가능성을 확인한 최신 혼합형 생성기 | 시간 head 대조의 성공을 전체 모델 우위로 확대하지 않기 |

현 primary 두 지표는 그대로 유지한다. 개인 정상 시간·금액·가맹점·다양성·부모별 후반 비용을 함께 보고한다. 개발 자료에서 좋은 조건만 고르거나, 지표를 사후 교체하지 않는다. 조건부 관계의 실용적 가치는 추후 사전 지정한 분석 재현으로 보강할 수 있지만 사기탐지기 점수 하나로 대체하지 않는다.

전역/위치만 보정이 같은 이득을 내면, 개인속도 구조의 추가 기여 주장은 끝낸다. 이 경우 다시 작은 공식을 덧붙여 그 주장을 살리는 자동 연쇄실험은 하지 않는다. 현재 결과는 유용한 설정 개선·분석으로 보존하고, 새 방법 가설은 별도 문헌 근거와 함께 판단해야 한다. 반대로 개인 조건의 이득이 반복되면 그 한 가지 효과를 중심으로 확장하며 모든 지표 완승을 요구하지 않는다. 방법 논문 가능성과 투고처의 수락 가능성은 별도다.

[MeLD 공식 저장소](https://github.com/jeffreyliang-vandy/MeLD)의 commit `b1e5bb0fd95786a7dc11f616892b60ea6b311767`에서 VAE 학습·latent 복호화·DiT 실행 파일을 받아 읽었다. `sources/`에 원본을 보존했다. 학습은 HDF5의 mixed fields/time/missing/masking을 요구하고, 생성 복호화는 latent만 입력받아 binary/category/numeric/time/EOS를 출력한다. README만 보고 학습 구현이 있다고 추정한 수준을 넘겨 진입 경로를 확인했다.

그러나 재현 완료는 아니다. parser와 Sparkov schema, 실제 시간 조건의 사용 범위, EOS 복호화, static context, 최대 길이를 먼저 맞춰야 한다. 공개 버전의 CLI는 README와 일부 다르고 author 경로/설정 placeholder가 있다. 논문은 최대 120방문을 다뤘으므로 수천 거래 적용이 검증됐다고 하지 않는다. 의료 도메인 모델인 만큼 동일 조건의 금융 비교로 사용할지 어댑터 검증 후 결정한다. TimeAutoDiff와 함께 최신 혼합형 전체 생성 비교의 구체적 후보이며, 순수 시간 TPP로 전체 필드 비교를 대신하지 않는다.

CPAR의 기존 128epochs 결과는 기본 설정 실행이다. 동일 고객 지원(기존143 대 현재147), 학습 예산과 선택 절차를 맞추는 비교가 아직 필요하다. 두 비교 작업을 새 모델 개선이 성공할 때까지 미뤄둘 이유는 없다. 이번에는 공식 소스 확인까지 했으며 학습은 시작하지 않았다.

## 7. 이번 검토의 결론

실행 가능한 연구와 성공을 보장하는 연구는 다르다. 지금 확보한 사실은 '아무것도 좋아지지 않았다'도 '기여가 확정됐다'도 아니다. 효과가 반복된 시간 보정이 있고, 그 효과 중 개인속도·위치 조건의 추가 가치와 최신 전체 모델 대비 유용성은 미확정이다. 이 한 가지를 판별하는 데 집중하는 것이 현재 코드·결과·선행에 맞는다. 구조 부품을 계속 늘리거나, 작은 비용 하나를 이유로 결과 전체를 폐기하는 판단을 반복하지 않는다.
