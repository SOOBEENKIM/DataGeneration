## 1. 첫 모의 (등록한 세 부품) — 미달

금액 기준점(`AMT`)·최근성(`REC`)·간격 재배열과 창 맞춤(`GAP`)을 합친 `ALL`의 효용은 .513(+.022, 기준 +.03)이었다. `AMT`는 재방문 금액을 첫 금액과 독립으로 흔들어 분산을 두 번 더했고(금액 표준 지표 1.9 → 10.2배),
`GAP`은 효용을 내리고(−.008) 간격 지표를 악화시켰다. 표는 프로토콜의 "첫 모의의 판정"에 있다. 고객 안 간격의 순위 자기상관은 .048뿐이라 순서 재배열은 사실상 무효였다.

### 판정 (`ALL2`, 등록한 수치 그대로)

- **N2 충족.** 효용 +.038(기준 +.03), 4쌍 모두 양.
- **N1′ 3 / 4.** 짧은 간격의 같은 가맹점 비율 92%, 업종 평균 금액 83%, 업종 안 금액 78% 닫힘(기준 50%). 사기처럼 보이는 정상 행 비율은 41%만 닫힘(1.61% → 1.32%, 실제 0.90%) — 미달.
- **N3 미달.** 판별기 AUC .825 → .809(−.016; 기준 −.05).
- **N4 미달.** 금액 표준 지표 1.87 → **4.00배**, 라벨 × 금액 쌍 3.67배. 사기 구조·속성 일관성·사기 행의 개인 대비 금액(.457 → .453)은 유지.
- **결론(등록 규칙): 일부만 충족 → 생성기 구현 단계로 가지 않는다.** 부품별 채택은 별도 등록으로 한다.

### 읽는 법

- 효용을 올리는 것은 **금액**이다(`AMT0` +.023, `AMT2` +.028). 머무름(`REC2`)은 대상 구조를 가장 크게 고치지만(.05 → .68) 단독으로는 효용을 내리고(−.010, 4쌍 모두), 금액 부품과 합칠 때만 보탬이 된다(+.028 → +.038).
  왜 그런지는 확인하지 못했다.
- `AMT2`는 고객 수준을 맞추지만((고객, 업종) 안 표준편차 .994 대 실제 1.011; 고객 수준의 퍼짐 .83 대 .81) **금액 분포의 모양을 바꾼다**: 5 / 95 / 99% 분위가 .85 / 5.38 / 6.33(실제 .52 / 5.01 / 5.78).
  수준과 잔차를 더하는 구성이 업종별 분포의 꼬리를 늘린다. `AMT0`는 모양을 맞추지만(표준 지표 1.18배) 고객 수준이 없다(.18).
- 효용 상승은 등록 탐지기에서만 보인다(로지스틱 +.005) — 이 연구에서 반복되는 탐지기 의존성이다.
- 남은 격차: `ALL2` .528 대 행 교체 상한 .597. 사기처럼 보이는 합성 정상 행이 아직 실제의 1.5배다.

## 4. 다음 (제안, 별도 등록 필요)

2. 통과하면 생성기 안 구현(간격 → 가맹점 → 금액 순서라 두 부품 모두 조건화 가능) 또는 2단계 모듈로의 채택을 등록하고, seed를 fit마다 달리한 독립 생성으로 효용 차이를 다시 잰다.
3. `REC2`가 단독으로 효용을 내리는 이유의 진단.
