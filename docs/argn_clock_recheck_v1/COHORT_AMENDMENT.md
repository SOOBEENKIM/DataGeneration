# 고객 구성 사후 진단의 추가 확인

최초 고정2048-support cohort는 생성draw별2–8고객뿐이었다. 이를 근거로 전체 고객의
동일한 장기 진행 변화라고 확대하지 않는다. 추가로1024건 이상 공통지원집합 고객에서
처음1024위치를 평가한다. 이 cutoff는 표본 부족을 확인한 뒤 추가한 사후 진단임을 밝힌다.
새 모델/계수 선택에 사용하지 않으며 optimization/internal/test split을 바꾸지 않는다.

동일48–수십 고객의 동일위치에서 정상 gap/clock의 signed log 편향과 고객동일가중W1을
구해, 전체 구간별 결과 차이에 고객 구성의 영향이 있는지 확인한다. 생성 시 미래길이를
조건으로 쓰지 않고 평가 cohort를 정의하는 용도로만 사용한다.
