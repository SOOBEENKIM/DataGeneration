# 2026-09-28 감사 구간 선택 수정

첫 실행은 저장된 40개 생성 파일의 label/length 동일성을 확인하고 구간별 지표를
saved_generation_positions.csv에 기록한 뒤, 이전 6–49 지표와 대조하는 검사에서
종료됐다. start=6만 선택하여 새로 추가한 6–20과 6–49가 함께 선택된 오류다.
16개와 8개를 비교하는 shape mismatch였으며 실제 값 불일치를 숨기는 허용오차 변경이 아니다.
시간 재생 job은 아직 시작되지 않았다.

원래 소스, 프로토콜, manifest, 로그, 부분 결과를 그대로 보존한다. 새 wrapper는
보존된 표에서 start=6 AND end=50으로 선택하고 부모/생성 seed 키를 일대일 대조한다.
기존 표의 hash도 별도 amendment manifest에 고정한다. 조건부 분포, 난수, 평가 구간,
목표, 학습·생성 모델과 데이터는 변경하지 않는다. 새로 학습하거나 threshold를 바꾸지 않는다.

별개로 최초 shell launch는 로그 디렉터리가 없어 Python 실행 전에 종료됐다.
디렉터리 생성 후 본 실행을 시작했으며 이 파일에 두 실행상 오류를 모두 기록한다.
