# 간격·사기 전환 대조 완료: 크게 회복됐지만 개인 대비 금액 비용이 남았다

2026-09-27 GPU2·3에서 **새 gap head 학습4회, 전체 자유 생성16회,
3,159,744거래**를 완료했다. 기존 업종+금액 기준4생성은 재사용했다.
현재 기준과 변경점은 ARGN의 조건부 출력 학습 및 알려진 관측 episode 통계다.
새 CS-SAF/개인 상태 neural architecture의 학습이나 최신 전체 모델 대비 우위가 아니다.

## 네 조건의 실제 자유 생성 결과

각 값은2개의 frozen parent fit×2generation draw 평균이다. W1는 log1p 공간에서
계산하며 낮을수록 좋다. 실제 고객147명 중 사기 경험114명, 사기 전용12명이다.

|---|---:|---:|---:|---:|---:|
| 고정 업종+금액 기준 |.9394|.2143|.1371|71.00|0.00|
| 기준 + gap 학습 |.1770|.1933|.1311|71.00|0.00|

| 기준 + gap + 전환 |**.1277**|**.1386**|.1778|**104.25**|**7.75**|

joint의 사기 간격 오차는 기준 대비86.4% 감소하고 두fit 모두 감소했다.
사기 경험 고객 count오차43→9.75, 사기 전용 count오차12→4.25다.
고객별 사기 비중 분포 W1도.0824→.0198로 감소했다. 같은 고객 ID의 실제 사기
배치를 복사한 결과가 아니라, 고정 고객 context에서 새 거래열을 생성한 분포 비교다.

전환 대조만 연결하면 gap 오차가 오히려 커졌다. gap을 함께 학습해야 상태 배치가
달라져도 간격 품질이 회복된다. 이것은 추가 출력 학습과 전환 교정의 결합 필요성을
보여 주지만, 비선형 W1의 차이를 금융 인과적 interaction이나 새 학습 원리로 주장하지 않는다.

## gap은 생성 이력의 누적 오차만이 아니었다

native gap head는 실제 이력·실제 현재 label/category를 공급한 학습 위치에서도
사기 간격을 잘못 재현했다. 예를 들어 fit20260930의 optimization 사기 gap 중앙값은
실제4,917.5초 vs 생성25,733.5초, development는 실제4,598.5초 vs29,722초였다.

동일 frozen representation에서 head만 추가 학습한 natural 조건은 development
사기 gap W1을 약1.10까지 줄였지만, balanced 조건은.100–.138로 줄였다.
balanced의 개발 사기 gap 중앙값5,311–5,965초다. 실제 category 대신 개선된
category head로 샘플링해도 비슷한 회복이 남는다. 따라서 이번 gap 문제에는
희귀 상태의 조건부 출력 학습 부족이 있었고, 큰 이력 구조를 바꾸지 않고도 상당 부분
해결됐다. 모든 최초 거래는 간격이 없으므로 학습/진단/평가에서 제외했다.

조건부 진단과 자유 생성은 표본 고객/사기 위치/길이가 같지 않으므로 두 W1 차이를
오직 rollout history 오류로 환원하지 않는다. step0 포함 internal-validation macro
NLL로 checkpoint를 골랐고 development를 선택 기준으로 쓰지 않았다.

## 전환 대조가 무엇을 해결했는가

원래 duration 기준은 이전 label과 capped run age만 봤다. 이번 episode_only는
strict-past 이전 사기 경험과 관측 시작 경계 상태를 더했고, 이 경우 사기 경험
고객은71→90.75로 늘었지만 사기 전용 고객은0에 머물렀다.

joint 전환은 이 대조에 첫 상태–모델 생성 길이의 관계를 추가한다. 첫 상태 조건은
optimization에서 학습한 작은 tree이며 고정 ‘100건 이하=사기’ 규칙이 아니다.
최초 label은 생성 후에만 memory에 저장한다. 확률은 자연 노출량으로 추정하고
smoothing해0/1이나 최대1회episode 강제를 하지 않는다. 실제 개발 미래 길이도
생성기에 공급하지 않는다. 생성 후 label을 재배정하지 않는다.

실제 development의 반복 사기 구간 고객은0인데, 기존 생성은평균29.5명,
episode_only5.5명, joint2명이다. label-only768draw에서도 사기 경험 고객은
평균73.96→95.17→105.29, 사기 전용은.46→.58→7.18로 바뀌었다. 이는 추가 neural
학습768회가 아니라 동일 transition의 sampling 변동 진단이다.

## 비용과 해결되지 않은 부분

- **개인 대비 사기 금액 W1은.1371→.1778로 나빠졌다.** 두fit 각각+.0351/+.0462.
  사전 practical 허용폭+.05 이내지만 실제 악화이며 ‘모든 관계 개선’이라고 하지 않는다.
  run-age 구성 표준화 후에도.1222→.1623으로 악화가 남았다. 이 표준화는 episode
  나이만 맞추므로 고객/길이/초기 상태 구성 전체를 통제한 인과 진단은 아니다.
- 전체 사기율은 실제.6438%, 기존.6064%, joint.5411%다. 고객 구성이 나아져도
  전체 사기율은 실제에서 멀어졌다. 비율을 사후 보정해서 이 실패를 숨기지 않는다.
- 정상 gap W1은.1507→.1290로 개선, 정상 금액.058365→.058767로 비슷했다.
  정상 merchant TV.067896→.067888, category–amount TV.120815→.120936으로 작게 변했다.
  두fit별 수치와 모든 draw는 all_metrics/paired_effects에 있다.
- 전체 unique merchant는 모든 draw에서693이며 고객당 unique merchant 중앙값의
  draw평균551.75→550.50, seen-merchant 비율.63923→.63939다. 이 제한된 다양성
  지표에서 큰 붕괴가 없다는 뜻이며 개인정보 보호나 모든 다양성을 보장하지 않는다.
- 사기 경험 고객104.25 vs실제114, 사기 전용7.75 vs12는 아직 완전히 맞지 않는다.
  학습에서 처음부터 사기인 고객 길이≤15, 정상 시작 고객≥471인데 생성 길이에는
  그 중간8–10고객이 있다. 개발 실제도 길이16인 사기 고객1명이 있으므로 중간
  길이 전부를 오류로 금지할 수 없다. 길이 분포와 초기 상태/지속의 조합을 다음에
  분리해야 한다. 이것만으로 개인 이력 encoder의 구조적 한계라고 결론 내리지 않는다.

## 연구 판단

이번 요청의 네 가지 조건, 추가 제거 대조, 정상·다양성 평가와 독립 검증은 완료했다.
단순한 교정으로 설명되는 간격·고객 구성 개선을 새로운 구조적 기여라고 포장하지 않는다.
반면 **고객 배치와 시간 관계를 고치자 개인 대비 금액과 전체 사기율에 비용이 남는 것**은
다음 진단의 구체적인 대상이 됐다. 현재 strongest simple controls를 고정하고,
길이–초기 상태/긴 정상 이력의 시작 위험/개인 조건부 출력의 구성 효과부터 분리한다.
그 뒤에도 남는 오류에서 공유 개인 상태를 전환·출력에 연결할 후보를 검증한다.
새 모델의 novelty는 가까운 조건부 hazard/MLP/상태 생성 문헌과 제거 대조를 거쳐 판단한다.
