## 4. 판정

- **F1 충족(`attr_all`).** 정상 행 업종·채널 일치 1.000, "대면 가맹점 온라인" 0.000; 사기 행 업종 일치 1.000, 온라인 .860, 채널-가맹점 일치 .245(실제 .315 ± .10 안).
- **F2 충족(수치 기준), 단 해석 주의.** `attr_all` **.455 ≥ .448**. 현재 모델 대비 +.124(가상 실험 예측 .476에 근접). RTF+전이표와의 차이 +.007은 **잡음 안**이다: fit 08에서는
  RTF가 높고(.52 vs .45), fit 09에서는 ARGN이 높다(.46 vs .37). 로지스틱 탐지기에서는 .571로 동률, `no_merchant`에서는 ARGN이 조금 낮다(.366 vs .379). 정확한 문장은
  "ARGN 모델이 시험한 것 중 가장 높은 RTF+전이표와 **같은 수준**이며 생성 간 분산은 더 작다(.03 vs .09)"이다. "최고"라고 쓰지 않는다.
- **F3 충족(설명).** `attr_cat` .338, `attr_chan` .331로 단독은 이득이 없고, 둘을 함께 맞춘 `attr_normal` .444 / `attr_all` .455에서만 오른다 — 진단대로 신호는 업종 × 채널
  **결합**이다. 사기 행 몫은 작다(+.011)이나 조기 탐지율(.766 → .811)과 사기 새 업종(5.08 → 0.84배)은 사기 행까지 맞춰야 좋아진다. 예고대로 `no_channel` 탐지기에서는 이득이
  없다(.134 → .118).
- **F4 위반 → 등록 규칙상 `attr_cat`·`attr_normal`·`attr_all`은 무효.** 라벨 과정·간격 구조·가맹점 구조는 유지되나 **표준 업종 TV가 2.22 → 3.25배**(.120 → .176)로 기준 3을 넘었다

## 5. F4 위반의 원인 (추가 진단, 새 생성 0; `DIAG_CATEGORY_MARGINAL.json`)

"가맹점이 함의하는 업종"(가맹점 → train 최빈 업종)의 주변분포를 dev와 비교한 TV:

| | 실제 업종 TV | 가맹점이 함의하는 업종 TV |
|---|---:|---:|
| train 240명 부분표본(바닥) | .053 | .053 |
| ARGN 원형 | .188 | .131 |
| ARGN + 가맹점 부품(`full`) / 현재 모델 | .120 | **.170** |
| `attr_all` | .176 | .178 |
| RTF+전이표 | .185 | .185 |

- 현재 모델이 고른 **가맹점들의 업종 구성은 이미 .170만큼 어긋나 있었다**. 업종 TV가 .120으로 좋아 보였던 것은 backbone이 업종을 가맹점과 따로 냈기 때문이다(일치 .31).
  일관성을 강제하자 가려져 있던 가맹점 주변분포의 오차가 업종 열에 그대로 드러났다(.176 ≈ .178). 즉 위반의 원인은 이 부품이 아니라 **가맹점 선택의 주변분포**다.
- 가장 큰 차이(생성 대 실제): 식료품점 5499 .032 vs .101, 주유소 5541 .052 vs .103, 송금 4829 .012 vs .048 — 자주 반복되는 생활 업종 가맹점이 덜 뽑힌다.
- 참고: 같은 지표에서 ARGN 원형은 .188, RTF+전이표는 .185(3.42배)로 `attr_all`보다 나쁘다. 그래도 이 단계의 기준은 "3배 이하"였으므로 위반은 위반이다.

## 6. 결정

- 부품의 **효과는 확인**됐다: 가맹점 속성 일관성으로 ARGN 효용 .331 → .455(상한 .61의 75%), 행 단독 .109 → .280, 조기 탐지율 .69 → .81. 구조 서술 "정상 거래는 가맹점이 업종·채널을
  정하고, 사기 거래는 가맹점이 업종만 정하며 채널은 상태가 정한다"가 그대로 부품이 됐고 ablation이 "결합이어야 한다"를 보여 준다.
- **채택은 보류**한다(F4). 남은 일은 기준을 고치는 것이 아니라 드러난 원인 — 가맹점 선택의 업종 구성(.170) — 을 고치는 것이다. 후보(미등록): 가맹점 부품의 새로움 가지가 쓰는
  backbone 가맹점 분포의 보정, 또는 반복 커널의 빈도 가중 재검토. 그 단계에서 `attr_all`을 다시 평가한다.
- 효용 주장 범위: 등록 탐지기·로지스틱에서 성립, 채널 특징이 없는 탐지기에서는 이득 없음. RTF+전이표와는 동률 수준.
