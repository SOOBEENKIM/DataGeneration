# 외부 비교의 입력·평가 준비 기준

2026-09-21. 이번 관측 관계 진단 **후** 작성한 다음 비교의 설계 결정이다. 아래 항목은 구현/검증 요구사항이며, 외부 신경망 학습의 사전등록 완료 또는 실행 완료를 뜻하지 않는다. 데이터 의미와 평가 대상을 먼저 고정한다. 새 구조/규제/rollout 손실은 이 준비 작업에 추가하지 않는다.

## 1. 무엇을 같은 조건에서 비교하는가

| 자료 | 행동과 수치의 의미 | 주 관계 | 별도 공개할 한계 |
|---|---|---|---|
| Berka | operation→결측 시 type, 거래 금액, 일 단위 날짜 | 날짜 간 간격–거래 종류, 종류–금액, 일별 거래 수/구성 | 같은 날짜 내부 참 순서 불명; 거래별 사기 정답 없음 |
| Sparkov | merchant, category, amount, 문자열 timestamp | 간격별 업종 전이와 가맹점/업종–금액 | 외부 시뮬레이션; 동일 가맹점 반복은 희소 |

첫 비교는 거래열 충실도 파일럿이다. 탐지 효용·개인정보 보호·완전한 은행 원장 생성은 별도 범위다. Berka의 balance/k_symbol과 Sparkov의 위치/사기 라벨을 포함할지 조용히 바꾸지 않는다. 공통 입력 schema와 제외 목록을 artifact로 고정하고, 포함한 필드만 모든 모델에 동일하게 제공한다. 사기 라벨 없는 첫 비교로 탐지 효용을 주장하지 않는다.

Sparkov category는 merchant에서 유일하게 결정되지 않는다. category를 독립적으로 생성/관측하는 동일 schema가 필요하며, 생성 후 임의 조회표로 고치지 않는다. `entity_any_fraud`와 현재/미래 fraud는 행동/금액 예측 입력에서 제외한다. 과거 관측 fraud도 첫 비교의 공통 입력으로 추가하지 않는다. 고정된 개체 분할을 유지하고 ID는 연결 키로만 사용한다.

## 2. 외부용 U/G 이식에서 먼저 해결할 구현 문제

관련 근거: `models/cs_saf.py`의 controlled schema 및 multiwindow 거부, `models/cs_saf_v2.py`의 2-context 고정 bank, `models/cs_saf_structure.py`의 반복 head.

1. 공통 외부 tensorizer: train 내부 fit으로 어휘·수치/간격 변환을 정하고 validation/test를 fit에 사용하지 않는다. 미등록 범주와 결측을 구분한다. 미등록 정답을 마스킹해 점수를 좋게 만들지 않는다.
2. 기존 기본 인코더가 지원하는 보조 필드와 정적 정보 처리를 공통으로 적용한다. 통제용의 두 집단을 외부 자료에 임의 생성하지 않는다. context bank 일반화는 **명시적 모델 변경**이므로 외부용 `U_ext/G_ext`의 계약·파라미터 수·초기화 규칙에 기록한다. 기존 U/G 결과와 같은 checkpoint/frozen architecture라고 부르지 않는다.
3. 길이 32는 최근 과거를 보는 범위로 사용할 수 있지만 전체 거래열의 절단 길이가 되어서는 안 된다. 모든 유효 target을 한 번씩 학습/평가하고 창 사이의 이전 행동·실제 gap을 보존한다. 패딩·개체 경계·창 경계에서 가짜 반복/첫 거래를 만들지 않는 CPU 검사와 step-by-step 생성 일치 검사를 한다.
4. U/G의 차이는 기존 copy mixture와 관측 반복 분해에 남긴다. 첫 이식에서 동시에 gap→비반복 선택 경로나 새 관계 손실을 넣지 않는다. 이로 인해 드러나는 한계는 결과로 보고한다.
5. 기존 통제 schema에 대한 수치 회귀 검사로 옛 결과 코드를 훼손하지 않았는지 확인한다. **첫 외부 학습 전에** 실제 입력을 통과하는 CPU forward/loss/샘플링·타깃 수·정보 누출 검사를 완료한다.

## 3. 비교 모델과 학습 기회

- `U_ext`, `G_ext`: 공통 인코더, 포함 필드, 최근 이력 범위, base likelihood, 유사 용량, 학습 예산과 선택 기준을 맞춘다. 기존 보정이 외부 schema에 적용 가능한 경우 양쪽에 같은 기회를 주고 raw/corrected를 함께 기록한다. 인공 데이터의 2집단 보정 계수를 그대로 재사용하지 않는다.
- 공식 TabularARGN 순차 모드 및 CPAR: 같은 데이터와 의미를 제공하고 각 모델의 공식 학습/생성 경로를 유지한다. 내부 U/G와 인코더까지 같게 바꾸지 않는다. 설치 버전·지원 필드·실현 길이·실제 update 수·학습 곡선·선택/최종 checkpoint를 공개한다. 기존 통제 자료 ARGN 결과를 외부 데이터 결과로 대체하지 않는다.
- 단순 관측 대조군: 전체 빈도, 전이 빈도, 업종에서 정보를 공유하는 전이 모델. 이번 고정 pseudocount20의 희소 가맹점 표만 대표 강한 baseline으로 두지 않는다. 평활화 후보는 **train 내부 check에서만** 제한된 목록으로 선택한다. 목록·선택 규칙을 다음 실행 등록에 넣는다. validation 결과로 계수를 추가하지 않는다.
- 조건부 예측표와 순차 생성 모델을 구분한다. 단순 모델도 gap/mark/category/amount를 스스로 생성하고 생성된 행동을 다음 이력에 넣어야 자유 생성 비교에 포함할 수 있다.

학습 시드/생성 시드/최대 update·시간·조기 종료/샘플 수는 CPU 처리량 검사 후 **첫 학습 전에** 공통 실행 설정으로 등록한다. 이 문서는 아직 이를 정한 학습 사전등록이 아니다. 데이터 크기가 다른 모델에 같은 epoch 숫자만 주고 학습 기회가 같다고 주장하지 않는다. validation에서 성능을 본 뒤 예산을 늘리는 후속은 원 실행과 구분한다.

## 4. 평가기의 필수 조건

| 영역 | 평가 대상 | 통제할 문제 |
|---|---|---|
| 실제 이력의 예측 | 가능한 모델의 mark/category log score, 반복 Brier, 금액 조건부 오차 | 현재 관측 gap을 준 조건부 평가와 gap까지 예측하는 평가를 구분. 서로 다른 수치 인코딩의 raw loss 직접 비교 금지 |
| 자유 생성 관계 | train 기준 gap 구간×업종/거래 종류 전이, 행동×금액 분포 | 관측 간격을 강제로 주지 않고 생성 gap 사용. 정답 DGP 확률/생성 후 관계 수리 금지 |
| 기본 분포 | gap, 0-gap 질량, mark/category, 금액, 길이/일별 거래 수 | 관계 개선 때문에 주변 분포·길이를 희생했는지 함께 공개 |
| Berka 시각 해상도 | 일별 거래 수·종류 구성과 날짜 간격, 명확한 인접 쌍 별도 | 날짜 내부 순서에 의존하지 않는 주 지표 포함. 애매한 약61% 전이를 제외한 점수만으로 전체 성능 주장 금지 |
| Sparkov 희소 상태 | 동일 가맹점 반복·긴 run은 보조 | 전이가 충분해도 양성 반복이 매우 적으면 불확실성 공개. 미관측 셀 삭제로 점수 개선 금지 |

정답 관계를 아는 인공 자료의 oracle TV를 그대로 계산하지 않는다. 실제 validation 경험분포와 생성 경험분포 사이의 거리라고 명시한다. 데이터별 관계를 따로 보고해 서로 다른 의미의 반복을 단일 평균으로 합치지 않는다. 발생량을 반영한 점수와 개체 균등 점수를 함께 두며, 신뢰구간은 개체 단위로 계산한다. 생성 난수 반복은 학습 시드 반복과 구분한다.

일별 지표의 정확한 정의·연속변수 구간·평가 표본 계획은 train에서만 확정해 평가기 CPU 검증과 함께 등록한다. 실현 길이를 임의로 잘라 두 모델의 점수를 맞추지 않는다. 동일 길이를 조건으로 주는 비교는 별도 조건부 과제로 표시하고 자연 길이 생성과 섞지 않는다.

## 5. 결과를 보고 어떻게 종료할 것인가

첫 외부 파일럿의 목적은 모델별 중요한 잔여 오류를 찾는 것이다. 항목마다 성능 차이·불확실성·부작용을 모두 보고하며, 여기서 좋은 점수 하나만 골라 방법의 우수성을 선언하지 않는다. 최종 후보 채택용 허용 손실/필요 개선 폭은 별도 확증 실험 전에 과제 목적에 맞게 고정한다. 인공 데이터의 문턱을 외부 자료에 기계적으로 옮기지 않는다.

- 단순 대조군으로 주 관계가 충분히 재현되면 복잡한 새 모듈의 필요성을 주장하지 않는다.
- U/G와 외부 모델 모두에 중요한 오류가 반복되면 위치·표본 수·학습 충분성을 확인한 뒤 원인 하나를 겨냥한 후보를 등록한다.
- 특정 모델의 기본 예측/학습이 불충분하면 그 점수를 제안 구조의 우월성 근거로 쓰지 않는다.
- U/G가 관계와 기본 분포에서 우위가 없으면 그대로 보고한다. 결과를 구제하려고 지표/데이터/계수를 계속 추가하지 않는다.

이 외부 비교 뒤에야 필요성이 확인된 방법 후보, 다른 분할/자료의 확인, Sparkov의 탐지 효용 실험을 정한다. Sparkov 효용이 좋아도 실제 은행 사기 탐지 검증으로 부르지 않는다.
