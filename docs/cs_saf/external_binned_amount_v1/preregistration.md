# 마지막 기본 금액 출력 비교: 실행 전 등록

Parent `5f81c5e`: D에서 실제 이력의 금액 tail 오류와 Berka 생성 이력의 증폭을
확인했다. 이 개발 자료를 이미 반복 분석했으므로 탐색 비교이며 독립 확인이 아니다.
**기존 D 보존, 새 D_bin 한 종류, Berka/Sparkov 각 1회 학습·2회 생성으로 종료한다.**
성공 여부와 무관하게 구간 수·구조·계수·seed를 추가하지 않는다.

## 변경과 비교 조건

- D의 고객 입력, 최근 31거래 GRU128, 직접 행동 MLP, 간격/행동/금액/보조 필드
  순서, 입력 정보, 데이터 split, 생성 plan을 그대로 사용한다.
- 기존 D의 **학습된 가중치를 미세조정하지 않는다.** 저장된 D의 `initial.pt`에서
  모든 공통 가중치를 그대로 가져와 처음부터 공동 학습한다. amount head만 교체한다.
  공통 가중치를 학습 중 동결하는 실험도 아니다. 금액 손실 변경이 이력 학습과
  다른 필드 예측에 영향을 줄 수 있으므로 아래 비용 기준을 적용한다.
- 금액 head는 기존과 같은 `[history, current_gap_features, current_mark_embedding]`
  입력의 선형층→softmax다. 현재 금액/현재 category/type은 넣지 않는다.
  학습된 구간 확률로 구간을 선택하고, 그 구간의 **fit 거래 금액**을 사건 빈도대로
  균등 표본추출한다. 고객·행동별 추가 pool, 보정, 규제는 없다.
- 양수 fit 금액의 기존 float32 log1p 표준화 좌표에서 1/32,…,31/32 분위와
  .99/.999 분위 경계를 만든다. float32 경계 중복/빈 구간은 결정적으로 합친다.
  0이 fit에 있으면 별도 범주다. 변환 좌표 사용은 학습 target과 pool의 경계
  반올림 불일치를 막는다. 원금액과 의미상 단조인 금액 구간이며 경계·구간 수를 저장한다.
- 구간 내부 표본은 원금액 그대로 저장하며, 원래 log1p codec으로 바꿔 **다음 이력에
  넣는다**. 이로 인해 이후 간격·행동도 변할 수 있다. 출력 clipping/사후 표 수정은 없다.
- head 가중치 0, bias는 fit 구간 빈도의 log로 초기화한다. 전체 파라미터 수 증가는
  공개한다. 이를 용량이 같은 새 방법의 기여 실험이라고 부르지 않는다.
- 학습 자료의 구간 내 원금액에만 질량을 둔다. 관측 범위 밖 값을 만들 수 없고
  학습 금액을 재사용한다. privacy 보장이나 외삽 능력을 주장하지 않는다.

## 예산과 모델 선택

신규 fit 2회, 신규 생성 4개, 보정 0회. raw만 평가한다. 기존 D raw checkpoint와
생성 4개, 전이/주변분포/ARGN/CPAR의 기존 결과는 변경 없이 참고한다.
seed, Adam .001, batch512, clip1, 30epoch/1200초(완료 epoch 경계), patience5는
기존 D와 같다. 시간 상한/학습 충분성 문제는 숨기지 않는다.

손실은 간격·행동·금액·보조 필드의 일반 likelihood 성분별 평균 합이다. 새 금액은
**구간 cross-entropy**이며 기존 연속 분포 NLL과 수치 수준이 다르다. 원래처럼 각
모델 내부 check loss 최소 epoch를 선택하지만 두 native loss로 성능 우열을 매기지 않는다.
기존 D가 학습한 이력 표현을 그대로 유지했다는 주장도 하지 않는다.
비교 가능한 점예측은 각각 `E[log(1+amount)]`의 log-MAE다. 새 분포는 구간별
fit log1p 평균과 구간 확률로 정확히 계산한다. 전체 손실 비중까지 분리하는 추가
실험은 이번 범위가 아니다.

## 실행 전 고정한 탐색 기준

기존 D 대비 생성 2회 평균을 사용한다. validation은 평가에만 쓰고 pool/경계/head
학습/epoch 선택에 넣지 않는다. 아래 기준은 통계적 유의성이나 금융 사업 허용치가 아니다.

**두 자료 공통 비용 제한**

- 시간–행동 TV 증가 ≤.01: Berka daily-gap/operation, Sparkov gap/category-transition.
- gap/mark/root TV 및 금액 KS 증가 각각 ≤.01.
- 실제 이력의 mark NLL 증가 ≤.02, repeat Brier 증가 ≤.002,
  amount log-MAE 증가 ≤max(.01, 기존의 5%).
- 음수/비유한 금액·잘못된 gap 0. 지정 고객별 전체 길이와 순서 유지.
- fit 금액 q99/q99.9의 생성 초과율이 validation 관측 초과율의 **0.5–2배** 범위.
  큰 금액을 없애기만 해서는 통과할 수 없다. 두 생성물의 평균으로 검사한다.
- q99/q99.9 각각에서 `Σ_root |P(root,A>cut)_gen − P(root,A>cut)_val|`
  증가 ≤.002/.0005. Berka root=operation, Sparkov root=category. 상위 금액의
  행동 구성을 함께 본다. 이 지표는 전체 사건 수로 정규화하며 조건부 TV가 아니다.

**Berka 주목적:** 행동–금액 TV를 절대 .02 이상이면서 상대 10% 이상 감소시킨다.
실제 이력에서 q99/q99.9 초과 확률의 관측 초과율 대비 절대 오차도 **각각 50% 이상**
감소시킨다. 이는 생성 범위를 제한한 결과만으로 선택하지 않기 위한 조건이다.

**Sparkov 호환성:** 행동–금액 TV 증가 ≤.01. 실제 이력 tail 확률 오차 증가
q99≤.002, q99.9≤.0005. Berka에서 주로 발견한 결함을 고치며 Sparkov까지
10% 개선해야 하는 조건을 추가하지 않는다.

**종료 결정:** Berka 개선+공통 비용과 Sparkov 호환성+공통 비용을 모두 통과하면
D_bin을 두 자료의 **고정 연구용 작업 모델**로 채택한다. Berka만 통과하면 자료별
후보로만 기록하며 공통 채택하지 않는다. Berka 기준을 못 넘으면 이번 수정 방향을
종료하고 D를 참고 기준으로 유지한다. 어느 경우에도 현재 구조의 독창성, U/G 전용
구조의 필요성, 외부 모델 대비 우수성이나 사기 탐지 효용이 입증된 것은 아니다.
단순 전이 대비 차이는 함께 공개하지만 이번 목적의 새로운 통과 조건으로 추가하지 않는다.
