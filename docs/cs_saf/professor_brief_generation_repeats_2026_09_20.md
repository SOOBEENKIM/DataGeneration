# 교수님 보고용: 생성 난수를 바꾸어도 문제가 반복되는가?

2026-09-20 · [상세 결과와 그림](generation_repeats_v1_report_2026_09_20.md)

**연구 목표:** 과거 거래로부터 새 거래를 순차 생성할 때, 거래 간격과 행동 반복 사이에 필요한 관계는 재현하고 관계가 없는 집단의 불필요한 반응은 줄이는 모델을 연구하고 있습니다. 기본 U도 거래 이력을 사용하며, E는 행동 반복확률 계산부에 추가 이력 보정을 넣은 모델입니다.

**이번 확인:** 같은 확률 보정을 적용한 뒤에도 E의 생성 오차가 U보다 컸습니다. 이것이 우연히 생성된 표본 때문인지 확인하기 위해 모델과 보정값을 고정하고, 새로운 생성 난수 다섯 개로 반복 평가했습니다. 네 집단 비율·두 조건·다섯 학습 시드·네 모델의 **800회 생성 평가**를 완료했습니다. 새 학습은 하지 않았습니다.

| 집단 비율 | U+보정 생성 오차 | E+보정 생성 오차 | E+보정의 오차가 큰 학습 시드 |
|---|---:|---:|---:|
| 5% | 0.031552 | 0.035293 | 4/5 |
| 10% | 0.030656 | 0.035597 | 5/5 |
| 25% | 0.028794 | 0.030726 | 4/5 |
| 50% | 0.018003 | 0.018022 | 2/5 |

간격·행동·수치값을 모두 생성했을 때의 반복관계 오차로, 작을수록 좋습니다. 같은 모델의 생성 다섯 번을 먼저 평균한 뒤 다섯 학습 시드에서 평균했습니다.

- **확인된 문제:** 5%·10%·25%에서는 생성 난수를 바꾸어도 E+보정의 평균 생성 오차가 더 컸고, 등록한 비용 일관성 기준에 해당했습니다. 다만 5%·25%의 학습 시드 간 참고 구간은 0을 포함하며, 50%는 평균 차이가 작고 방향도 섞였습니다. 모든 조건의 확정적 열세로 해석하지는 않습니다.
- **남아 있는 이점:** E의 다음 행동 분포 예측과 불필요한 반응 억제 이점은 유지됩니다. 문제는 이 이점이 실제 생성 관계의 개선으로 이어지지 않는다는 점입니다. 기본 U에서도 보정의 생성 개선이 세 비율에서 반복돼, 보정 효과를 E 구조만의 기여로 설명할 수 없습니다.
- **다음 계획:** 저장된 U+보정/E+보정의 생성 이력을 서로 교차해 입력하고, 같은 이력에서의 예측 차이와 스스로 만들어낸 이력 분포의 차이를 구분하겠습니다. 그 근거로 추가 이력 경로를 단순화할지, 학습 목표와 순차 생성의 관계를 보완할지 결정하겠습니다. 이 후속 진단은 아직 사전등록·실행하지 않았습니다.

현재 결과는 같은 인공 데이터와 저장 모델에서 확인한 현상입니다. 새로운 데이터·학습 시드에서의 재검증, 외부 모델 대비 우수성 및 실제 사기 탐지 효용은 별도로 확인해야 합니다. 원본 배열에서 오차 4,800개를 독립 재계산해 일치함을 확인했고 GPU 실행은 종료했습니다.
