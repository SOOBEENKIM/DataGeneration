# U/G를 고정한 생성 관계 보정 — 실행 전 등록

## 질문과 변경 범위

이번 질문은 **실제 이력에서 맞춘 보정 A보다, 생성한 거래열의 관계로 학습하는 B 및 예측 손실을 제한한 P가 예측·생성의 동시 성능을 개선하는가**다. 기존 C 구조의 실패는 유지한다. P는 C의 재명명이 아니며 C의 평균 보존 제약을 사용하지 않는다.

`12ce8d3`의 U/G×κ0/1×3개 학습 시드, 총 12개 저장 부모를 재사용한다. 데이터 seed42, 소수 집단 10%의 기존 인공 데이터다. 모든 신경망 tensor와 기존 입력을 동결한다. 각 부모의 집단별 native gap 5구간과 **10개 logit offset**만 사용한다. A는 이전 train-only gap 보정값 그대로, B/P는 A에서 출발해 같은 10개 값만 수정한다. 새 신경망·이력 특징·gap 해상도·반복하지 않을 때 행동 출력 경로를 추가하지 않는다. 총 **24회 보정 탐색, 신경망 재학습 0회**다.

## 학습 목표와 예측 보호

학습 목표는 outer train 관측 거래에서 집단별로 센 `(native gap 구간, 실제 반복 여부)`의 5×2 결합 빈도다. 생성 표본에서도 같은 결합 빈도를 구해 제곱 차이의 합을 집단별로 계산한 뒤 두 집단을 동일 가중 평균한다. 집단은 관측된 입력이고 활성 여부를 알려주는 oracle 표식은 쓰지 않는다. 구간별 반복률만 맞추며 구간의 발생 빈도를 바꾸는 편법을 피하도록 결합 빈도를 사용한다. 평가 지표와 학습 목적함수가 완전히 같다고 주장하지 않는다.

B는 이 생성 관계 목적함수만 최소화한다. P는 같은 목적함수·탐색·생성 횟수를 사용하면서, **실제 outer train의 각 집단에서 A 대비 Brier 증가≤.001 및 행동 NLL 증가≤.01**인 후보만 채택한다. 반복/비반복 사이의 질량만 바꾸므로 실제 이력을 고정했을 때 행동 NLL 차이는 반복 Bernoulli NLL 차이와 같다. 첫 거래는 제외한다. 이 훈련 제약은 validation에서의 보장을 뜻하지 않으므로 평가 허용폭 .002/.02를 따로 확인한다.

보정은 행동을 생성하는 순간 적용하며 그 행동·수치값을 다음 이력에 넣는다. 신경망 가중치를 동결해도 뒤의 간격·금액 분포가 변할 수 있다. 샘플링한 이산 행동을 미분 가능한 값으로 간주하거나, 생성 이력에 실제 다음 행동을 정답처럼 붙이지 않는다. 10개 파라미터의 한정된 derivative-free 탐색으로 학습 목표의 효과를 먼저 확인한다. 새 미분 추정기의 기여를 주장하지 않는다.

## 고정 탐색과 선택

- 각 κ의 train에서 집단별 1,024개 개체를 선택해 탐색 계획 2,048개를 만든다. 겹치지 않는 다른 train 개체로 동일 크기의 선택 계획을 만든다. 이들은 길이·집단만 제공하며 실제 거래 이력을 생성 시작값으로 복사하지 않는다. 정답 통계는 outer train 전체다. 선택 계획은 독립 평가 데이터가 아니다.
- 탐색 난수 2개와 선택 난수 2개를 분리하며, trial별 +100 offset을 적용한다. 모든 부모·방법은 같은 계획과 같은 대응 난수를 쓴다. 최종 평가 난수는 이들과 다르다.
- offset 절대 범위 ±8, step .4/.2/.1의 **3회 좌표 순회**. 각 순회 10좌표에 −/+ 후보를 모두 평가한다. 순서는 trial별 고정 permutation이다. 현재값보다 목적함수가 1e-12 이상 낮은 후보만 채택하고 동률이면 현재값을 유지한다. P의 예측 제약에 걸린 후보도 같은 생성 평가를 실행하여 B/P의 호출 예산을 맞춘다.
- 60개 후보와 초기값의 탐색 평가, 각각 2개 생성 난수. 선택 계획에서는 A 및 각 순회 종료값의 4개 후보를 2개 난수로 평가한다. 보정 한 번당 **130개 생성 호출**로 고정한다. A도 후보에 남으며 가장 좋은 선택 목적함수의 후보를 채택한다. P는 적격 후보만 선택한다.
- 손실계수 탐색, 결과 기반 추가 순회/시드/파라미터는 없다. 모두 완료하거나 기술 오류를 보존하고 중단한다. 기술 수정은 과학적 기준을 바꾸지 않고 기록한다.

## 최종 평가와 oracle 격리

모든 보정값과 선택 결과를 먼저 저장한 후 validation 및 oracle 평가를 실행한다. 12부모×A/B/P×새 생성 난수3개=**108개 신규 생성 데이터셋**. 이전 공통 평가 계획과 같은 2,048개 길이·집단으로 간격·행동·수치값을 모두 자유 생성한다. 실제 이력의 반복 Brier·행동 NLL·곡선 L1, 기본 13개 생성 지표, 비활성 평균 제거 모양, 고정 이력 gap 민감도를 모두 공개한다.

정답 생성기는 별도 평가 프로그램에서만 사용한다. 기존에 검증한 observable-filter joint oracle로 **JOINT_CONT 및 JOINT_BIN**, κ0/1 각각 30개 신규 난수, 총 **120개 데이터셋**을 생성한다. 신경망 평가와 같은 2,048개 개체 길이·집단이며 첫 행동은 새 균등 표본, 수치값은 생산 법칙의 새 독립 표본이다. 관측 첫 행동·수치값을 복사하지 않는다. CONT는 연속 joint DGP, BIN은 gap support로 양자화된 joint DGP 기준이다. raw validation 기준 결과와 BIN의 양자화 reference 결과를 구분한다.

oracle는 보정 학습·선택·방향 결정에 사용하지 않으며, 실현된 원본 잠재상태를 읽지 않는다. 평가 분산·평균 오차를 참고값으로 공개한다. **이는 엄밀한 최소 오차 하한, 모델 실패의 원인 분해, 새 데이터에서 모델을 학습한 독립 재현이 아니다.** 30개 oracle 난수는 30개 학습 시드로 세지 않는다.

## 통과와 주장

B−A와 P−A를 U/G 각각에서 판정한다. 생성 난수는 각 부모 안에서 먼저 평균한다.

1. 활성 생성 L1: 평균 10% 및 .002 이상 감소, ≥2/3 학습 시드 개선, 어떤 시드도 .005 초과 증가 없음, 후보 각 시드≤.03.
2. 예측: 각 κ/집단/시드에서 A 대비 Brier 증가≤.002, 행동 NLL 증가≤.02. A와 후보 모두 이전 기본 예측 적격 기준을 통과한다.
3. 다른 생성 분포: 각 κ/집단/시드에서 A 대비 gap KS/행동 sparse TV/수치값 KS 증가≤.01, 길이 scaled W1 증가≤.02.
4. 비활성: 생성 곡선 L1≤.03, 평균 제거 모양 L1≤.02. 이번에는 추가로 **A 대비 고정 이력 평균 반복확률 범위 증가≤.01**도 요구한다. 이는 이번 단계의 사전 기준이며 과거 C 판정을 소급 변경하지 않는다.

P가 동시 기준을 통과하고 B는 생성 개선을 통과하면서 예측 비용 때문에 실패할 때에만, 예측 보호의 유용성을 지지하는 탐색 근거로 해석한다. B도 동시 통과하면 보호 장치가 필수라고 하지 않는다. B/P가 A보다 이득이 없으면 이 수정 방향을 채택하지 않는다. U/G 모두에서 이득이면 **가까운 두 내부 구조에서의 적용 가능성**이며 외부 생성기 전반의 일반화가 아니다. C를 살리는 결과로 해석하지 않는다. 어느 성공도 학회 수준의 신규성·실제 금융 효용·통계적 우월성 확정이 아니다.

이번 한정 비교를 마치면 종료하고 결과에 따른 주장을 기록한다. 추가 신경망, 외부 모델, 새 데이터 학습, 다른 전이 법칙 실험은 이번 실행에 포함하지 않는다.

## 실행 검증·자원

사전등록 commit 이후 구현한다. CPU에서 train-only 입력/목표, 집단·구간 정렬, 보호 비용식, 동결, 보정 항등성, 실제 생성 이력의 피드백, 선택 알고리즘 및 고정 예산을 검사한다. GPU에서 같은 가중치의 확률과 순차 계산, 자원 사용을 확인한 후 탐색한다. FP32, TF32 off. 사용률≤65% 및 여유≥2GiB인 원격 GPU에서 한 작업씩, allocator4%; 다른 작업을 종료하지 않는다. GPU가 없으면 대기한다. 평가 CPU 최대2 worker/각1 thread.

코드·입력·부모·보정·생성물 hash 및 탐색 경로를 남긴다. 원본은 변경하지 않는다. compact 결과와 전체 실패를 `research/cs-saf-external-audit-v1`에 push하고 대용량 원본은 워크스테이션에 보존한다.
