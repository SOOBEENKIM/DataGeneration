# 생성 관계 보정 비교: 무엇을 바꾸는 실험인가

연구 질문은 **거래별 예측력을 유지하면서, 모델이 스스로 만든 거래열의 간격–행동 반복 관계를 더 정확히 재현할 수 있는가**다. 이번 실험은 새 신경망 구조의 우수성을 평가하지 않는다. 저장된 U/G 신경망은 동결하고 같은 10개 보정값을 학습하는 목표만 비교한다. 과거 제약 구조 C의 실패는 그대로 남는다.

| 방법 | 바꾸는 값 | 학습·선택에 쓰는 정보 |
|---|---|---|
| A: 실제 이력 보정 | 집단 2개×간격 구간 5개의 logit offset | 이전 단계에서 실제 학습 이력의 반복 예측 NLL로 맞춘 값 그대로 |
| B: 생성 관계 보정 | A와 같은 10개 값 | 생성 거래열의 구간×반복 결합 빈도와 학습 데이터 관측 빈도의 차이 |
| P: 예측 보호를 둔 생성 관계 보정 | A와 같은 10개 값 | B와 같은 차이. 실제 학습 이력에서 예측 비용이 상한을 넘는 후보는 제외 |

U는 잠재 복사 확률과 일반 행동 분포를 섞고, G는 관측 반복확률을 직접 예측한다. 둘 다 이미 과거 거래 이력을 이용하는 생성기다. G도 내부에서 구현한 신경망 구조이며, 이력을 버리고 구간 반복률로 교체하는 `direct` 통계 대조군과 다르다.

## 계산과 학습 목표

이전 행동과 같은 행동이 나올 확률을 r, 관측 집단을 g, 현재 간격의 고정 구간을 b라고 하면 보정은 다음과 같다.

\[
\widetilde r=\sigma(\operatorname{logit}(r)+\delta_{g,b}),\quad |\delta_{g,b}|\leq8.
\]

보정은 반복/비반복 사이의 확률 질량만 바꾼다. 비반복 행동들 사이의 상대확률과 첫 행동 분포는 유지한다. 보정한 분포에서 행동을 뽑고, 그 행동으로 수치값을 생성한 뒤 다음 거래 이력에 넣는다. 따라서 신경망을 고정해도 이후 간격·행동·수치값은 모두 달라질 수 있다. 완성된 표를 사후 수정하지 않는다.

학습 데이터 전체에서 집단별 `(구간 b, 관측 반복 y)` 결합 빈도 T를 만든다. 하나의 생성 난수 s에서 얻은 결합 빈도를 F라고 하면 목적함수는 다음과 같다.

\[
L(\delta)=\frac{1}{2}\sum_{s=1}^{2}\frac{1}{2}\sum_{g=0}^{1}
\sum_{b=1}^{5}\sum_{y=0}^{1}\left(F^{(s)}_{g,b,y}(\delta)-T_{g,b,y}\right)^2.
\]

즉 **두 난수 각각에서 오차를 계산한 뒤 평균**한다. 두 빈도를 먼저 합친 뒤 제곱하는 방식은 아니다. 집단별 결합 빈도는 해당 집단의 유효 전이 수로 정규화한다. 활성 집단이라는 oracle 정보를 목적함수에 넣지 않으며 두 관측 집단에 같은 가중치를 준다. 학습 목표의 구간은 A의 native gap code 구간, 최종 곡선 평가의 구간은 기존 평가기가 학습한 실제 gap 분위수 구간이다. 목적함수와 최종 지표가 완전히 같다고 하지 않는다.

P는 각 집단의 실제 학습 이력에서 A 대비 Brier 증가≤.001, 행동 NLL 증가≤.01인 값만 채택한다. 행동의 반복 여부만 보정하므로 NLL 차이는 반복 Bernoulli NLL 차이로 정확하게 계산할 수 있다. 첫 거래는 제외한다. 이 조건은 유한 학습 데이터의 제약이며, validation 예측력을 보장하는 정리는 아니다. validation에서는 별도 허용폭 .002/.02를 검사한다.

## 탐색·선택·평가의 분리

각 조건에서 학습 개체 중 집단별 1,024개를 뽑아 탐색 계획을 만들고, 겹치지 않는 다른 집단별 1,024개로 선택 계획을 만든다. 계획에서는 길이·집단만 사용한다. 관측한 첫 행동, 간격, 수치값이나 이후 이력을 복사하지 않는다. 선택 계획도 outer train 내부이고 독립 검증 데이터가 아니다.

10개 좌표를 trial별 고정 순서로 .4/.2/.1씩 세 차례 탐색한다. 매 좌표에서 ± 후보를 모두 평가하고 개선된 적격 후보만 채택한다. 후보 60개와 시작값에 각 2개 생성 난수, 시작값과 순회별 종료값 4개에 별도의 선택 난수 2개를 사용한다. **B/P 각각 130번, 매번 2,048개 거래열을 생성**한다. P가 거부하는 후보도 생성하므로 호출 예산이 같다. 선택 후보에는 A가 항상 남는다. 이산 표본을 미분하는 학습이나 새 기울기 추정기를 구현한 실험은 아니다.

모든 24개 보정 결과를 저장한 뒤에만 실제 validation과 최종 생성 난수 3개를 평가한다. 최종 계획은 과거와 같은 자연 비율의 2,048개 거래열이다. 각 부모 안에서 세 생성 난수를 먼저 평균하고 세 부모 학습 시드를 비교한다. 난수 9개를 독립 학습 9회로 세지 않는다. 길이는 공통 계획으로 주므로 길이 지표를 잘 학습한 성과로 해석하지 않는다.

## 정답 생성기 평가의 의미

별도 프로그램에서 관측 정보에 대한 semi-Markov filter로 정확한 joint 생성을 한다. 연속 gap의 CONT와 모델의 유한 gap 지지집합에 맞춘 BIN을 각각 30번 생성한다. 모델과 같은 길이·집단·표본 수를 쓰고 첫 행동과 수치값은 새로 뽑는다. 원본에서 실현된 잠재상태를 읽지 않는다. 평가 프로그램은 모든 보정 학습이 완료되어야 실행된다.

CONT는 연속 정답 분포의 표본 오차를, BIN은 간격 양자화가 포함된 비교를 제공한다. BIN의 raw reference 평가와 quantized reference 평가를 별도로 보고한다. 30번의 평균·분위수는 **이 고정 reference와 표본 크기에 대한 Monte Carlo 참고 분포**다. 엄밀한 오차 하한이나 모델 오차를 표본·구조 원인별로 분해한 값이 아니다. 분위수 안에 들어간다는 것만으로 동등성을 입증하지 않는다. 학습이나 후보 선택에는 사용하지 않는다.

## 통과와 기여의 구분

활성 생성 오차 개선만으로 통과시키지 않는다. 생성 평균 10% 및 .002 이상 개선, 시드별 기준, 예측 비용, 다른 변수의 분포 비용, 비활성 곡선·고정 이력 민감도 기준을 모두 실행 전에 고정했다. [정확한 기준](preregistration.md).

- B가 동시 기준을 통과하면 예측 보호 장치가 필수라는 주장은 하지 않는다.
- P는 동시 통과하고 B는 생성 개선을 통과하지만 예측 비용 때문에 실패할 때, 이번 조건에서 보호 장치의 유용성을 지지하는 탐색 근거가 된다.
- U/G 모두에서 효과가 있어도 가까운 두 내부 구조에서의 결과다. 외부 생성기 전반의 적용성을 입증하지 않는다.
- 기존 보정 A보다 추가 이득이 없거나 비용 기준을 통과하지 못하면 이번 후보를 채택하지 않는다. 계수·시드를 추가해 성공을 찾지 않는다.

생성 과정을 고려하는 학습이나 제약식 최적화 자체의 신규성은 주장하지 않는다. 이 실험은 기존 인공 데이터 seed42·집단 비율 10%에서의 한정된 탐색이며, 새 데이터에서의 재현·외부 모델 우월성·실제 금융 효용·학회 수준의 기여를 확정하지 않는다. G의 비반복 행동 선택 경로는 이번 실험에서 바꾸지 않는다.
