# 교수님 보고용: 간격별 보정은 도움이 되지만 E의 생성 우위는 확인되지 않음

2026-09-20 · [상세 결과·그림](gap_calibration_v1_report_2026_09_20.md)

**연구 목표:** 거래 간격에 따른 행동 관계를 잘 재현하면서, 관계가 없는 집단에는 불필요한 반응을 만들지 않는 생성 모델을 연구하고 있습니다. 기본 U도 과거 이력을 사용하며, E는 반복확률 계산부에 이력 보정을 추가한 모델입니다.

**이번에 한 일:** 이전 실험에서 확인한 간격별 예측 편향을 줄이기 위해 U와 E에 같은 5구간 보정을 적용했습니다. 기존 신경망과 이전 보정값을 고정하고 학습 데이터의 관측 행동만 사용했습니다. 4개 집단 비율·2개 조건·5개 학습 시드의 80개 보정과 400개 생성 평가를 완료했습니다.

| 집단 비율 | U 생성 오차 변화 | E 생성 오차 변화 | 개선된 학습 시드 |
| --- | --- | --- | --- |
| 5% | -11.0% | -17.5% | 각각 5/5 |
| 10% | -8.4% | -16.7% | 각각 5/5 |
| 25% | -10.6% | -13.4% | 각각 5/5 |
| 50% | -21.7% | -18.3% | 각각 5/5 |

**잘 나온 점:** 두 모델 모두 네 비율 각각의 5개 학습 시드에서 실제 생성 데이터의 반복관계 오차가 줄었고, 조건부 행동분포 예측도 개선됐습니다. 제한된 보정만으로 생성 품질의 일부를 개선할 수 있다는 결과입니다.

**남은 문제:** 같은 보정을 적용한 U와 비교하면 E의 생성 오차는 평균적으로 3.3~5.6% 더 컸고, E가 더 좋은 학습 시드는 비율별로 1/5·2/5·1/5·1/5였습니다. E의 조건부 정확도와 비활성 반응에는 상대적 이점이 남아 있지만, 이것이 생성 우위로 이어지지는 않았습니다. 또한 보정 전보다 두 모델 모두 비활성 집단의 불필요한 반응이 소폭 증가했고, U는 일부 비율에서 다른 생성 관계 지표(MI 오차)가 악화됐습니다. 따라서 모든 목표를 함께 해결한 모델로 결론 내리지 않았습니다. E/U의 오차 차이에 대한 불확실성 구간에는 0이 포함되므로 E의 일반적인 열등함을 확정하는 것도 아닙니다.

**연구 방향의 수정:** “E의 추가 이력 구조가 실제 생성 성능을 높이는 핵심 기여”라는 주장은 현재 연구 결론에서 제외하고, 조건부 예측의 이점과 실제 생성의 비용을 구분해 정리했습니다. 일반적인 간격별 보정의 효과를 E만의 기여로 설명하지 않겠습니다.

**다음 계획 제안:** 계수를 계속 늘리기보다 현재 U/E 및 보정 전후 모델을 고정하고, 우선할 생성 지표와 허용 가능한 비활성 반응 비용을 먼저 정한 뒤 새로운 데이터 생성 시드·학습 시드에서 독립 확인을 진행하는 것이 타당합니다. 이후 같은 보정 기회를 준 외부 모델 비교와 행동–사기 관계·실제 탐지 효용으로 연결해야 합니다. 이 후속 실험은 아직 실행하지 않았습니다.

CPU/GPU 검증과 원자료의 생성 지표 2,400개 독립 재계산을 통과했습니다. 이번 결과는 같은 통제 인공 데이터에서 얻은 탐색 결과이며, 실제 사기 탐지 성능이나 최종 모델의 우수성을 입증한 단계는 아닙니다.
