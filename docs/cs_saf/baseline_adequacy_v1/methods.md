# Stage 1의 비교가 의미하는 것

이 문서는 이번 비교의 해석 범위다. 결과는 같은 폴더의 완료 보고서와 CSV를 기준으로 한다. [사전등록](preregistration.md)과 [설정](../../../configs/benchmark_v2/cs_saf_baseline_adequacy_v1.json)은 과학적 실행 전에 고정했다.

## 질문과 대조군

질문은 **“외부 모델의 반복 오류가 학습 예산을 늘리거나 간단한 보정을 해도 남는가?”**다. 새 CS-SAF 신경망을 학습하는 단계가 아니다. 대표 외부 실행은 공식 `mostlyai-engine==2.4.0` TabularARGN 순차 모드이며, 기존 U도 같은 형태의 보정 기회를 받는다. U는 이미 거래 이력과 반복 재사용 경로를 가진 기준 모델이다.

| 변형 | 반복확률을 정하는 방법 | 확인하려는 것 |
|---|---|---|
| raw | 저장된 모델 그대로 | 원래 오류 |
| level | 집단별 상수 2개로 logit 이동 | 평균 반복률만 잘못 맞춘 것인가 |
| gap | 집단×간격 구간별 상수 10개로 logit 이동 | 간단한 간격별 보정으로 충분한가 |
| direct | 집단×간격 구간의 학습 반복률 10개를 직접 사용 | 모델의 반복 예측 없이도 해당 곡선을 맞출 수 있는가 |

`direct`는 학습 데이터의 반복 횟수를 세어 만든 통계적 대조군이다. 이력을 학습하는 새 신경망 head를 구현·학습한 것으로 세지 않는다. 이전 행동의 **정체**는 반복/비반복 행동을 선택할 때 계속 사용하지만, 반복할 **확률** 자체에서는 모델이 계산한 이력별 차이를 제거한다. 비반복 행동 사이의 상대확률은 원래 모델 것을 유지한다.

이러한 보정은 계수를 바꾸는 순간부터 다음 행동, 현재 수치값, 다음 거래 이력에 반영한다. 완성된 생성 표본의 행동만 사후에 바꾸지 않는다. 첫 거래는 원래 모델을 유지한다.

## 수식과 정보 범위

이력과 현재 gap을 입력받은 모델의 행동 분포를 p, 직전 행동을 m이라 하면 관측 반복확률은 r=p(m)이다. 기존 U의 잠재 copy 확률과 구분한다.

\[
r' = \sigma(\operatorname{logit}(r)+\delta_{g,b}),\qquad
p'(m)=r',\quad p'(j)=p(j)\frac{1-r'}{1-r}\quad(j\ne m).
\]

level은 b를 구분하지 않는다. gap은 집단별 native gap code 분위수로 정한 5구간을 사용한다. ARGN은 numeric bin, U는 기존 gap support이므로 정보의 해상도까지 같다고 주장하지 않는다. ARGN이 이후 무작위로 복원할 연속 gap 값을 미리 보지 않는다.

offset의 목적함수는 학습 거래의 반복 BCE와 고정 ridge다. 같은 구간의 표본 수 비중으로 규제항을 가중하므로, 각 offset의 독립 1차 조건은 `mean(sigmoid(logit(r)+delta)-y)+ridge*delta=0`이다. 최종 검증에서는 실제 학습에 사용한 L-BFGS와 다른 스칼라 root 해법으로 각 해를 확인한다. direct는 반복 횟수에 Beta(.5,.5)를 더한 값이다.

관측된 집단과 실제 거래 이력·간격·행동을 사용한다. 생성기의 정답 법칙, 관계 활성 표식, 평가 데이터는 보정의 학습 목표가 아니다. 계수 파일을 저장한 후에 validation을 읽는다. ARGN 신경망은 outer train 안의 내부 train으로 학습했고, 이번 보정은 outer train 전체를 사용했다. 두 단계의 학습 표본 범위가 다르다는 점도 공개한다.

## 학습 예산을 늘리는 방법

원래 ARGN 4개에서 선택된 checkpoint, optimizer, scheduler를 복사해 이어 학습한다. 모델·기본 손실·배치 256·변수 순서 설정은 그대로 유지하고 조기 종료 patience만 101로 늘린다. 원래 저장된 best도 후보에 포함한다. 추가 예산은 각 100 epoch 또는 30분 이내로 고정한다.

공식 내부 validation으로 선택한 모델이 주 분석 대상이다. 마지막 가중치의 실제 이력 예측은 보조 진단으로 별도 공개한다. 마지막 모델이 더 좋아 보인다는 이유로 이를 보정·생성 후보로 추가하지 않는다. 추가 100 epoch가 최적 수렴을 증명하는 것은 아니다. 공식 progress에 저장된 반올림 loss를 이전 best의 기준으로 사용한 정밀도 제한도 있다.

## 예측, 생성, 통과 기준을 구분한다

- **실제 이력 예측:** validation의 실제 이전 거래와 현재 gap을 입력한다. 반복 Brier는 거래별 이력 차이를 포함한 예측 정확도를 측정한다. 행동 NLL은 64개 행동 전체의 정답 확률을 측정한다. 곡선 L1은 5개 구간에서 평균 반복률이 맞는지를 측정한다. 세 지표는 서로 대체되지 않는다.
- **자유 생성:** 간격·행동·수치값을 모델 스스로 생성하고 생성된 거래를 다음 이력으로 넣는다. 같은 2,048개 학습 기반 개체 계획, 부모 모델마다 3개 생성 난수를 사용한다. ARGN의 native 길이 생성과 U의 고정 계획 길이는 그대로 둔다.
- **비활성 집단:** 평균 반복률 오류와 평균을 제거한 곡선 모양 오류를 구분한다. 이 집단의 관측 곡선 지표는 고정 이력에서 gap만 바꾼 인과 개입이나 민감도 검사가 아니다.
- **부작용:** gap KS, 행동 sparse TV, 수치값 KS, 길이 scaled W1을 원래 부모 모델과 비교한다. 행동 sparse TV는 상위 20개와 나머지 하나로 묶은 분포이며 64개 전체 TV가 아니다. 기본 13개 지표는 모두 보존한다.

실용 screen은 반복곡선 L1≤.03, null 모양 L1≤.02, 자기 raw 대비 gap/행동/수치값 오차 증가≤.01, 길이 오차 증가≤.02 등으로 사전에 고정했다. 생성 screen은 부모별 3개 난수의 평균에 적용하고 범위도 보존한다. 통과했다고 최적 모델이나 통계적 우월성이 증명되는 것은 아니다. 특히 단순 평균 대조보다 크게 나쁘지 않은 예측을 요구하는 screen은 강한 기존 U의 예측 정확도까지 보존한다는 조건과 다르다. 결과 보고에서 이 차이를 숨기지 않는다.

두 학습 모델의 범위나 세 생성 난수의 범위는 신뢰구간이 아니다. 생성 난수를 늘려 학습 시드 수가 늘었다고 계산하지 않는다. 과거 U와 ARGN의 학습 예산·시드도 달라서 이번 표를 최종 동등 예산 우월성 검정으로 사용하지 않는다.

## 자원과 재현

Intel Arc/XPU로 이식하지 않는다. 원격 NVIDIA에서 여유 메모리 ≥2,048 MiB 및 사용률 ≤65%를 확인한 뒤 추가 학습을 하나씩 시작한다. PyTorch allocator 상한은 GPU 메모리의 4%이며 실제 예약량도 저장한다. 이것은 CUDA 전체 프로세스 사용량의 정확한 상한이나 다른 작업과의 자원 경합이 전혀 없다는 보장은 아니다. 다른 사용자의 작업을 종료·재시작하지 않는다. CPU worker는 최대 2개, 수치 라이브러리 thread는 각각 1개다.

원본 데이터와 checkpoint는 변경하지 않는다. 결과에는 입력·보정·생성물의 hash와 코드 commit을 남긴다. 항등 보정의 동일 난수 출력 일치, 집단/이전 행동 정렬, 길이가 다른 행의 종료, 현재 정답·미래 값 누출 검사를 확인한다. 기술 smoke에서 발생한 두 오류와 수정은 [실행 기록](execution_notes.md)에 보존했다.

이번 데이터는 **기존 인공 데이터 생성 시드 42, 집단 비율 10%, 기존에 확인한 validation**이다. 새로운 데이터의 독립 확인, test 평가, 실제 거래·사기 탐지 실험이 아니다. 이번 등록 범위가 끝나면 학습을 멈추며, 후속 구조나 생성 궤적 학습은 별도 실험으로 다룬다.
