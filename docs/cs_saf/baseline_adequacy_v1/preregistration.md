# Stage 1: baseline 학습 충분성·동일 관측 반복 보정 — 실행 전 등록

이 후속은 기존 외부 audit 4회와 별개다. 기존 결과를 실패/성공으로 바꾸어 쓰지 않는다. 새로운 모델의 학습, 독립 검증, 학회 수준의 방법 기여를 이번 단계에서 주장하지 않는다.

## 고정 범위

- 기존 pi=.10, DGP seed=42, κ=0/1, 공식 ARGN 학습 시드 20260920/20260921을 유지한다. 원본 파일·checkpoint는 읽기 전용이다.
- **4회만** 저장된 최선 checkpoint에서 추가 100 epoch/30분 이내로 이어 학습한다. optimizer와 scheduler를 복구하며 모델·손실·batch 256·유연 변수 순서를 유지한다. 조기 종료 patience만 101로 늘려 추가 고정 예산 동안 종료되지 않게 한다. 공식 엔진 위에 이 등록된 실행 제어를 적용한 변형이지, 기본 설정 그대로의 공식 baseline이라고 부르지 않는다.
- 복사한 workspace의 progress를 실제 저장된 최선 checkpoint 시점으로 맞춘다. 최선 checkpoint 선택에는 기존 최선도 포함한다. 최종 학습 가중치도 보조 진단용으로 보관한다. 상한/시간에 도달해도 추가 연장하지 않는다. 이 예산으로 수렴이 입증되는 것은 아니다.
- 원래 ARGN 4개, 추가 학습 ARGN 4개, 기존 U trial 0/1×κ 2개=4개, 총 12개 부모 모델을 평가한다. U를 새로 학습하지 않는다. 두 계열의 과거 학습 예산·시드는 다르므로 최종 우월성 검정이 아니다.
- 각 부모에 raw / level / gap / direct를 적용한다. 후자의 3개는 신경망을 바꾸지 않는 작은 train-only 보정/예측 대조군이다.

## 동일한 보정이 뜻하는 것

관측 반복확률 r=p(직전 행동)를 대상으로 한다. 기존 U의 latent copy q 보정 수치를 그대로 재사용하지 않는다. **동일한 관측 확률 변환을 두 계열에 새로 적용**한다.

- level: 관측 집단별 logit offset 1개, 총 2개.
- gap: 관측 집단×5개 coarse gap 구간별 logit offset, 총 10개. level과 비교하면 기본 수준 보정과 간격별 배분의 효과를 구분할 수 있다.
- direct: 같은 집단×gap 구간에서 관측된 반복률(Beta .5/.5 평활화)을 직접 예측, 총 10개. 신경망의 반복 예측을 무시하는 통계적 head이며 새 신경 아키텍처가 아니다.
- offset은 [-8,8], ridge=1e-4, 이진 NLL로 학습한다. 범위·규제값을 결과에 따라 추가 탐색하지 않는다.
- 각 모델이 생성 당시 실제로 아는 native gap code에서 학습 집단별 20/40/60/80% 경계를 정한다. ARGN은 자체 numeric bin, U는 기존 gap support를 쓴다. 같은 형태/자유도를 제공하지만 두 모델의 양자화 정보가 같다고 주장하지 않는다. ARGN에서 나중에 무작위 복원될 실제 gap 값을 미리 보고 보정하지 않는다.
- 수정 후 p'(직전 행동)=r', 나머지 행동은 원래 상대확률을 유지한 채 합이 1-r'가 되도록 바꾼다. 첫 거래에는 적용하지 않는다. 수정된 행동을 즉시 이후 이력과 현재 수치값 생성에 반영한다. 생성 후 행동을 바꿔 끼우는 수리는 금지한다.
- fit은 outer train에서만, 정답 법칙·validation/test·활성 여부 없이 수행한다. 계수 저장 후 validation을 읽는다. 기존 U는 outer train 전체, ARGN 신경망은 그 안의 내부 train을 학습했다는 차이를 공개한다.

## 생성과 CPU gate

- external audit와 같은 2,048개 학습 기반 집단·계획 길이, 생성 시드 3개를 모든 비교에 쓴다. 12부모×4변형×3시드=144조건, 원래 ARGN raw 12조건을 재사용하므로 신규 생성 132회다. 생성 난수는 학습 반복으로 세지 않는다.
- ARGN은 공식 순차 생성/길이/복원 루프를 유지하고 mark를 뽑기 직전에만 확률을 바꾼다. hook 없는 raw와 identity adapter의 동일 seed 출력 일치, 이전 행동·현재 gap·집단 정렬, 행 종료 후 정렬, 확률 정규화와 비반복 상대확률 보존을 CPU에서 확인한 후 실행한다.
- U도 같은 계획으로 새로 생성한다. 길이는 U의 고정 계획과 ARGN의 native 생성이라는 차이를 유지·보고한다.
- 원본 hash, 학습/평가 개체 분리, 4개 parent weights 불변성, 생성 support·값, 같은 확률 변환의 numpy/torch 일치, gradient/최적화 검증을 수행한다. 기술 실패는 기록하고 원인을 바로잡되 과학적 조건을 바꾸지 않는다.

## 판단 기준과 종료

기준은 결과를 보기 전에 설정한 **탐색용 실용 기준**이며 논문의 통계적 유의성/최적 수렴 판정이 아니다. 각 학습 시드와 집단 결과를 모두 공개한다.

- 기본 예측 점검: 평균 반복률 오차 ≤2%p, Brier가 train 집단 평균 상수 대조보다 0.002 넘게 나쁘지 않음, 행동 NLL이 균등 64개 예측보다 ≥.02 nat 낮음. 관계 있음 10% 집단의 반복곡선 L1 ≤.03도 확인한다.
- 추가 예산의 기여: 같은 저장 모델 대비 Brier ≥.01 및 행동 NLL ≥.05 개선이 두 시드에 재현되는지 본다. 충족하지 않아도 구조적 학습 불가능을 뜻하지 않는다.
- 생성 점검: 관계곡선 L1 ≤.03, null 평균 제거 곡선오차 ≤.02. raw 대비 gap KS/mark sparse TV/amount KS 증가가 각각 ≤.01, length scaled W1 증가 ≤.02인지 함께 본다. 생성 3개의 평균과 범위를 공개한다. 2–3%p 기준은 표본 변동과 허용 오차를 구분하기 위한 현 단계의 screening이며 실제 금융 허용치가 아니다.
- level만으로 해결되면 수준 보정 문제, gap/direct로 해결되면 단순 조건부 보정/직접 반복 표현으로 설명 가능한 부분으로 분류한다. 이 효과를 제안 결합 모듈의 기여로 옮기지 않는다.
- 조건부 예측 gate를 통과하지 않으면 생성 경로 학습을 추가하지 않는다. 통과했는데 생성이 실패한 경우만 후속 이력/궤적 진단 후보로 남긴다.
- 이번 등록 범위에서 종료한다. 설정 추가·학습 연장·새 구조 학습을 성공할 때까지 반복하지 않는다. 결과가 기본 보정으로 설명되면 복잡한 구조의 필요성을 재검토한다.
