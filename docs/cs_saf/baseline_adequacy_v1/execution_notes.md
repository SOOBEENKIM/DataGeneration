# 기술 검증·실행 기록

- 추가 학습 CPU smoke에서 첫 호출은 공식 enum 값에 소문자 문자열을 넘겨 실패했다. 공식 `ModelStateStrategy.resume`로 수정했다. 두 번째 호출은 HuggingFace cache가 읽기 전용 경로를 가리켜 실패했다. 별도 실험 cache를 쓰도록 바꿨다. 두 실패 폴더를 각각 보존했고 과학적 추가 학습은 시작하지 않은 상태였다.
- 세 번째 CPU smoke는 저장된 optimizer/scheduler를 복구해 제한된 step을 실행하고 원본 불변성을 확인했다. smoke의 최선 가중치는 그대로 유지되고 마지막 학습 가중치는 바뀌어, 실제 업데이트와 best 유지가 각각 작동함을 확인했다.
- 확률 변환 CPU 검증에서 numpy/torch 값, 확률 정규화, 원래 반복률을 넣었을 때의 항등성, 비반복 행동 간 상대확률 보존을 확인했다.
- ARGN의 numeric bin 코드 중 MIN/MAX는 일반 bin 번호순과 값의 순서가 다르다. 학습·생성 양쪽에 같은 순서 변환을 적용해 MIN은 맨 아래, MAX는 맨 위로 보낸다. 무작위 디코딩된 gap의 미래 값을 사용하지 않는다.
- ARGN adapter는 공식 생성 함수의 정확히 한 지점에 정렬된 이전 mark와 현재 집단을 전달하는 호출을 삽입하고, mark 추출 직전 확률만 변경한다. library 파일은 수정하지 않는다. 적용한 공식 함수 소스 hash를 실행마다 남긴다.
- 공식 progress의 validation loss는 반올림된 값으로만 남아 있다. 추가 학습에서 기존 best를 포함할 때 이 저장 정밀도를 사용한다. 이를 정밀한 최적 수렴 검정으로 해석하지 않는다.
- 두 계열 모두 sampler CPU gate 통과: 같은 seed의 raw/identity 출력이 정확히 일치했다. 별도 기술 fixture에서 집단 0을 반복률 0, 집단 1을 반복률 1로 설정했을 때 554개 전이가 모두 기대값과 일치했고, 서로 다른 길이에서 개체 종료 후에도 정렬이 맞았다. 첫 거래와 원본 가중치는 유지됐다. 이 극단값은 과학적 실험의 fit 값이 아니다.
- CPU 보정·생성 worker는 최대 2개, 각각 수치 라이브러리 thread 1로 제한한다. 추가 학습은 GPU 여유 기준을 만족할 때 최대 1개만 실행한다.
- 과학적 추가 학습 4회는 모두 완료됐다. 첫 실행은 물리 GPU 1, 나머지는 GPU 0에서 시작했다. 각 실행은 시작 전 여유 메모리 ≥2,048 MiB와 사용률 ≤65%를 확인했다. 동시 GPU 학습은 1개였고 PyTorch 최대 예약 메모리는 각 444,596,224 bytes였다. 이 값은 CUDA context를 포함한 전체 프로세스 메모리 사용량이 아니다. Intel Arc는 사용하지 않았고 다른 작업을 종료하지 않았다.
- 추가 학습 epoch는 97→197, 44→144, 43→143, 35→135였고 선택 epoch는 각각 98, 144, 143, 135였다. 마지막 가중치도 보조 진단에 보존했다. 공식 루프의 epoch 상한은 nominal budget이며, 마지막 저장 가중치는 마지막 기록 validation 이후의 소수 minibatch 업데이트를 포함할 수 있다. 정밀한 step 수 동등성이나 최적 수렴의 증명으로 표현하지 않는다.
- 12개 부모×4변형×3생성 난수=144조건의 평가를 완료했다. 신규 132개 데이터셋은 270,336개 개체열, 재사용 12개를 포함한 평가 대상은 294,912개 개체열이다. 생성 난수를 독립 학습 시드로 세지 않는다. 추가 과학적 학습 재시도나 성능에 따른 계수 탐색은 없었다.
- 최종 집계 후 별도 스칼라 root 계산으로 12개 부모의 offset 최적값을 재확인했다(최대 차이 9.913e-8). direct 확률 차이는 0, 기존 ARGN 실제 이력 replay 확률 차이는 0이었다. 재사용 기본 생성 지표 차이는 9.715e-17이었다. 원본 입력·모델·optimizer·scheduler hash, 생성물 hash, 실행 중 핵심 구현 불변성을 확인했다.
- 전체 GPU 학습 dispatcher와 CPU 보정·생성 dispatcher가 정상 종료됐다. 요약·독립 검증·그림 작성도 완료했다. 이번 단계 이후의 새로운 신경망 또는 생성 궤적 학습은 시작하지 않았다.
