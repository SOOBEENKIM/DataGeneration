# 교수님 보고: 조건부 정확도가 생성 품질로 이어지지 않는 이유의 진단

> 후속 진단 완료: [동일 이력 교차 평가와 joint-oracle 결과](replay_oracle_v1_report_2026_09_17.md)를 함께 읽어야 한다. 정확한 online oracle도 gap 경로를 강제하면 반복관계가 왜곡됐다. 아래의 역사적 수치는 유지하지만, OBS의 증가만으로 신경망 mark 이력 결함을 단정할 수 없다. 다음 진단은 더 이상 미실행 상태가 아니다.

**실제 gap과 수치값을 유지해도, 모델이 생성한 mark를 다음 이력으로 넣는 단계에서 상대 오차가 증가하는 근거를 확보했다.** 우선 수정·검증 대상으로 mark 이력의 피드백과 생성 경로의 보정을 좁힐 수 있다. 다만 혼합 입력에 대한 민감도 진단이므로 유일한 원인을 인과적으로 확정한 것은 아니며, 개선된 새 모델을 학습한 결과도 아니다.

## 완료한 작업

저장된 U/E/L003 best checkpoint 120개(네 집단 비율, κ=0/1, 5개 모델 trial)를 모두 평가했다. 기존 validation·자유 생성 지표를 재현하고, 집단별 고정 128개 entity와 3개 생성 난수로 네 단계의 생성 비교 368,640개 시퀀스를 실행했다. 신규 학습은 0회다. 실제 이력 → mark만 재귀 생성 → gap 대표값 치환 → gap 자체 생성 → 수치값 자체 생성의 순서로 비교했다. 기존 ER 실패 판정은 유지했다.

**구분한 설명은 다음과 같다.**

- full-mark TV뿐 아니라 실제 이력의 반복 절대오차와 factual TV도 평균적으로 개선됐다. 비반복 mark 부분만 좋아져 기존 정확도 개선이 생겼다는 가설은 이번 결과와 맞지 않는다.
- 이산화, gap 자체 생성, 수치값 자체 생성의 추가 단계는 여러 비율에 걸친 등록 기준을 통과하지 않았다. 하지만 일부 비율에서는 영향이 있어 이 경로들을 무관하다고 배제하지 않는다.
- L003은 25/50%에서 실제 이력의 집계 반복곡선 보정도 E보다 나빴다. 모든 문제가 재귀 생성 이후에 처음 시작되는 것은 아니다.
- 기존 자유 생성에서 현재 mark의 추출 잡음을 줄여 모델 확률을 평균해도 L003−E 오차가 네 비율 모두 양수다. 평균 곡선은 짧은 gap의 반복을 낮게, 긴 gap의 반복을 높게 예측하며 L003에서 양 끝이 더 평평해진다. 이력별 평균 정확도와 생성 경로에서 집계된 관계 보존은 다르다.

## 한계와 다음 방향

OBS는 관측 gap에 생성 mark를 결합한 혼합 경로이며 true joint DGP의 적법한 인과 대조군이나 미래 gap까지 조건화한 정확한 생성기가 아니다. 모델별로 방문한 이력도 달라서 예측 함수와 이력 분포의 기여를 완전히 분리하지 못했다. 비활성 조건에도 일부 효과가 있었다. 기존 데이터·validation 재사용, 하나의 고정 panel, 세 생성 난수라는 한계가 있다.

다음은 **같은 생성 이력에 U/E/L003를 교차 적용하는 비교와 올바른 joint oracle rollout 대조군**을 별도로 등록하는 것이 타당하다. 이후 근거에 따라 생성 중의 gap–repeat 보정·여러 단계 관계를 직접 다루는 제한된 학습 수정을 비교해야 한다. 어떤 손실·구조 수정이 해결책인지는 아직 입증되지 않았다. 이 다음 작업은 제안이며 현재 실행하지 않았다.

진단 코드와 결과의 저장으로 이번 실행을 마친다. 새 모델 학습 성공이나 외부 baseline 대비 새로운 우위를 주장하지 않는다. CPU 9개·GPU 기능 12개 검증, 120개 job의 확률·불변성 검사, 입력/출력 해시 1,440개 재검증을 완료했다. GPU 프로세스는 종료했다.
