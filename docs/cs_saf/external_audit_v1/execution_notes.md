# 실행상의 확인과 수정

- 원래 환경은 변경하지 않고 별도 Python 환경을 설치했다. 공식 2.4.0 소스를 사용했으며 신경망·손실·최적화는 수정하지 않았다. 2.7.0 최신 HEAD를 실행했다고 하지 않는다.
- CPU 학습·checkpoint 재로드·생성·인코딩 왕복 검증 통과. 진단 네트워크의 현재 정답/미래 정보 불변성과 prefix 일치도 통과했다.
- 초기 CPU 진단 호출의 wildcard import에서 비공개 함수 이름이 제외되어 NameError가 났다. 명시적 import로 바로잡았다. 학습/평가 수치와 무관한 호출 오류다.
- 첫 저장 모델의 읽기 전용 replay에서 Pandas nullable string의 첫 행 비교가 NA여서 정수 변환이 실패했다. 첫 거래의 반복 여부는 정의되지 않고 모든 관계 평가에서 제외된다. 그 구조적 첫 비교만 False로 표시해 직렬화를 가능하게 수정했다. 원래 생성값·모델·학습 조건은 바꾸지 않았다. 실패 log를 보존하고 replay만 재실행한다.
- 공식 순차 손실의 정규화는 배치 마스크 총합을 사용하므로 로그 NLL의 절대 크기를 U/E 또는 다른 batch size와 비교하지 않는다. 같은 설정의 공식 checkpoint 선택을 그대로 사용했다.
- 사전등록한 시간/epoch 상한을 그대로 유지한다. 상한에서 종료되면 최적화 미완료 가능성을 별도 기재하며 구조적 불가능성을 주장하지 않는다.
