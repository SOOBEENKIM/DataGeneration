# 외부 순차 모델 오류 위치 확인 — 실행 전 고정

이 실험은 E를 성공시키기 위한 추가 조정이 아니다. 과거 이력과 집단 정보를 이미 사용하는 공개 순차 모델에서도 현재 연구 문제가 남는지 확인하고, 그 결과에 따라 다음 모델 후보를 선택한다. 외부 모델의 실패와 새로운 구조의 성공을 미리 전제하지 않는다.

## 대표 모델과 실행 범위

- 공식 TabularARGN (`mostlyai-engine==2.4.0`), 최신 저장소 HEAD 2.7.0과 구분한다. 2.4.0은 현재 Python 3.10에서 실행 가능한 공식 배포판이며 별도 환경에 설치한다. 최신 버전 전체를 재현했다고 하지 않는다.
- TabDiT는 공식 HEAD 소스를 확보했으나 학습·생성 구현이 없다. 비교 제외 사유를 공개하고, 점수나 가짜 대체 구현을 만들지 않는다. 기존 CPAR 결과는 유지하고 REaLTabFormer는 후속 외부 보강 후보로 남긴다.
- 비율 10%, 관계 없음/있음 두 조건, 학습 시드 2개 = 4회. 기존 데이터 생성 시드 42, 전체 학습 집단만 모델에 입력. 모델 내부 검증 분할도 외부 학습 집단 안에서 만든다. 외부 validation은 결과 측정 전용. test와 정답 법칙은 학습에 넣지 않는다.
- 최대 100 epoch / fit당 30분, 공식 조기 종료와 최저 내부 검증 손실 checkpoint. 시간 제한으로 종료되면 최적화 미완료 가능성을 표시하며 구조 한계로 단정하지 않는다. 결과를 보고 예산·시드·모델 크기를 추가하지 않는다.
- 각 checkpoint에서 같은 학습 집단 기반 2,048개 context/계획 길이를 제공하고 생성 시드 5개를 사용한다. 시드 5개는 학습 5회가 아니다. TabularARGN은 길이를 직접 생성하므로 계획 길이와 실제 길이의 차이를 별도 보고하고 자르거나 채우지 않는다.
- 집단은 범주형, 행동은 범주형, gap/수치값은 공식 numeric auto를 사용한다. ID와 시간 인덱스는 예측 특징에서 제외한다. 첫 gap=0 호환 표시는 평가 시에만 missing으로 복원한다. 그 외 값의 사후 수리는 금지한다.

## CPU 검증과 오류 분리

1. 학습 집단 일부의 CPU 짧은 실행은 연결·저장·재생성·유효성 검증 전용이며 과학적 결과와 구분한다.
2. 학습에서 정한 공식 인코더/디코더로 외부 validation을 왕복 변환한다. 원본 대비 관계·개별 분포 변화가 이미 큰지 본다. 변환 과정에서 읽은 validation으로 통계나 모델을 업데이트하지 않는다.
3. 원래 validation을 기준으로 자유 생성의 반복률 곡선 L1, 전이 조건부 TV, MI, gap/행동/금액 분포, 자기상관, 길이 오차를 집단별로 모두 보고한다. 관계 없음 조건에서도 동일하게 측정한다. 관측 반복률 오차를 고정 이력에서의 인과적 반응과 혼동하지 않는다.
4. 가능한 경우 원래 이력에서의 확률과 생성 이력에서의 확률을 동일한 공식 네트워크로 측정한다. 순차 추론 API가 지원하지 않으면 별도 검증한 내부 adapter가 필요하며, 확인 없이 원인을 노출 편향으로 명명하지 않는다.
5. 표본 변동은 생성 시드별로 보고하고, 기존 U/E/보정 결과는 동일한 지표·데이터 조건의 참고 비교로만 사용한다. 서로 다른 학습 예산/길이 조건과 새로운 생성 계획을 명시한다. 두 학습 시드의 순위로 우월성 검정을 하지 않는다.

## 구조 선택 규칙

- 왕복 변환에서 주 오류가 발생하면 먼저 표현과 복원 문제를 해결한다. 이력 모듈 추가를 해결책으로 선정하지 않는다.
- 왕복 변환은 잘 보존되지만 실제 이력에서도 조건부 관계를 못 배우면 관계 추정/학습 가중의 문제를 먼저 다룬다.
- 실제 이력의 예측보다 자기 생성 이력에서 반복적으로 오류가 커지고, 단순 동일 보정으로 해결되지 않는 경우에만 생성 경로를 대상으로 하는 학습 후보를 우선한다.
- 선행모델이 현재 문제를 충분히 해결하면 현재 인공 데이터의 E 우수성 주장을 중단하고 다른 실제 미해결 과제를 찾는다.
- 전처리와 생성오차 차이는 진단 근거이지 순수한 인과 분해가 아니다. 복수 원인이 남으면 불확실성을 그대로 남긴다.

## 다음 방법 후보의 지위

이력 인코더 → gap/행동의 개별 분포 → 관계 결합 모듈 → 순차 생성 → 학습 데이터의 관계 통계와 비교하는 구조는 **검증 후보**다. 같은 이력에서 주변 분포를 유지하는 제약, copula/Sinkhorn, 생성 이력 학습은 각각 기존 아이디어다. 이를 합쳤다는 사실만으로 새 기여라고 하지 않는다. 생성 경로 전체에서 주변 분포가 유지된다는 주장도 하지 않는다.

방법 기여를 주장하려면 같은 기반 모델의 일반 목적함수, 같은 보정, 단순 생성 통계 손실, 제안 결합 제약의 차이를 분리해야 한다. 이후 고정한 허용 손실과 독립 데이터·학습 시드, 다른 관계 법칙, 실제 데이터/탐지 효용 검증이 필요하다. 이 단계가 끝나기 전에 최종 논문 구조나 학회 수준의 성과를 확정하지 않는다.
