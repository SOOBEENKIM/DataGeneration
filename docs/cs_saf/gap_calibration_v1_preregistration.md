## Hypothesis and exactly one change

The current groupwise affine calibration still leaves gap-dependent repeat-curve bias. Test whether a bounded, train-only coarse-gap logit offset helps native generation, and whether E adds benefit over U after the SAME extension. Freeze every neural weight AND the previously fitted four affine scalars in each Ucal/Ecal. Only new group-by-gap offsets are fitted. Call the resulting models Ugap/Egap. Do not fit to replay plots, validation summaries, oracle targets, latent states or generation outcomes.

For observed context s and support bin k, define z_cal=a_s+b_s*z_base, q_gap=sigmoid(z_cal+delta[s,B_s(k)]), R_gap=q_gap+(1-q_gap)*f(previous|history). Fresh-mark, history encoder, gap/value heads, a and b remain frozen. First-event fresh probabilities are unchanged; subsequent events use complete recursively generated histories. A changed repeat law can indirectly change all later variables.

Use five coarse gap bins per context. Compute .2/.4/.6/.8 quantiles (NumPy linear method) of NONFIRST TRAIN gaps after mapping through the original float32 support code and float32 support representatives; group by observed code3/4. Map support representatives with searchsorted(side=right). Stop on duplicate edges or empty bins; no outcome-driven regrouping. Same train-derived map and weights for U/E and every trial in a data cell. No extra continuous sub-bin information is introduced. Metric bins remain the historical native metric bins; calibration bins need not be identical to metric bins.

For each context fit five deltas with sum_b w[s,b]*delta[s,b]=0, where w are TRAIN transition frequencies, and -0.5<=delta<=0.5. This is four new effective degrees of freedom per context, eight total (ten stored offsets minus two constraints), on top of four FROZEN old scalars. Centering is in logit space: it does NOT keep the mean repeat probability fixed and is not itself the proposed solution. In the zero-gap intervention control, disable both the original current-gap route and the new gap offsets, retaining the original history/affine terms.

Fit each context independently by mean observed-repeat NLL plus (lambda/2)*sum_b w_b*delta_b^2 with lambda=.001. SLSQP, analytic gradient, zero initialization, box bounds, one equality constraint, maxiter500, ftol1e-12. Same input transitions, feature batch512, precision, bounds and budget for both models. No lambda/bin-count/bound search, no validation-based selection, no second initialization. Require success, finite parameters, feasibility (1e-8), penalized objective no greater than zero-offset objective (1e-10); report all bounds hits and fit details. Computational failures stop dispatch and require a documented implementation correction, not coefficient changes.
