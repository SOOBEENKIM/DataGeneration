# 교수님 보고용: 같은 이력을 넣어도 생성 관계의 차이가 남는가

2026-09-20 · [상세 결과·그림](calibrated_replay_v1_report_2026_09_20.md)

**연구 목표:** 거래 간격에 따라 필요한 행동 관계를 재현하면서, 관계가 없는 집단의 불필요한 반응을 억제하는 순차 생성 모델을 연구하고 있습니다. 기본 U도 과거 이력을 사용하며, E는 반복확률 계산부에 추가 이력 보정을 넣은 모델입니다.

**이번 실험:** 같은 확률 보정을 적용한 뒤에도 E의 생성 관계 오차가 더 컸습니다. 원인을 좁히기 위해 저장된 U/E 생성 이력을 두 모델에 똑같이 넣어 비교했습니다. 4개 집단 비율·2개 조건·5개 학습 시드·5개 생성 난수의 **400개 저장 경로, 800회 교차 평가**를 완료했습니다. 재학습·재보정·새 생성은 하지 않았습니다.

| 집단 비율 | 같은 입력에서 E의 반복확률 곡선 오차 증가 | 오차가 증가한 학습 시드 |
|---|---:|---:|
| 5% | +0.003157 | 4/5 |
| 10% | +0.002620 | 4/5 |
| 25% | +0.001024 | 4/5 |
| 50% | -0.000234 | 2/5 |

양수는 E+보정의 오차가 더 크다는 뜻입니다. 예측 반복확률을 간격 구간별로 평균해 validation의 관측 반복률과 비교한 오차입니다. U 이력을 공통으로 넣은 예측기 차이와 E 이력을 공통으로 넣은 예측기 차이를 평균했습니다. 각 학습 시드에서 생성 다섯 결과를 먼저 평균한 뒤 시드끼리 비교했습니다.

- **확인한 점:** 5%·10%·25%에서는 입력 이력을 같게 해도 E의 집계 반복확률 곡선 오차가 더 컸습니다. 따라서 생성 이력이 달라진 효과만으로는 기존 생성 품질 차이를 설명할 수 없습니다. 특히 짧은 간격의 반복률 과소예측과 긴 간격의 과대예측이 E에서 더 커지는 평균 패턴이 있었습니다.
- **해석의 범위:** 일부 중간 구간은 개선됐고 50%는 같은 방향이 아닙니다. 5%·25%는 학습 시드 간 참고 구간에 0이 포함됩니다. 기존 조건부 예측의 이점은 유지되지만, 실제 생성 우수성은 여전히 입증되지 않았습니다. 이번 진단만으로 이력 encoder 또는 추가 계수만의 결함을 확정할 수 없습니다.
- **다음 제안:** 반복확률의 간격별 편향을 겨냥한 제한된 추가 보정을 U/E에 동일하게 적용해 보겠습니다. 학습 데이터의 관측값만 사용하고 실제 생성 오차·조건부 정확도·비활성 반응을 함께 평가해야 합니다. U에서도 같은 개선이 나오면 일반 보정의 효과와 E 구조의 기여를 구분하겠습니다. 이 후속 수정은 아직 사전등록·실행하지 않았습니다.

평가 방법과 인과적 해석을 구분하며 연구 질문에 맞춰 원인을 좁히는 과정입니다. 차별화된 방법의 기여를 주장하려면 수정 후 새로운 데이터·학습 시드와 공정한 외부 비교에서 재확인이 필요합니다. 현재는 인공 데이터의 진단 결과이며 실제 사기 탐지 효용을 입증한 단계가 아닙니다.
