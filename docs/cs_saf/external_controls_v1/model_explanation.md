# 이번 비교의 모델을 설명하는 한 장

**목표:** 금융 거래의 시간 간격·행동·금액이 서로 맞는 거래열을 생성한다. 이번 비교는 현재 반복 중심 구조가 필요한지 결정하기 위한 탐색 실험이다. 사기 탐지 성능이나 최종 방법의 우수성을 입증한 결과로 설명하지 않는다.

## 모든 신경 모델이 공유하는 뼈대

```mermaid
flowchart LR
    A[고객·계좌 정보와 최근31거래] --> B[GRU 이력 요약]
    B --> C[다음 거래 간격]
    C --> D[다음 행동]
    D --> E[금액]
    E --> F[거래 종류·가맹점 범주]
    F --> G[생성 거래를 다음 이력에 추가]
    G --> A
```

각 출력은 앞서 생성한 필드와 이력 요약을 함께 사용한다. Berka의 행동은 거래 operation, 보조 범주는 transaction_type이다. Sparkov의 행동은 merchant, 보조 범주는 category다. 자료를32거래에서 잘라 버리지는 않지만 한 번에 직접 보는 과거는31거래다. 모델은 관측 이력에서 학습하고, 생성 시에는 자기가 만든 거래를 다시 입력받는다.

## 행동을 만드는 세 가지 방식

| 방식 | 다음 행동을 뽑는 방법 | 이번에 답하려는 질문 |
|---|---|---|
| U | 이전 행동을 복사하거나 일반 행동 분포에서 뽑는다. 일반 분포에서도 이전 행동이 나올 수 있다. | 복사/일반 선택 혼합으로 충분한가? |
| G | 반복 여부를 먼저 뽑고, 반복하지 않을 때 이전 행동을 제외한 후보 중 고른다. | 관측 반복확률을 직접 표현하면 도움이 되는가? |
| D | 이력·간격·직전 행동을 받아 모든 행동의 확률을 한 번에 계산한다. | 별도의 반복 구조 없이도 충분한가? |

U/G/D 모두 과거 이력을 사용한다. 이력을 쓰는 사실 자체를 기여로 설명하지 않는다. D에도 직전 행동을 명시적으로 제공하고 전체 파라미터 수를 U/G_both의1% 이내로 맞췄다.

## 이번에 바꾼 두 부분

- **금액 변경(amount):** 기존에는 변환된 금액에 Gaussian 하나를 사용해서 음수가 나올 수 있었다. 새 출력은 양수 금액 크기의 세 분포를 섞고, 학습 자료에0이 있으면0 확률도 따로 학습한다. 생성 후 음수를 잘라내는 처리가 아니다. 다른 규모의 금액과 꼬리를 더 잘 표현하는지도 평가한다.
- **행동 변경(action):** 기존에는 현재 간격이 반복확률에만 직접 들어갔다. 새 경로는 다른 행동끼리 고를 때도 현재 간격을 사용한다. 예를 들어 반복하지 않는다는 조건에서 A와 B 중 선택하는 비율이 간격에 따라 달라질 수 있다.

`U_amount`는 U의 금액만, `U_action`은 행동만, `U_both`는 둘 다 바꾼다. G도 동일하다. `D_both`는 새 금액 분포와 일반 행동 구조를 쓴다. 예전 E/ER/C와 생성 손실을 추가로 누적한 구조가 아니다.

## 결과를 읽는 방법

1. 원래 U/G와 비교해 어떤 기본 수정이 효과가 있었는지 본다.
2. U/G_both와 D_both를 비교해 반복 전용 구조의 추가 이득을 본다.
3. 관측 빈도 기반 단순 전이 모델과 비교해 복잡한 모델이 필요한 성능 근거가 있는지 본다.

조건부 예측과 자유 생성의 관계 오차를 함께 확인한다. 일반 D면 충분하다면 반복 전용 구조의 기여를 주장하지 않는다. U/G가 낫더라도 학습 seed 하나의 탐색 결과이므로 후보로만 남긴다.

**이 비교는 완료했다.** 금액 출력 개선에는 효과가 있었지만 U/G가 일반 D보다 예측·생성 관계를 함께 개선한다는 근거는 얻지 못했다. 일반 D도 단순 전이 모델과의 격차와 Berka 금액 꼬리 문제가 남아 최종 채택하지 않는다. 자동 수정·시드 탐색을 멈추고 현재 구조와 확인된 효과를 정리한다. [실제 결과](README.md).
