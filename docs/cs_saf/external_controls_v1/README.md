# 금액 출력·현재 간격 행동 선택: 한정된 외부 비교

**실행 전 등록 및 구현 검증 완료. 과학 실험 결과는 아직 없다.**

이 단계에서는 계수나 시드를 탐색하지 않는다. Berka/Sparkov에서 기존 U/G와 금액만 변경·행동만 변경·둘 다 변경한 U/G, 그리고 반복 gate 없는 일반 모델을 비교한다. 신규 학습14회, 생성56개로 고정했다. [사전등록](preregistration.md)에 구조, 수식의 의미, 평가·종료 기준을 기록했다.

실행 전 CPU 테스트34개가 통과했다. 혼합 lognormal 밀도를 SciPy와 대조하고 Jacobian, 0 질량, 양수 support, strict-past, 긴 생성의 이력 재입력, 이전 구현과의 동일성, 간격별 행동 변화, 보정 범위를 확인했다. 개발 데이터 전체1,990,071거래의 금액 target support와7개 새 모델의 경계 입력을 검사했다. GPU에서도8개 자료/모델 조합의 forward/backward가 유한함을 확인했으며 가중치 갱신은0회다.

일반 D와 U/G_both의 파라미터 수는 Berka127,378 대127,293, Sparkov288,877 대289,254다. 차이는0.14% 미만이다. 같은 정보·비슷한 용량을 제공한 비교이며 같은 함수/최적화 문제라는 주장은 아니다.

기존 결과와 테스트는 바꾸지 않았다. 결과가 나온 뒤 이 문서를 실제 효과·비용과 구조 선택 근거로 갱신하며, 자동 후속 수정이나 시드 확대는 하지 않는다.
