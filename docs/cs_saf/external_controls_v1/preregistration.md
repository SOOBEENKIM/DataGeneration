# 외부 금액·행동 출력 비교: 실행 전 등록

출발점은 `34ee431`의 Berka/Sparkov 외부 파일럿이다. 이전 결과와 실패 판정을 유지한다. 이번 실험은 **모델 설명과 후보 선택을 위한 한정된 탐색 비교**이며, 완료 후 자동으로 구조·계수·시드를 늘리지 않고 결과 정리 단계에서 멈춘다.

## 질문과 고정된 비교

1. 금액 분포만 바꾸면 비음수 유효성과 종류/범주–금액 관계가 좋아지는가?
2. 현재 gap을 비반복 행동의 상대확률에도 제공하면 시간–행동 관계가 좋아지는가?
3. 두 변경을 합친 U/G가 같은 정보·비슷한 용량의 일반 categorical 행동 head보다 추가 이득을 내는가?

자료마다 기존 U/G를 재사용하고 U/G × (금액만, 행동만, 둘 다) 6개와 일반 head D_both 1개를 학습한다. **새 신경 학습은 7×2=14회**다. 기존 4개 U/G fit은 새 학습 횟수에 포함하지 않는다. 고정 학습 seed 20260925, 생성 seed 20261021/20261022를 유지한다. 각 새 모델에 raw와 동일 gap 보정을 평가하므로 **새 생성물은 14×2×2=56개**다. raw가 주 분석, 보정은 보조 분석이며 좋은 쪽을 선택해 주 결론을 바꾸지 않는다.

이전 공식 ARGN/CPAR-tail과 관측 Marginal/Transition 결과는 참고 기준으로 재사용한다. 이번에는 재학습·튜닝하지 않으며 CPAR 학습 충분성, ARGN 길이·전처리 차이의 기존 한계를 유지한다.

## 구조

공통: 기존 GRU, 정적 정보, 과거 최근31거래, gap support, auxiliary 생성 순서, 실제 생성된 모든 필드의 다음 이력 반영을 유지한다. 미래 사기 라벨·정답 생성 법칙·test는 사용하지 않는다. Sparkov category→merchant로 생성 순서를 바꾸는 수정은 이번 범위에 넣지 않는다.

- **금액:** fit의 양수 금액 log(a)를 표준화하고 3성분 lognormal 혼합으로 모델링한다. fit에서 0이 관측되면 0 질량을 별도로 학습한다. 성분 수/scale 범위는 고정하며 양수 성분의 평균은 제한하지 않는다. 이력에는 기존 signed-log1p 표준화 표현을 유지한다. loss는 Jacobian을 포함해 기존 금액 좌표의 밀도로 계산하고, 0은 별도 질량이다. 0 질량이 생기는 만큼 옛 연속 Gaussian과 완전히 같은 기준측도라고 주장하지 않는다. checkpoint는 각 모델 내부 check loss로만 선택하며 서로 다른 모델의 loss 숫자로 우열을 정하지 않는다. 생성 금액은 float64 원표본을 저장하고, 이력에 들어갈 표현만 float32로 만든다. 이는 clipping이 아니며 0의 역변환 반올림을 막는다. 양수 크기·꼬리 표현 변경의 효과와 support 효과는 이 실험만으로 추가 분리하지 않는다.
- **행동:** U/G의 기존 fresh logits에 `W_gap e(gap)`을 더한다. 초기 추가 가중치는 0으로 기존 행동 분포에서 시작한다. 반복 gate와 그 밖의 구조는 유지한다. 새 경로는 다른 행동 간 상대확률에 현재 gap을 제공한다. 이 용량 증가는 이식 변경으로 공개하며 효과를 순수 정보 효과로만 단정하지 않는다.
- **일반 D:** 이력·정적 정보·현재 gap·직전 행동 embedding·첫 거래 여부를 받아 MLP→categorical로 다음 행동 전체를 직접 예측한다. 반복 gate/복사 혼합/제약은 없다. 첫 거래의 직전 행동 embedding은 0이다. U/G_both와 행동 head 용량이 가깝도록 은닉 폭을 공식으로 정하고 전체 파라미터 차이1% 이내를 CPU 검사한다. 동일한 파라미터 수가 같은 표현력/최적화를 보장하지는 않는다.

U/G의 공통 초기 tensor는 이전 저장 initial.pt와 정확히 일치시킨다. 추가·교체 head는 고정 seed/fit 통계로 초기화한다. 새 모델 전체의 초기 함수가 같다는 주장은 아니다. D는 공통 backbone/다른 출력의 초기 tensor만 공유한다.

## 자료·학습·생성

기존 input/preflight 해시와 fit/check/validation 개체 분할, 모든 거래 target, 128개 context와 길이 계획, 지표 구간을 그대로 쓴다. 새로운 amount 통계는 fit만 사용한다. 모든 head의 일반 likelihood 합, Adam .001, batch512, gradient clip1, 최대30epoch/20분, check patience5를 유지한다. 시간 상한은 epoch 종료 시 확인한다. GPU 병렬 실행 시 실제 학습량 차이와 상한 여부를 반드시 보고한다.

출력 전처리는 모델별로 숨겨서 유효값으로 수리하지 않는다. 비유한 생성값은 실패 기록 후 중지하며 난수 재시도나 clipping으로 숨기지 않는다. 두 데이터는 이미 검토한 개발 자료다. 이번 validation은 독립 확증이 아니다. 학습 seed1개/생성2개로 통계적 우수성을 주장하지 않는다.

## 주지표와 실행 전 판단 기준

주지표는 이전 그대로 Berka `daily_gap_mark_joint_tv`, Sparkov `gap_root_transition_joint_tv`, 두 자료 `root_amount_joint_tv`다. 생성2회의 평균과 각각의 값을 전부 공개한다. 다음 수치는 효과·비용을 구분하기 위한 **탐색적 사전 기준**이며 업무 효용으로 검증된 임계값이나 통계적 유의성 기준이 아니다.

- 금액 효과: 같은 U/G 기존 출력 대비 amount 공동 TV가 **.02 이상이면서10% 이상 감소**, 음수/비유한 금액0, 행동 관계 TV 증가≤.01.
- 행동 효과: 같은 U/G·같은 금액 설정 대비 행동 관계 TV가 **.01 이상이면서10% 이상 감소**, amount 공동 TV 증가≤.01. legacy와 수정 amount에서 각각 비교한다.
- 공통 비용: 실제 validation mark NLL 증가≤.02, 반복 Brier 증가≤.002, amount log-MAE 증가≤max(.01, 기준×5%), 생성 gap TV/mark TV/root TV/amount KS 증가 각각≤.01. 예측 amount point는 예전 Gaussian의 평균 좌표, 새 혼합의 기대 log1p를 quadrature16으로 계산한 좌표다. 서로 다른 분포에서의 이 점예측 차이도 기록한다.
- 둘 다 수정한 구조의 후보 기준: 자기 기존 모델보다 두 주지표가 각 위 개선폭을 충족하고 공통 비용/유효성 통과.
- **반복 구조의 추가 이득 후보:** U_both/G_both 각각 D_both 대비 행동 관계가 .01 및10% 이상 개선되고 amount TV 비용≤.01, 공통 비용 통과. 추가로 Transition 대비 두 주지표가 .01 넘게 뒤지면 외부 확대 후보로 승격하지 않는다. 같은 기준을 데이터별로 보고하며 두 자료 모두 통과해야 공통 후보라 부른다. 좋은 자료나 U/G만 사후 골라 보편 기여로 표현하지 않는다.

항목 하나의 성공과 전체 후보 기준 통과를 분리한다. 외부 자료에는 알려진 비활성 집단 정답이 없으므로 인공 데이터의 null-safety를 입증했다고 표현하지 않는다. 새로운 null 집단을 평가 결과를 보고 만들지 않는다.

## 종료·검증

CPU에서 혼합 밀도/Jacobian/0 질량, 출력 support, mark 정규화와 gap 경로, strict-past, 32거래 이후 replay, 초기값/용량, 보정 범위를 검증한다. 전체 fit/check/validation의 amount target support를 검사한다. CPU 통과 후 코드·설정·등록을 커밋하고 GPU 작업을 시작한다. 작업 시작마다 GPU 사용률<5%·메모리<512MiB를 확인한다. 다른 작업을 종료하지 않는다.

등록된14회와 평가를 마치면 저장 checkpoint 및 생성물 지표를 별도 집계로 검산하고, 설정별 효과/비용/실패를 모두 표로 공개한다. 기술 실패는 보존하고 원인·수정이 필요한 경우 별도 정정으로 남긴다. 방법 실패를 지우기 위해 계수/시드/성분 수를 추가하지 않는다. **완료 후 설명 가능한 구조·확인된 효과·미확인 기여를 정리하며 종료한다.**
