# 교수님 보고용: 같은 보정 후에도 추가 이력 구조가 필요한가?

2026-09-20 · 통제된 인공 거래 데이터 · [상세 결과](calibration_u_control_v1_report_2026_09_20.md)

**무엇을 연구하는가:** 과거 거래를 바탕으로 새 거래를 순차 생성할 때, 거래 간격과 행동 반복 사이에 존재하는 관계는 재현하고 관계가 없는 집단에서는 불필요한 반응을 줄이는 모델을 연구하고 있습니다. 기본 U도 이력을 사용하며, E는 행동 반복확률 계산부에 추가 이력 보정을 넣은 모델입니다.

**이번 질문:** 앞서 E의 반복확률을 보정하자 평균 생성 오차가 줄었습니다. 이것이 추가 이력 구조의 효과인지 확인하기 위해 **U에도 동일한 보정**을 적용했습니다. 기존 모델은 고정하고 학습 데이터만으로 네 값씩 보정했으며, 네 집단 비율·두 조건·다섯 시드의 40개 비교를 추가했습니다.

| 집단 비율 | U+보정 생성 오차 | E+보정 생성 오차 |
|---|---:|---:|
| 5% | 0.031640 | 0.034517 |
| 10% | 0.030563 | 0.033105 |
| 25% | 0.025389 | 0.027262 |
| 50% | 0.019344 | 0.019670 |

작을수록 좋으며 각 값은 다섯 시드 평균입니다. 간격·행동·수치값을 모두 모델이 생성했을 때의 반복관계 오차입니다.

- **잘 나온 점:** 같은 보정 후에도 E는 U보다 다음 행동의 조건부 예측 오차와 불필요한 반응이 네 비율 각각 5/5 시드에서 작았습니다.
- **남은 문제:** E의 생성 반복관계 오차는 평균적으로 U+보정보다 컸습니다. 다만 시드 차이의 참고 구간이 모두 0을 포함해 U의 일관된 우월성까지 입증한 것은 아닙니다. 조건부 예측의 개선이 실제 생성 품질로 이어졌다는 주장은 아직 할 수 없습니다.
- **알게 된 점:** U도 같은 보정으로 평균 생성 오차가 줄었습니다. 따라서 앞선 보정 효과를 E 구조만의 기여로 설명하면 안 됩니다. U 보정과 E 구조 모두 등록한 생성 오차 일관성 기준을 충족하지 못했습니다.
- **다음 계획:** 먼저 구조와 보정값을 고정한 채 여러 생성 난수로 반복 평가하여, 생성 오차 차이가 표본 변동인지 반복되는 현상인지 구분하겠습니다. 이후 근거가 확인된 부분만 수정하고, 새로운 데이터·학습 시드와 외부 모델 비교로 재검증하겠습니다. 이 다음 실험은 아직 등록·실행하지 않았습니다.

현재까지는 정답 관계를 아는 인공 데이터에서의 결과이며, 실제 사기 탐지 개선이나 최종 생성 모델의 우수성을 입증한 단계는 아닙니다. 실행·독립 수치 검증은 완료했고, 모든 결과를 연구 브랜치에 보존했습니다.
