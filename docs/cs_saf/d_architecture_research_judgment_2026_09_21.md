# D 아키텍처와 연구 방향의 재판정 — 2026-09-21

검토 기준: `research/cs-saf-external-audit-v1`, 결과 commit `bc5a5314025f64b1bb619c4f7e1b7f48674183a6`.
이번 작업은 소스·저장 결과·선행논문 원문의 검토다. **신규 학습, 생성, 보정, seed 확대는 없다.**
아래의 검증 수치는 이미 완료된 검사 기록이며 이번에 재실행했다는 뜻이 아니다.

## 판단

**일부 개선은 실제로 나왔지만, 현재 D를 계속 수정하면 논문 수준의 방법이 된다고 보장할 근거는 없다.**
D는 유효한 확률 생성기이자 내부 일반 대조군이다. 최종 제안 구조로 확정하지 않는다.
수학적으로 정의 가능한 모델, 데이터에 적합한 모델, 충분히 학습된 모델, 새로운 기여가 있는 모델은 서로 다른 판단이다.

| 질문 | 현재 판단 |
|---|---|
| 개선 가능성이 실제로 있는가? | D_bin에서 두 자료의 생성 관계·상위 금액 재현 개선을 관측했다. 가능성은 있으나 성공 가능성의 크기·새 방법의 우수성은 모른다. |
| 구조/코드에 문제가 없다고 확신할 수 있는가? | 점검한 경로에서 결과를 무효화하는 새 오류는 찾지 못했다. 표현 제약과 학습·평가의 미확인 사항은 남는다. 무결성 보증은 아니다. |
| 한 성능을 고치면 다른 성능이 반드시 나빠지는가? | 그런 필연성은 입증되지 않았다. Sparkov는 이번에 모든 등록 기준을 통과했다. Berka에서는 허용치를 넘는 비용이 관측됐다. |
| D를 기본으로 확정해도 되는가? | **내부 비교 기준으로 보존: 가능. 최종 제안 아키텍처로 확정: 근거 부족.** |
| 기존 논문의 기본 능력은 확보했고 새 한계만 남았는가? | 아니다. 금액 분포·행동 구성 같은 기본 품질과 공식 baseline의 비교 충분성부터 미해결이다. |

## 수정이 누적된 규모와 진행상의 문제

[9월20일 감사](dataset_literature_and_process_audit_2026_09_20.md)는 CS-SAF oracle부터
이력/반복 진단까지 **22개 완료 결과 묶음**을 열거했다. 이후 외부 관계 점검,
외부 이식 비교, 금액/행동 출력 비교, 저장 D 진단, D_bin 비교의 **5개 후속 단계**가 있다.
이 수는 아키텍처 변경 횟수나 학습 횟수가 아니다. 저장 결과만 읽은 진단도 포함한다.
외부 이식 이후 정상 완료 신경모델 학습만 세면 **8+14+2=24회**다.
별도 보정·생성·제외된 CPAR 원시도는 이 학습 수에 넣지 않는다.

각 비교에는 국소적인 이유가 있었지만, 자체 인공 데이터의 반복확률 문제를 오래
다듬는 동안 외부 자료에서 중요한 관계와 기본 출력 분포의 적합성을 늦게 확인했다.
이는 진행상의 실제 약점이다. 검사를 통과했다는 사실과 다음 수정 후보가 있다는
사실만으로 구조의 타당성이나 성공 전망을 강하게 설명해서는 안 된다.

Sparkov의 동일 merchant 반복은 약0.204%였고, Berka의 mark는 거래 operation이다.
인공 데이터의 반복 중심 과제를 그대로 외부 금융 생성 문제의 대표로 삼을 수 없다.
[관측 관계 감사](external_relations_v1/README.md).

## D가 실제로 계산하는 것

고객 정적 정보 s와 최근31개 거래를 GRU128차원 h로 요약한다. 거래를 생성하는 순서는
`간격 g → 행동 m → 금액 a → 보조 필드 z → 다음 이력`이다.
Berka의 m/z는 operation/transaction_type, Sparkov는 merchant/category다.
길이와 고객 조건은 고정 계획으로 제공하며 그 분포를 함께 학습하는 실험은 아니다.

```text
p(g_t,m_t,a_t,z_t | H_t,s)
 = p(g_t | h_t) p(m_t | h_t,s,g_t,m_(t-1))
   p(a_t | h_t,g_t,m_t) p(z_t | h_t,g_t,m_t,a_t)
```

이는 선택한 조건부 분해이며 금융의 인과 법칙을 식별하는 수식은 아니다.
첫 거래의 없는 gap은 별도로 처리한다. h는 현재/미래 정답을 포함하지 않는다.
각 조건부분포를 충분히 정확하게 맞출 수 있다면 이 생성 순서 자체가 행동과 금액의
동시 재현을 금지하지 않는다. 실제 모델의 유한 이력·출력 함수·학습 결과가 충분한지는 별개다.

D의 행동부는 이력·정적 정보·현재 gap·직전 행동을 MLP에 넣어 모든 행동 확률을
직접 계산한다. 이전 U/G의 반복 전용 gate를 제거한 **일반 대조군**이다.
D의 금액은 3성분 lognormal 혼합과 필요한 경우 0 질량, D_bin은 구간 확률과
학습 금액 재표본이다. GRU나 일반 확률 분해, 혼합분포 자체가 이번 연구의 독창성은 아니다.

### 코드에서 확인한 제약과 아직 확인하지 못한 원인

| 확인된 구현 사실 | 의미 | 현재 실패 원인으로 입증됐나? |
|---|---|---|
| 매 target마다 최대31개 과거 거래로 GRU를 계산 | 긴 거래열을 생성해도 더 오래된 개별 거래를 직접 참조하지 못함 | 아니오. 더 긴 기억이 필요하다는 효과 비교 없음 |
| 금액 head는 `[h, gap표현, mark표현]`에 적용한 단일 선형층 | 분포의 원시 매개변수에서 이력×현재 행동의 자유로운 상호작용을 제한 | 제한 자체는 확정, 오차 기여는 미확정 |
| 현재 category/type은 금액 이후에 생성 | 현재 보조 필드와 금액의 관계를 이 순서에서 표현해야 함 | 순서가 수학적으로 틀린 것은 아님. 제한된 함수에서의 비용은 미분리 |
| 같은 GRU에 간격·행동·금액·보조 필드 손실이 흐름 | 금액 출력만 교체해도 이력·행동의 학습 결과가 달라질 수 있음 | 경로는 존재. 이번 악화가 gradient 간섭 때문인지는 미확정 |
| 학습 과거 gap은 관측값, 생성 gap은 support 대표값 | 실제 이력과 생성 이력의 표현/분포가 다를 수 있음 | 기존 감사에 기록된 가능성, 주원인으로 확정하지 않음 |
| D_bin의 구간 내부 추출은 선택한 bin 외의 이력/행동에 조건화하지 않음 | 구간 안 금액의 세부 차이와 새로운 정확한 금액을 표현하지 못함 | 제약은 확정, Berka 비용 중 이 제약의 몫은 미분리 |

금액 head의 제한은 다음처럼 명시할 수 있다.

```text
D 원시 출력 v(h,g,m) = W_h h + W_g φ(g) + W_m e(m) + b
D_bin log(q_k/q_l) = α_kl(h) + β_kl(g) + γ_kl(m) + c_kl
```

현재 g와 m은 strict-past h 안에 들어 있지 않다. 따라서 D_bin의 구간 log-odds에는
임의의 현재 이력×행동 상호작용 항이 없다. 단, D의 softmax/softplus와 혼합 연산은
비선형이므로 **금액분포 전체가 단순 가산적이거나 상호작용을 전혀 못 한다고 확대하면 안 된다.**
gap 표현에도 Tanh가 있다. 이 제약을 발견했다고 곧바로 MLP 확장을 실행하지 않는다.

### 수식·코드 검증의 의미

D의 양수 금액 likelihood는 log(a) 분포를 기존 log1p 좌표로 옮기는 Jacobian을
포함하며, fit에0이 있으면 별도 원자로 취급한다. 이 경로와 인과 마스킹·확률 정규화·
긴 거래열 replay는 기존 CPU 검사 대상이었다. D_bin의 fit-only 경계/pool,
생성 금액의 다음 이력 입력, checkpoint 선택 및 결과 집계도 검사되어 있다.

최근 기록은 CPU5 검사, 개발 자료1,990,071건 부호화, 생성76개 지표/48개 tail 값
독립 집계 검산이다. 예측 검산은 같은 모델 forward를 사용하고 reduction을 별도로
구현한 것이므로 네트워크 구현 전체를 독립 재현한 증거라고 부르지 않는다.
[검증 기록](external_binned_amount_v1/verification.json),
[이전 구조 감사](history_diagnostic_v1/architecture_audit.md).

손실은 필드별 평균의 합으로, 하나의 무가중 전체 거래열 NLL과 정확히 같지 않다.
D_bin은 연속 밀도 NLL 대신 bin CE를 사용한다. 전체를 다시 학습했으므로 출력
구조·손실·소폭 용량의 변화가 함께 있다. 서로 다른 native loss 값으로 모델 간
우열을 정하지 않았다. 금액 log-MAE는 `E[log(1+A)]`의 점예측 오차이며 조건부분포
전체의 정확도와 동일하지 않다. MAE의 최적 점예측이 중앙값이라는 점도 구분한다.

## 실제 결과가 말하는 수준

아래는 같은 개발 자료에서 생성2회 평균이며 낮을수록 좋다. 두 자료의 시간–행동
정의는 서로 다르므로 자료 안에서만 비교한다. 단순 전이는 개인 정적 조건의
품질까지 검증한 모델이 아니다.

| 자료·관계 TV | D | D_bin | 단순 전이 |
|---|---:|---:|---:|
| Berka 시간–행동 | .1311 | .1167 | .0931 |
| Berka 행동–금액 | .1650 | .1225 | .0587 |
| Sparkov 시간–행동 | .0880 | .0732 | .0774 |
| Sparkov 행동–금액 | .0825 | .0583 | .0488 |

D_bin의 행동–금액 오차는 25.8%/29.3% 줄었다. Berka의62,500초과 생성 비율도
2.3380%에서.1269%로 실제.1091%에 가까워졌다. 따라서 개선 자체가 없다는 평가는 틀리다.
그러나 Berka 행동 비율 TV는.0573→.0829, 금액 log-MAE는.4660→.5097였다.
허용한 비용은 각각+.01과+5%였고 실제 비용은+.0256과+9.4%다.
완벽한 동시 개선을 요구한 판정이 아니다. **Sparkov 통과, Berka 실패, 공통 채택 거절**을 유지한다.
[최종 결과와 기준](external_binned_amount_v1/README.md).

이 현상을 모든 모델의 불가피한 교환관계로 일반화할 수 없다. 출력 교체가 공유
인코더 학습과 생성 이력을 모두 바꾸므로, 현 비교만으로 비용을 한 원인에 배분할 수 없다.
단일 학습 seed이고 Berka D_bin은30epoch 상한에서 종료했다. 수렴 및 독립 재현성은 미확인이다.

## 가까운 선행논문이 설계와 근거를 연결한 방식

논문에서 평가하지 않은 관계를 곧바로 그 모델의 실패라고 부르지 않는다.
아래 비교는 원문 방법·실험·한계에 근거하며 전체 분야 전수조사는 아니다.

| 문헌 | 문제와 구조의 연결 | 근거와 남은 범위 |
|---|---|---|
| [TabularARGN, 2025 공개 원고](https://arxiv.org/html/2501.12012v2) §3–4, App.E–G | 혼합 필드를 이산 부호화하고 얕은 필드별 예측기·LSTM 이력·열 순서 무작위화를 결합. 품질/속도/조건부 유연성을 함께 제안 | Berka 등 순차 자료5회 비교. 주요 지표는 저차원 분포와 인접 시점 coherence. **우리 해석:** 이 평균 점수가 희소 집단·장기 상태·극단 금액의 조건부 관계까지 보장하지 않는다. 실제 실패는 별도 측정해야 함 |
| [TabDiT, ICLR2025](https://arxiv.org/html/2504.07566) §4–5, Tables1–3 | 행별 VAE, 행 내부 자기회귀 decoder, 행 잠재열 diffusion Transformer, 숫자 표현과 길이 생성까지 설계 | Age2에서 같은 수치 표현/decoder를 공유한 AR 대조군과 모듈 제거 비교. 기본 MLD-TS68.3→50.8. 공개6자료·3분할 검증. Berka 무조건 생성은85.53으로 이상적50과 거리가 남음. 희소 관계 보장을 입증한 것은 아님 |
| [CPAR, 2022 기술 원고](https://arxiv.org/html/2207.14406) §3–4 | context 조건 GRU와 자료형별 확률 출력·종료로 혼합 다중 거래열을 다룸 | NASDAQ103시계열을128epoch 학습해 CTGAN과 비교. 저자도 대부분 지표의 큰 차이가 없다고 서술; 길이/확장/조건부 유연성이 장점. 이 결과를 모든 금융 관계의 해결로 해석할 수 없음 |
| [CoFinDiff, IJCAI2025 AI4Tech](https://www.ijcai.org/proceedings/2025/1040), [원문 §3–6](https://arxiv.org/html/2503.04164) | 가격의 추세·변동성을 조건으로 주고 wavelet 표현과 cross-attention diffusion을 결합 | 조건 충족·다양성·deep hedging을 연결. 전체 표본의 효용은 실제 자료 학습이 더 좋고 일부 고위험 조건에서 이득. 저자는 다종목 상관·다른 필드·조건 확장을 후속으로 남김. 고객 거래열의 직접 baseline은 아님 |

배워야 할 점은 층 수 자체가 아니다. **해결할 문제 → 그 문제를 겨냥한 장치 →
그 장치 없이도 같은 이득이 나는지 비교 → 실제 용도에서의 이득**이 연결되어야 한다.
기존 구성요소를 이용한 기여도 가능하지만, 현재 D에서 그 추가 이득은 입증하지 못했다.

우리 공식 baseline 비교도 아직 확증 수준은 아니다. CPAR는 고정64epoch 마지막에도
손실이 감소했고, ARGN은 자연 길이 및 다른 인코딩 통계 범위를 사용했다.
TabDiT는 이 프로젝트에서 학습·평가하지 않았다. 따라서 자체 D 오류를 곧바로
‘TabularARGN/TabDiT도 못 푸는 한계’라고 쓰거나 논문 수치를 직접 비교하지 않는다.

## 여기서 유지할 것과 종료할 것

- 현재 U/G의 반복 전용 구조를 핵심 기여로 채택하지 않는다. D도 그 주장을 대신
  입증한 모델이 아니라 일반 대조군으로 보존한다. D_bin의 자료별 개선은 함께 보존한다.
- 이번 금액 출력 방향은 종료한다. 새 head/규제/구간/seed 실행으로 채택될 때까지 찾지 않는다.
- 후속 연구 판단은 **충분히 학습한 가까운 공식 baseline에서도 같은 중요한 오류가
  남는가**, 그리고 그것이 실제 사용 목적에 왜 중요한가에 달려 있다. 이 연결이
  확인돼야 그 오류를 겨냥하는 구조/학습법을 새 기여 후보로 설계할 근거가 생긴다.
- 공식 baseline의 충분성 확인으로 오류가 사라지면 기존 U/G→D 수정 계열의
  독자적 방법 주장은 중단해야 한다. 다른 문제로 연구를 바꿀 수는 있지만 이름만
  유지하며 현재 설계의 성공으로 설명하지 않는다.

연구 자체의 불가능성을 증명한 결과는 아니다. 그러나 현재 증거만으로 ‘구조는
확립됐고 seed만 늘리면 된다’거나 ‘계속 고치면 충분히 좋은 논문이 된다’고 말할 수 없다.
