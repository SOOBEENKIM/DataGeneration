2026-09-17. 최신 누적 연구 브랜치는 `research/cs-saf`이며 `main`은 이전 SAF 기준 버전이다.
[상세 보고서](replay_oracle_v1_report_2026_09_17.md) · [수치](replay_oracle_v1_result.json) · [bin별 근거](replay_oracle_v1_binwise.json).

**이번에는 원인 해석을 수정하고 다음 수정 대상을 더 좁혔다. 새 모델 우수성을 증명한 실험은 아니다.**

기존 U/E/L003 checkpoint 120개를 그대로 두고 4개 집단 비율·2개 κ·5개 model trial에서 같은 생성 이력의 교차 예측 2,160회와 oracle sequence 153,600개를 평가했다. 새 학습 0회다. 실행 전 14개 CPU 테스트, GPU 검증, 전체 배열·지표·checkpoint 검증을 통과했고 GPU 실행은 끝났다.

첫째, **실제 gap을 고정하고 mark만 생성하는 경로는 정확한 oracle에서도 왜곡된다.** 정확한 joint 생성에 비해 활성 expected repeat L1이 +.0228~+.0347 커졌다. 네 비율 각각 5/5 생성 난수 trial에서 증가했다. bin 표현을 맞춘 대조군에서도 같은 방향이다. 따라서 이전의 “실제 gap을 유지해도 오차가 늘었다”는 수치는 맞지만, 그것만으로 신경망의 mark 이력 피드백이 원인이라고 단정할 수 없다. 고정 gap과 생성 mark를 결합한 진단 자체의 한계를 확인했다.

둘째, **같은 생성 이력을 넣어도 L003은 E보다 반복곡선 보정이 나쁘다.** FULL의 동일 이력 predictor 차이는 +.00266~+.00299이고 네 비율 각각 5/5 paired model trials에서 양수다. 이력 source를 바꾼 차이는 일관성이 약하다. 짧은 gap 반복은 더 과소예측하고 긴 gap 반복은 더 과대예측하는 평균 패턴이 남는다. 다음 후보는 이력 인코더를 바로 교체하기보다 E/L003의 같은 대조군에서 반복 확률 보정을 제한적으로 검증하는 것이다. 이 분해는 산술적이며 유일한 학습 원인의 인과 규명은 아니다.

셋째, **완벽한 모든 조건 충족만을 요구하는 것은 아니다.** L003은 비활성 copy-range를 평균 약 .0087~.0099 줄였고 각 비율 5/5에서 이득이 있다. 반면 기존 자유 생성의 활성 repeat L1 오차는 E 대비 2.6/6.7/11.7/11.5%, MI 오차는 7.8/9.1/13.2/18.7% 증가했다. 활성 conditional TV 이득은 작고 모든 참고 구간이 0을 포함한다. 비활성 억제가 주목적이면 이런 성능 교환을 명시해 연구할 수 있지만, 생성 품질 전반의 개선이라고 주장할 단계는 아니다.

후속 실험에서는 허용할 손실과 주요 이득을 사전에 정하고 새 데이터·시드에서 확인해야 한다. 기존 ER FAIL은 유지한다. 이번 결과로 연구 중단을 결정할 이유는 없지만, 성공할 때까지 임의 수정하기보다 생성 이력에서의 보정이라는 한정된 가설을 검증하는 것이 타당하다. 다음 보정 모델은 아직 사전등록·학습하지 않았다.

현재 한계: 같은 seed42 데이터와 validation 반복 사용, oracle trial은 생성 난수 반복, held-out test·실데이터·독립 데이터 확인 없음. 기존 CPAR 대비 이득은 U도 얻었으므로 규제의 고유 기여로 해석하지 않는다. Git에는 코드·설계·검증·보고서·수치를, 대형 원시 모델과 경로는 원격 워크스테이션에 보존했다.
