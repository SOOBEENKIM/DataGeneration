# 내부 구조 비교 — 실행 전 등록

기존 Stage 1의 단순 보정 성과와 E/ER의 실패를 유지한다. 이번 질문은 **새 구조 C가 같은 용량의 일반 구조 G보다 자유 생성 관계를 개선하면서, 같은 조건으로 새로 학습한 U+gap의 거래별 예측 성능을 유지하는가**다. 기존 인공 데이터/validation을 사용하는 탐색 파일럿이다. 독립 확인 또는 금융 효용 실험이 아니다.

## 구조와 고정 범위

- U: 기존 CS2-U1, 잠재 copy와 fresh mark 혼합. G: 같은 특징으로 관측 반복확률을 직접 출력하는 일반 sigmoid head. C: 같은 파라미터에서 이력별 반복 수준과 gap 관계를 제약 결합하는 head.
- 공통 GRU128, gap/mark embedding32, 집단 embedding8, 집단별 rank16 경로, 같은 gap support/수치값 decoder/첫 거래. 파라미터는 모두 133,549개. G/C는 이전 행동을 제외한 비반복 분포를 사용한다. U에는 기존 혼합을 유지한다. U–G는 반복 표현의 효과, G–C는 결합의 효과를 비교한다.
- G의 logit은 b(h)+s(h,g). C는 sum_k a_k(h)*sigmoid(s_k(h)+alpha(h))=sigmoid(b(h))를 만족한다. a는 공통 gap decoder의 분포다. 이는 알려진 제약 계산이며 자체 신규성을 주장하지 않는다. C의 mark loss는 결합을 통해 gap head에도 기울기를 보낸다.
- 모든 구조에 동일한 초기 파라미터 값을 배정하되 U와 G의 초기 확률까지 같다고 주장하지 않는다. G와 C는 초기 관계 가중치 0에서 같은 예측을 낸다. 매 시드 모든 공통 tensor와 개체 순서를 확인한다. warm start/기존 학습 가중치 사용 없음.
- pi=.10, 기존 데이터 seed42의 κ0/1, 새로 고정한 모델/은행 시드 3쌍, 3구조로 **18회** 신경망 학습. 각 최대50epoch/patience5, batch512, AdamW lr.001, weight decay1e-5, gradient clip1. global validation base NLL로 best 선택. 기존 U의 목적함수인 gap/mark/value 평균 NLL 합을 그대로 쓰며 반복 BCE/균형 손실/규제/rollout loss를 추가하지 않는다.
- 실패한 과학적 조건도 전부 완료하며 결과에 따른 seed/epoch/모델을 추가하지 않는다. 기술 실패는 원본을 보존하고 새 dispatch를 멈춰 원인을 기록한다.

## 보정·평가

모든 부모에 raw/gap/direct를 평가한다. gap/direct는 Stage 1의 동일 관측 반복확률 변환이며 outer train만 사용한다. 계수 저장 후 validation을 평가한다. C에 posthoc gap/direct를 적용하면 이력별 기본 반복 수준 보존 제약이 일반적으로 깨진다. 따라서 **C raw가 1차 제안 모델**, C+gap은 그 성질이 없는 보조 비교다. C+gap의 성공으로 C raw 실패를 바꾸지 않는다. 공정한 보정 후 구조 비교 C+gap–G+gap도 전부 보고한다.

학습 기반 동일 개체 계획 2,048개, 생성 난수 3개, 18부모×3변형×3난수=**162개 신규 생성 데이터셋**. 모든 내부 모델은 같은 길이/집단 계획을 사용한다. 원래 ARGN 결과는 과거 참고값으로 남기며, 다른 학습 예산·난수의 값을 새로운 동등 조건 우월성 표에 섞지 않는다. 좋은 후보가 나오면 외부 재비교/독립 검증을 별도로 등록한다.

주 평가: 실제 이력에서 관측 반복 Brier·64개 행동 NLL·5구간 반복곡선 L1, 자유 생성의 기본13지표 및 null 평균 제거 곡선 L1. pooled/두 집단/각 학습 seed/각 생성 난수를 공개한다. 고정 이력의 gap 민감도도 보조 진단하며, 인공 법칙을 모델의 학습 목표로 쓰지 않는다. best 가중치를 사용하고 final은 진단 가능하도록 보관만 한다.

## 허용 오차와 진출 판단

**두 1차 비교 C raw–G raw, C raw–U gap을 모두 통과**해야 후속 후보로 삼는다.

- 활성집단 생성 반복 L1: 세 학습 seed 평균에서 상대10% 및 절대.002 이상 감소, 적어도2/3 seed 개선, 어떤 seed도 .005 초과 악화하지 않으며 C의 각 seed L1≤.03.
- 예측 비용: 각 seed/κ/집단에서 두 대조군 각각 대비 Brier 증가≤.002, 행동 NLL 증가≤.02. C raw와 U gap 자체도 Stage 1 기본 예측 screen을 통과해야 한다.
- 생성 비용: 각 seed/κ/집단에서 두 대조군 각각 대비 gap KS/mark sparse TV/수치값 KS 증가≤.01, length scaled W1 증가≤.02. C의 각 null cell 반복곡선 L1≤.03, 평균 제거 모양 L1≤.02.
- 이는 탐색용 실용 기준이다. Brier .002는 이전 U+gap .1413의 약1.4%, NLL .02는 이전3.268의 약0.6%인 작은 허용 손실이다. 생성 .002/10%는 사소한 표본 차이만을 성공으로 세지 않기 위한 사전 선택이다. 금융 현장의 허용치/통계적 비열등성/유의성이라고 하지 않는다. 생성 난수 평균은 학습 seed별로 먼저 계산하며 생성 난수를 독립 학습으로 세지 않는다.
- 3개 시드의 파일럿 성공은 기여 확정이 아니다. 통과하면 후보/설정을 그대로 고정하고 새 데이터·학습 seed, 다른 행동 법칙과 외부 모델의 공정한 재비교를 등록한다. 실패하면 그 실패 및 어느 기준 때문인지 보고하고 원인에 맞는 후속만 제안한다. 이 단계에서 생성 궤적 loss를 자동으로 추가하지 않는다.

## 검증과 실행

등록 commit 후 구현한다. CPU에서 확률 정규화·NLL 분해·모델 파라미터/초기화·G/C 초기 일치·strict past·조건부 결합 보존·유한차분 기울기·학습 감소·저장/재로드·생성 지원을 확인한다. C는 sigmoid 확률을 다시 logit으로 바꿀 때의 끝점 불안정을 피하는 double 정밀도 implicit logit 계산을 사용하며, 기존 coupling 함수와의 일치도 확인한다. GPU smoke에서 메모리/처리시간을 확인한 뒤 같은 구현으로 시작한다.

이전과 같이 여유≥2GiB/사용률≤65%인 원격 GPU에서 하나씩 실행하며 다른 작업을 종료하지 않는다. PyTorch allocator4%, CPU 평가 worker최대2/각 thread1. 사용자 로컬 Intel Arc로 이식하지 않는다. 원본 데이터/과거 checkpoint는 변경하지 않고 모든 결과·실패·hash를 보존한다. 코드·등록·작은 결과는 기존 research/cs-saf-external-audit-v1에 저장하고 push한다.
