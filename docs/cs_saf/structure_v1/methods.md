# 이번 내부 구조 비교의 의미

질문은 **같은 이력 정보와 학습 용량에서 반복확률의 계산 구조만 바꾸면, 거래별 예측 정확도를 유지하면서 자유 생성의 반복관계를 더 잘 재현하는가**다. 이전 E의 추가 이력 계수나 ER 규제는 넣지 않는다. 그 구성의 실패는 과거 결과로 유지한다. 이번 C는 별도로 고정한 제약 결합 후보다.

## 무엇을 같게 하고 무엇을 바꾸었는가

세 모델은 과거 거래를 요약하는 GRU128, 집단 embedding8, gap/행동 embedding32, 집단별 rank16 관계 경로, gap 분포 및 수치값 출력 구조를 공유한다. 각 133,549개 파라미터이며 같은 시드에서는 초기 tensor와 개체 순서까지 같다. 모두 실제 과거와 관측 집단을 사용한다. 같은 파라미터 수가 같은 함수나 계산량을 의미하지는 않는다.

| 구조 | 반복확률 계산 | 비교 목적 |
|---|---|---|
| U | 이전 행동 복사 확률과 일반 행동 분포의 혼합 | 기존 기준 구조 |
| G | 이력 수준과 gap 점수를 더한 logit의 sigmoid | 관측 반복을 직접 예측하는 일반 신경망 |
| C | gap별 반복확률의 가중평균이 이력 수준에 맞도록 logit을 조정 | 수준과 gap 관계를 제약식으로 연결하는 효과 |

G는 이전 Stage 1의 `direct` 통계 대조군과 다르다. G는 매 거래의 과거 이력을 입력받아 반복확률을 학습하는 신경망이다. `direct`는 집단×gap 구간의 학습 반복률로 교체하므로 반복확률의 이력별 차이가 없다. 세 부모 모두 raw/gap/direct를 평가해 이 둘을 혼동하지 않는다.

## 실제 계산

이력·집단 특징을 h, 현재 간격 구간을 k, 이전 행동을 m이라고 하자. U의 일반 행동 분포가 f이고 잠재 복사 확률이 q이면 관측 반복확률은 `q+(1−q)f(m)`이다. q 자체를 실제 반복률이라고 부르지 않는다.

G와 C는 관측 반복확률 r을 직접 만들고, 반복이 아니면 이전 행동을 제외한 분포에서 행동을 고른다. 따라서 행동 likelihood는 반복 거래에서 r, 비반복 거래에서 `(1−r)f(j)/[1−f(m)]`이다. 첫 거래에는 반복 변수가 없고 공통 일반 행동 head를 쓴다.

G는 `r_k = sigmoid(b(h)+s_k(h))`다. C에서는 gap decoder의 확률을 a_k, 이력별 반복 수준을 rho=sigmoid(b(h))로 두고 다음을 만족하는 alpha를 계산한다.

\[
r_k=\sigma(s_k+\alpha),\qquad \sum_k a_k r_k=\rho.
\]

alpha는 double 정밀도 이분법으로 계산하며, implicit derivative로 학습한다. C에는 추가 학습 파라미터가 없다. C의 행동 손실은 이 제약을 통해 gap head에도 기울기를 보낸다. 따라서 G–C 차이는 **제약에 의한 매개화와 그 학습 경로의 결합 효과**이며, 그 둘의 개별 인과 효과를 분해한 결과는 아니다.

고정된 h에서의 등식은 구현 검증 대상이다. 이력별 rho의 정확성이나 여러 거래를 생성한 뒤 전체 반복률·행동·수치값 분포의 정확성을 보장하지 않는다. 같은 점수를 일정하게 이동해도 alpha가 보상하는 등 구조상 불변성도 있으므로, 단순 파라미터 수 일치만으로 두 함수군이 완전히 같다고 주장하지 않는다. 이 알려진 제약 계산 자체가 새 논문 기여라는 주장도 하지 않는다.

## 학습·보정·평가의 분리

모든 부모는 gap/행동/수치값 평균 NLL의 합으로 새로 학습한다. 반복 BCE를 추가로 더하지 않는다. 규제·균형 보조 손실·생성 궤적 손실도 없다. 학습률·최대 epoch·조기 종료·global validation NLL 선택을 동일하게 고정했다. 공통 최대 예산과 중단 규칙을 쓰므로 실제 종료 epoch는 모델마다 다를 수 있다. 실제 시간과 epoch도 공개한다.

보정은 선택된 checkpoint를 동결한 후 outer train만 사용한다. `gap`은 집단별 native gap code 분위수 5구간의 logit offset(총 10개), `direct`는 같은 구간의 경험 반복률이다. 첫 거래와 비반복 행동 사이의 상대확률은 유지한다. 보정된 행동을 생성하는 즉시 수치값과 다음 이력에도 반영한다. C에 사후 보정을 하면 원래 rho를 보존하는 등식은 일반적으로 깨진다. 그래서 **C/raw가 1차 후보이며 C/gap의 결과로 1차 실패를 뒤집지 않는다.**

예측은 실제 validation 이력과 실제 현재 gap에서 측정한다. 반복 Brier와 64개 행동 NLL은 거래별 정확도, 곡선 L1은 gap 구간 평균의 정확도다. 이 단계의 점수는 정답 생성 법칙에 대한 oracle 거리와 다르다. 생성에서는 gap·행동·수치값을 모두 스스로 만들고 이력에 넣는다. 고정된 길이·집단 계획 2,048개를 모든 내부 모델에 똑같이 준다. 길이 분포는 모델이 새로 배운 결과가 아니다.

기본 13개 생성 지표와 비활성 곡선의 평균 제거 모양 오차를 저장한다. 행동 sparse TV는 상위 20개 행동과 나머지를 묶은 분포 거리이며, 64개 전체 TV로 부르지 않는다. 고정된 이력에서 gap만 바꾼 반복확률 범위도 별도로 공개하지만, 이것은 인과효과나 생성 곡선 오차와 같지 않다.

각 학습 시드 안에서 3개 생성 난수의 지표를 먼저 평균한다. 이 3개의 학습 결과를 비교하며 생성 난수 9개를 독립 학습 9회처럼 취급하지 않는다. 그림의 시드 범위는 신뢰구간이 아니다. 판단 기준은 [사전등록](preregistration.md)에 있고 실패 크기와 위치도 함께 공개한다.

## 적용 범위와 저장

기존 인공 데이터 seed42, 집단 비율 10%, 관계 없음/있음 두 조건과 이미 확인한 validation을 쓴 탐색 파일럿이다. 새 학습 시드는 사용하지만 새 데이터의 독립 재현, test, 실제 사기 탐지 효용 또는 외부 모델 대비 최종 우월성 검증은 아니다. 과거 ARGN 결과는 참고용으로 연결하며 새로운 동일 조건 표에 섞지 않는다. 모든 1차 기준을 통과한 후보에 한해 외부 비교와 독립 검증을 별도 등록한다.

CPU 수학·기울기·누출·저장/재로드·미니 학습 검증과 GPU 확률/메모리 검증을 본 학습 전에 통과했다. 세 구조 모두 FP32, GPU 학습은 여유 확인 후 한 작업씩 실행한다. 원본 입력과 checkpoint는 변경하지 않으며 hash, 초기 상태, 학습 순서, 보정 최적해와 생성 계획을 다시 확인한다. 큰 checkpoint·생성 원본은 워크스테이션에, 코드·등록·표·그림·검증 기록은 Git 연구 branch에 보존한다.
