# native_argn_episode_probe_v1 — 2단계(1) 프로토콜 (등록 2026-11-07, 실행 전)

1단계에서 원형 ARGN 엔진은 첫 사기 다음 85%가 즉시 종료했다(실제 0%). 이 진단은
그 원인이 **조건부 학습 실패**(실제 이력을 줘도 지속 확률이 낮다)인지, **생성 측 문제**
(실제 이력에서는 지속 확률이 높지만 스스로 만든 이력에서는 낮다)인지 가른다.

## 1. 관측 오류와 근거

`rare_state_persistence_v1/RESULTS.md`: 원형 엔진 생성 4개에서 구간 나이 1건째 종료 위험
.847(실제 .000), 사기 고객당 구간 2.0–2.5개(실제 1.0), 지속률 .79(실제 .91).
기존 `sparkov_argn_control_v2/probe_native_*.csv`(2026-09-28 등록 teacher probe)는
사기 지속 조건 656건에서 라벨 head의 사기 확률 .853/.885를 보고했지만 구간 나이별 분리와
자가 생성 이력 조건이 없다.

## 2. 가장 가까운 선행 방법

ARGN v2 §3.5–3.6의 sequential model과 `scripts/probe_sparkov_argn_control.py`의
teacher forward(2026-09-28). exposure bias 대 조건부 학습 실패의 구분은 Seq2Synth v3의
longitudinal 평가와 LBDTPP(누적 오차 가정)에 암묵적으로 전제돼 있으나, 드문 상태 시작 사건에
한정해 teacher/self 이력을 대조한 보고는 읽은 범위에 없다.

## 3. 중복과 남는 가설

teacher-forced 진단 자체는 선행이다. 남는 가설: (H1) 실제 이력에서 나이 1 조건의 사기 확률이
높고(≥ .8) 자가 생성 이력에서는 낮다(≤ .3) → 생성된 시작 사건이 학습 분포 밖이라 상태가
이어지지 않는 생성 측 원인. (H2) 실제 이력에서도 나이 1 조건이 낮다 → 시작→2건째 전이의
조건부 학습 실패. (H3) 둘 다 높다 → 종료는 라벨 head가 아닌 다른 열의 생성에서 온다(재검토).

## 4. 비교 실험

동결 가중치, teacher forward 1회, rollout 없음, 새 학습 0. 원형 엔진 2개 학습본
(native_20260928, native_20260929)과 설정 변경 2개(numeric_digit_relaxed_*)에
(a) 실제 development 147명 시퀀스, (b) 같은 엔진의 자유 생성 2 draw를 각각 입력한다.
위치 상한 512(기존 probe와 동일). 직전 사건 상태(정상 / 사기 나이 1, 2–5, 6–10, 11–20, 21+)별로
라벨 head 사기 확률 평균, 실현된 다음 라벨 비율, 라벨 NLL을 기록한다. 라벨은 엔진 열 순서상
같은 행의 앞 열(간격·가맹점·금액·업종)에 조건된 값이며, 이를 "이력만" 조건 확률로 부르지 않는다.
보조로 사기 사건의 나이별 금액·간격·가맹점 재방문·업종을 실제/생성에서 비교한다.

## 5. 판단 조건

- 실제 이력 나이 1 조건 사기 확률 ≥ .8 이고 자가 생성 나이 1 조건 ≤ .3 → H1 채택.
  3단계 방법 가설을 "시작 사건의 조건부 출력 일관성"으로 구체화한다.
- 실제 이력 나이 1 조건 ≤ .5 → H2. 전이 head가 복원한 이유를 라벨 조건부 학습으로 설명한다.
- 그 사이 → 판정 보류, 학습본 추가 없이 보조 비교로 해석만 기록한다.
