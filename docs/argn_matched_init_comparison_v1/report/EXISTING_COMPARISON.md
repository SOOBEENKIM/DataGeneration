# 고정된 history_calibration_only와 강한 대조의 추가 분석

2026-10-02. 새 모델 성능이 아니라 기존 18개 전체 생성 결과를 재분석했다.
3개 독립 전체 학습 × 2개 생성 × 3개 방법, 3,562,662행. 동일 라벨·거래열 길이를
확인했고 15개 지표 × 18개 결과의 재계산 최대 차이는 9.72e-17이다.
등록 파일 740개(이전 620개 포함)는 유지했다. 새 테스트 데이터는 읽지 않았다.

C=`history_calibration_only`, P6=`history_position6`, H=`history_only`.

사기 시작은 평균만 소폭 개선됐고 학습별로는 1/3만 개선됐다. 기존 분석의 학습

## 고객 속도에 따른 새 설명적 분해

속도 경계는 optimization 고객의 정상 간격 중앙값으로 고정했다. 개발 고객의
실제 정상 거래를 이용한 그룹 구분은 결과 설명용이며 생성 시 주어진 입력이나
새로운 학습·선택 조건이 아니다. C−P6 오차 차이에서 음수는 개선이다.

| 고객 그룹 | 실제 정상 고객 수 | 정상 전체 차이 | 정상 개인 대비 차이 | 사기 시작 개인 대비 차이 |
|---|---:|---:|---:|---:|
| 빠른 거래 속도 | 34 | −.000707 | +.003032 | +.011005 |
| 중간 거래 속도 | 43 | −.007436 | +.002877 | −.000368 |
| 느린 거래 속도 | 58 | −.002884 | +.002409 | −.000886 |

정상 개인 대비 관계는 세 속도 그룹에서 모두, 각 독립 학습 3/3에서 악화됐다.
빠른 고객의 사기 시작 관계도 3/3에서 악화됐지만 실제 시작 사건은 24건뿐이다.
이를 별도 검증 없는 확정적 하위집단 발견이나 사건별 정답 예측으로 해석하지 않는다.
정상 전체 개선은 중간 속도 그룹에서 가장 컸다. 이는 pooled W1의 가법적
분해가 아니므로 세 그룹의 값을 합쳐 전체 개선의 기여율로 해석할 수 없다.

개별 고객 W1을 모든 6개 대응 생성에서 계산할 수 있는 고객은 119명이다.
C 대 P6에서 정상 절대 시간은 92명 개선/27명 악화, 정상 개인 대비 시간은
11명 개선/108명 악화였다. 이전 독립 고객 분석과 수치가 일치한다. 주 평가의
147명에서 나머지를 제외한 것이 아니다. 해당 고객의 이용 가능한 대응 수는
CUSTOMER_EFFECTS.csv에 그대로 남겼다.

실제 짧은 거래열 12명은 정상 구간이 없는 사기 전용 고객이어서 정상 시간 W1을
계산할 수 없다. 생성에는 이 고객 ID들에서 정상 구간도 생긴다. 이 차이를
0오차로 채우거나 고객별 실제 사기 상태를 생성기에 주지 않는다. 고객 ID별
원본 행동을 복사해야 한다는 뜻도 아니다. 전체 고객 구성 문제와 시간 출력
문제를 구분하고, 모든 방법이 같은 생성 라벨·길이를 공유한다는 점을 유지한다.

## 지금의 판단

C는 비교의 중심 후보로 유지한다. P6 대비 추가 정상 시간 효과는 있으나 개인
관계 비용이 한 고객에만 국한되지 않는다. 평균 점수만 보고 보정을 더 강하게
만들 근거는 없다. H도 정상 개인 대비 오차 .061720을 가지므로 C의 추가 비용
전체를 보정식 하나의 문제로 단정할 수도 없다.

동일한 최신 ARGN 세 학습본에 적용한 init_only 비교는 별도로 진행 중이다.
그 결과에서 GMR 계열의 개인 관계 장점이 반복되는지, H 단계부터 차이가 있는지
확인한 뒤 출력 자체와 보정 중 수정할 대상을 좁힌다. 이전 다른 부모에서 얻은
init_only 수치를 이 표에 섞지 않았다. C/P6/H/기존 init_only는 모두 보존한다.

이 분석만으로 최신 생성기 대비 우위나 최종 논문 기여를 확정하지 않는다.
MeLD500/2000은 이미 끝난 예비 결과이며, 충분히 학습된 최종 비교로 승격하지 않는다.
