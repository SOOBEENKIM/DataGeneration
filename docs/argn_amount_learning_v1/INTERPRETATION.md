# 학습 대조로 확인한 것과 남은 것

두 부모 fit에서4개 출력 학습 팔,16개 자유 생성(3,159,744거래)을 완료했다.
모든 팔을 보고하며 최종 test는 열지 않았다. 기존 duration label head를 공통으로
사용했고 같은 seed의 label/길이/고객 순서는16개 생성 모두 기준과 정확히 같다.

## 1. 기존 표현으로도 사기 금액 학습을 상당 부분 회복했다

실제 이력·현재 앞 필드를 주었을 때 개발 사기 금액 log-W1은 부모1.921/1.941에서
natural_shared .478/.492, balanced_shared .093/.063으로 감소했다.
balanced_shared의 사기 금액 중앙값은339.97/353.06(실제361.07)이었다.
단순 추가 학습도75% 안팎 개선됐으므로 원래 ARGN의 표현 능력 부재나
현재 label 입력의 결여가 유일 원인이라는 설명은 맞지 않는다.

natural과 balanced 모두 같은 표본 index stream, head 구조, optimizer,
최대 step, macro-class 내부 validation 기준을 썼다. 따라서 두 새 팔의 비교는
목적 가중치 대조다. 그러나 원래 parent와 natural 간에는 동결 학습 범위,
층별 dropout 조건, 층화 minibatch, checkpoint 기준, 추가 학습량이 함께 달라졌다.
parent 실패의 단일 원인을 class imbalance 하나로 확정하지 않는다.

## 2. 실제 자유 생성에서도 개선됐다

네 생성 draw의 평균은 다음과 같다. W1/TV는 작을수록 좋다.

| 방법 | 사기 금액 log-W1 | 개인 rolling 비율 log-W1 | 정상 금액 log-W1 | 사기 고차 관계 TV |
|---|---:|---:|---:|---:|
| frozen duration parent |1.9137|1.1022|.0571|.8776|
| natural_shared |1.1617|.6571|.0640|.7430|
| balanced_shared |.9599|.4680|.0450|.5570|
| balanced_mixture |.9887|.4594|.0588|.5636|
| balanced_routed |.7788|.3555|.0819|.5509|

balanced_shared는 parent 대비 사기 금액 오차49.8%, 개인 비율 오차57.5% 감소했다.
정상 금액의 전체 평균은 나아졌지만 한 fit에서는 악화됐다. 두 fit별 정상 W1 변화는
-.0595/+.0353이며 사전 practical screen의 절대+.05 이내였다. 모든 팔이 이
진행 screen을 통과했으나 이를 정상 품질 무손실이나 통계적 유의성으로 해석하지 않는다.

## 3. 출력 분리 자체의 안정적인 우월성은 아직 아니다

mixture/routed는 같은565,182파라미터, 동일 복제 초기값이며 shared는282,591이다.
routed가 한 fit의 자유 생성에서 특히 좋아졌지만 정상 금액 평균 비용도 더 컸다.
다른 fit에서 shared 대비 일관된 개선을 보여 새 구조의 기여로 확정할 상황은 아니다.
따라서 후속 현재 조건 진단과 상류 category 학습은 가장 단순한 balanced_shared를
고정해 이어갔다. 유리한 단일 draw의 routed를 새 대표 모델로 고르지 않았다.

## 4. 왜 금액만 고쳐도 자유 생성이 완전히 회복되지 않는가

[현재 조건 진단](condition_probe/RESULTS.md)에서 실제 과거/label을 고정해도
category/gap/merchant를 모델이 생성하면 금액 W1이.822–.831이었다.
category만 실제 값으로 주면.072–.098로 돌아왔다. 이는 상류 업종의 조건부
오류가 금액 출력으로 전달되는 근거다. 현재 조건과 생성 이력·고객 구성의 영향을
혼동하지 않기 위해 [업종만/금액만/둘 모두](../argn_category_amount_v1/PROTOCOL.md)
제거 대조를 별도로 등록했다.

이 성과는 알려진 조건부 학습을 통해 더 강한 ARGN 기준을 만든 것이다.
희귀 상태별 학습이나 전문가 분리 자체를 새 기여로 주장하지 않는다.
개인별 사기 발생·지속·종료와 거래 출력의 결합 개선은 더 강해진 기준 위에서
단순 조건부/기간 모델과 비교해야 한다. CPAR 조정과 최신 직접 비교군도 남아 있다.
