# 잔여 관계 오류 위치 진단 — 2026-09-27

현재 최종 개선 후보 MODEL_REGISTRY.json을 고정하고 수정 전 강한 기준/current,
길이·발생만 개선/fixed_joint, 최종 시작 금액 개선/onset_fit을 같은 두 부모와
네 생성 seed에서 비교한다. 신규 학습 0, 최종 test 접근 0. 원본은
optimization/internal-validation/development만 허용한다.

1. 정상→사기, 지속 사기, 관측 처음부터 사기, 사기→정상, 그 밖의 정상 및
   처음 정상으로 나누어 간격·금액·개인 대비 금액을 평가한다. 각 표에 고객/행
   수를 기록한다. 정상 복귀 후 20건도 별도 진단한다.
2. optimization의 엄격한 과거20건 금액/간격 중앙값의 사분위 경계를 고정한다.
   동일 phase 및 phase+업종/과거 수준에서 비교한다. 표준화는 진단용이며
   실제 출력 변경이나 W1의 가법적 인과 분해가 아니다. 빠진 셀의 질량을 보고하며
   20행·10고객 미만 셀은 작은 표본으로 표시한다.
3. 실제 development 과거와 실제 현재 선행 필드에서 gap/amount를 각각 4회
   샘플링한다. 2개 고정 부모를 사용한다. 전체 development 위치를 사용해
   드문 정상 복귀가 정상 일부추출에서 빠지는 문제를 피한다. 첫 거래 gap은 제외.
   gap cache는 해당 필드 이전 입력으로 새로 구축하고 native logits와 replay 검증한다.
   amount cache는 이미 검증된 실제 과거 cache를 hash와 위치·label로 대조한다.
   시작 금액 전문가만 정상→사기 위치에 적용한다. 기존 전환 분포는 이 진단에서
   정답 라벨로 대체하지만 이는 자유 생성 성능/사기 탐지 정확도 평가가 아니다.
4. 저장된 이전 actual-prefix 진단의 출력 가중치가 동일함을 먼저 확인한다.
   모델이 같은 조건에서 내는 분포와 자유 생성의 차이는 이력·현재 조건·구성의
   합성 차이이며, 그 차이만으로 history 하나의 인과 효과를 확정하지 않는다.

참고 근거: [TabCascade §4](https://arxiv.org/html/2601.22816v3)는 이산 조건과
연속 출력 분해를, [OmegaSDS §2 식2·§4](https://arxiv.org/html/2605.06315v1)는
상태 전환과 출력의 결합을 이미 다룬다. [Seq2Synth §3.3](https://arxiv.org/html/2607.15606v3)는
주변 분포와 시간 fidelity를 구분한다. 각 원문의 해당 절을 이번 실행 전 재확인했다.
이 진단에서 이들 구조/식별성 정리를 적용·재현했다고 하지 않는다.

판단: 실제 과거에서도 남는 큰 조건부 오류는 출력 표현·학습의 최소 대조로
이어간다. 실제 과거에서는 작고 자유 생성에서 크면 개인 상태/현재 조건을
차례로 고정하는 대조를 우선한다. 구성 변화만으로 설명되는 작은 비용 때문에
공유 상태 구조를 도입하지 않는다. 다음 변경은 진단 결과·가장 가까운 방법·
제거 대조를 등록한 뒤 하나만 선택한다. 새로운 기여는 이 단계에서 확정하지 않는다.
