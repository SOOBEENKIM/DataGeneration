## 5. 해석 — test 뒤에 쓸 수 있는 문장

- **쓸 수 있다**: (i) 부품 사다리의 순서와 최종 부품의 기여(+.13)가 한 번도 보지 않은 고객에서 재현됐다. (ii) 최종 모델은 시험한 것 중 가장 높던 비교군(RTF + 전이표)과 **같은 수준**이며 생성 간 변동이
  절반이다. (iii) 정상 행 속성 일관성, 사기 새 가맹점, 구간 내 간격, 구간 길이·지속률은 test 바닥의 3배 안이다.
- **쓸 수 없다**: "실제 데이터 효용의 80%"(test에서는 57%), "비교군보다 우월", "모든 표준 지표가 3배 안"(test에서 사기율 3.30배, 고객당 가맹점 수 3.25배).
- **미달 기록**: S1 부분 재현(57%), S4 일부 미달(사기율·고객당 가맹점 수). 프로토콜대로 이 결과를 본 뒤 IBM 모델은 고치지 않는다. 사기율 과다 생성(train 대비 약 1.6배)은 dev가 우연히 가려 준 결함으로,
  IBM에서는 기록만 하고, 다른 데이터에서 전이표를 쓸 때 생성 사기율을 train 사기율과 대조하는 점검을 넣을 근거로 남긴다.
