# init_only 고정 후 출력·목적 2×2 및 최신 비교 — 2026-09-29

요청한 첫 단계의 구현·학습·전체 생성·비교를 마쳤다. **이번 새 후보는 채택하지 않는다.
init_only의 기존 개선을 보존한다.** 새 잔차 출력이 얻은 일부 이득은 있지만,
목표했던 정상 시간 분포와 개인 대비 사기 시작 관계의 추가 개선은 입증되지 않았다.
이것은 Berka 재현 실패나 ARGN 전체의 구조적 불가능성, 연구 전체 중단을 뜻하지 않는다.

## 실제 실행

- ARGN 시간 head4개 학습. 평균만 바꾸는 출력/혼합확률·평균·분산을 바꾸는 출력 ×
  주변분포 목적/조건별 clock-gap 결합·보호 목적. 한 기존 부모20260930, 같은 fit seed.
- 각2회 native 전체 생성, 총8개/1,616,196행. 새 native ARGN backbone 학습0회.
- 공식 LBDTPP 코어로 Sparkov50epoch 학습2설정, 각2회 생성,4개/808,098행.
  같은 길이 스케줄에서 시간·업종·사기 라벨을 생성하는 명시적 적응 실험이다.
- 기존 ARGN 원형·수치표현 개선·열순서 대조, 일반 이력 밀도, CPAR를 같은 시간/상태
  지표로 재평가했다. 전체147명과 모든 모델의 공통143명을 구분했다.
- 학습/생성/추가 진단12개 실행 세션 모두 exit0. 독립 평가 완료. 이전350개 hash 보존,
  선택된 identity3개×2draw는 모든 필드가 init_only와 정확히 일치한다.
- 이전 활성 clock_prefix와 모든 후보 보존. commit/push/최종test 읽기 없음.

초·중반, 사기 간격이 악화했고 사기 시작 개인 관계도 개선되지 않았다. 목적에 맞는
추가 진전으로 채택할 근거가 부족하다. 사소한 비용 하나라도 있으면 논문을 못 쓴다는
판정이 아니라, 이번 변경이 **사전에 정한 주 효과를 보이지 못했다**는 판단이다.

다른 세 팔은 내부 검증에서 identity를 선택했다. 따라서 그 팔의 새 생성이 init_only와
같다는 것은 학습하지 않았다는 뜻이 아니라, 학습한 변경이 선택 기준을 넘지 못했다는
뜻이다. 새 후보가 선택된 mixture_marginal도400step 조건부 likelihood 단계의 결과다.
그 뒤160update 재귀 시간 학습은 더 좋은 체크포인트를 주지 않았다. 결합 손실의
필요성이나 효과는 이번 실험에서 확인되지 않았다.

## 이번 학습이 증명하지 못한 것

최근 재평가 제안을 구체화하면서 mean 대조도 기존6계수 Powell 그대로가 아닌,
동일 신경 잔차에서 평균 성분만 활성화한 대조로 등록했다. 목적도 weighted W1의
128quantile 근사와 위치 층화 minibatch를 쓴다. 이 차이는 학습 전에 PROTOCOL.md에
명시했다. 기존6계수 절차를 똑같이 재현했다고 설명하면 안 된다.

새 clock는 생성된 시간에서 순차 갱신하지만, 학습 replay의 ARGN1322차원 표현과
라벨은 실제 과거에서 가져왔다.64step만 역전파하고 prefix는80update마다 갱신했다.
전체 native 생성에서는 ARGN 표현도 생성된 모든 필드로 갱신된다. 따라서 이번 결과는
완전한 자유 생성 학습을 충분히 해도 안 된다는 증거가 아니다. 단일 초기화,400step
likelihood warm-up,160rollout update, 근사 목적·prefix, 별도 checkpoint 선택 조건의
**제한된 screen**이다. 저장한 것은 선택된 head와 모든 평가 learning curve이며,
선택되지 않은 각 중간 step의 전체 가중치는 별도 저장하지 않았다.

일반 이력 모델은 이번2draw에서 정상 시간.124383/개인 onset.175367, init_only는
.062183/.098863이었다. 이는 init_only의 보존 가치를 뒷받침하지만, 일반 이력 모델을
새 목적·새 예산으로 독립 반복해 비교한 결과는 아직 아니다. 새 joint 팔이 유망할 때
실행하도록 한 추가 대조/3독립 refit 조건이 충족되지 않아 이번에는 확대하지 않았다.

## 최신 직접 비교와 그 한계

LBDTPP2026은 코드를 확인만 한 상태에서 실제 학습·생성한 상태로 진전했다.
원문 코어를 수정하지 않고, 테스트 자동 로더를 우회하며 첫 라벨을 보존한 어댑터를
별도 작성했다. 두 설정 모두 full-length 학습을 했다. 시간 단위만 공식 max-duration과
train-median으로 대조했다. 정확한 차이·프레임워크 버전·EMA·스케줄은 해당 프로토콜에 있다.

하지만 두 draw 평균 생성 사기율은 공식 단위58.07%, median단위64.20%로 크게 틀렸다.
정상 gap W1도4.264806/.617585였다. 이를 '강한 최신 모델을 이겼다'는 근거로 쓰지 않는다.
첫 Sparkov 적용의 적합성 문제가 남은 상태다. 전체 금액·가맹점ID·정적 고객조건까지
생성하는 모델도 아니므로, 전체 혼합형 거래 생성 우위로 확대하면 안 된다.

추가 frozen 진단은 라벨 매핑 오류와 denoising 문제를 구분했다. 실제 latent를 바로
decode하면 mark 정확도는 각 위치99.79–99.97%였다. 그러나 가장 큰 noise99의 첫 블록
추정에서는 사기 비율이46.68%/68.67%였다(실제 내부검증 첫 구간6.02%). 이때 다른
블록은 실제 clean history를 사용한 조건부 진단이다. 자유 생성 성능으로 부르면 안 된다.
공식 시간 단위에서는 true latent의 시간 복원도 크게 틀렸다(log-gap MAE3.16–3.86).
median단위는.48–.65로 나았지만 생성의 라벨 문제는 해결하지 못했다.
이는 단위 설정과 초기 denoising을 검증할 필요를 보여주며, LBDTPP 구조의 보편적
한계나 한 가지 원인을 확정한 것은 아니다. 체크포인트나 학습 조건을 결과에 맞춰
바꾸지 않았고 실패한 출력도 모두 보존했다.

CPAR는 기존128update 단일 fit을 재평가했다. **충분히 조정한 CPAR의 새 학습은
이번에 하지 않았다.** 원형 ARGN·CPAR는 각자의 길이를 생성했고, LBDTPP는 init_only의
생성 길이를 외부 조건으로 받는다. 길이·조건 정보의 차이가 포함된 탐색 비교다.
원형 ARGN 수치 개선은 정상 시간에 더 강하지만 개인 onset 관계는 더 약한 행도 있다.
어떤 한 점수만 보고 모든 선행을 이긴다고 설명하지 않는다.

## 다음 순서와 판단

새 보정 항목을 더 붙이거나 이 joint 구조를 확정하지 않는다. init_only를 고정하고,
이번 실제 생성에서 선택된 mixture_marginal의 이득이 왜 전체/초반 오류와 충돌했는지
먼저 구분한다. **같은 phase·clock·noise에서 실제 과거 ARGN 표현과 생성 과거 ARGN
표현만 바꾸는 대조**가 다음 핵심 진단이다. 이 추가 진단은 아직 실행하지 않았다.
차이가 크면 실제 생성 표현을 사용하는 학습을 검토하고, 작으면 표본 가중·위치 목적과
warm-up/학습 예산 문제를 먼저 본다. 원인 없이 학습 구조를 모두 동시에 바꾸지 않는다.

가까운 선행의 조건부 법칙과 입력 분포 구분(Lin2026), 생성 경로 학습(SigTPP2026),
LBDTPP2026의 empty-prefix 논의를 참고한다. 이런 발상 자체가 신규라는 주장은 하지
않는다. 강한 최신/CPAR 적용 검증, 독립 refit, 다른 자료와 최종 미개봉 test는 최종
기여 주장에 여전히 필요하다. 이번 screen 실패 때문에 init_only의 기존 결과를 지우지 않는다.
