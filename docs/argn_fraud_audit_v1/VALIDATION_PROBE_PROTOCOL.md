# 고정 체크포인트의 내부 검증 변동 검사

2026-09-27. 두 native 학습과 네 생성 결과를 본 뒤 등록하는 탐색적 원인 진단이다. 새 모델을 학습하거나 checkpoint를 다시 선택하지 않는다.

- 두 선택 체크포인트, 기존 check 고객138명, native batch32.
- window sampling(공식 random / 각 열의 최초101개 prefix 고정) × column order(공식 random / 저장된 열 순서 고정)의 2×2 조건.
- 각 조건에 난수20261010~20261015를 사용해 6회 재평가한다. 유효 check 데이터, 가중치와 batch 구성은 같다. 학습 중 이미 사용한 check만 읽으며 test는 읽지 않는다.
- 모든 조건의 손실 범위와 표준편차를 공개한다. 구간/순서를 고정하면 조건부 과제 자체도 달라지므로 조건 간 평균 차이를 모델 품질 개선으로 해석하지 않는다. 동일 조건 안의 변동만 진단한다.
- 둘 다 고정했을 때 결정적인 결과인지, 체크포인트 hash가 유지되는지 검사한다. random 조건 변동이 존재한다는 사실만으로 조기 종료가 관계 오류를 유발했다고 결론내리지 않는다. 그 인과 주장은 별도 학습 대조가 필요하다.
