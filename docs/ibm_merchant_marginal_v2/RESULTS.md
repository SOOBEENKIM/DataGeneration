## 1. 모의실험 (`SIM_VALIDATION.json`, `SIM_CANDIDATES.csv`, `SIM_SELECTED.json`)

- **검증 통과.** 가맹점 과정만 모의한 결과가 v1의 GPU 실측을 재현: 표준 업종 TV .380 / .278 / .269(실측 .369 / .272 / .261), `_RARE_` 비율 .147 / .085 / .015(실측 .143 / .089 / .016).
- **선택(train 240명 모의, 20개 설정).** 곱셈형(ρ^β)은 β = .25에서 업종 TV .088이지만 1위 가맹점 비중이 실제의 1.5배를 넘어 탈락(β ≥ .5는 과집중으로 악화). 가산형(횟수 + κ·ρ)은 κ가 클수록
  단조 개선 — **κ = 8, λ = 1**(빈도만)이 업종 TV .069로 선택. 격자 끝값이므로 더 큰 κ가 나을 수 있으나 등록 격자 안에서 고정한다.
- **dev 관문 통과.** 모의 업종 TV **.078**(≤ .159), 고객당 가맹점 수 90.7(실제 92, 상대차 .014).
- 커널(`KERNEL.json`): 반복 가중 = 횟수 + 8·ρ(업종), ρ = train의 (고객, 가맹점)당 평균 방문 수 비(통행료 ≈ 7.5, 식료품 ≈ 2.6, 외식 ≈ .5 등). 방문 횟수가 쌓이면 횟수가 지배하고, **횟수가 적은 초반에만
  가맹점 종류가 작용**한다. 희귀 묶음은 반복 제외, 새 가맹점은 위치 구간 업종 표 먼저.

## 3. 판정

- **M1 충족.** 표준 업종 TV **1.50배**(한도 3; 모의 예측 .078, 실측 .082), 가맹점이 함의하는 업종 TV .233 → .115(기준 ≤ .135), 방문 수 순위 Spearman .99. 반복 행 구성 오차가 .252 → .124로 줄었다.
- **M2 충족.** 효용 **.491**(기준 ≥ .425). `attr_all` 대비 +.036, 이전 채택 모델 대비 +.160.
- **M4 충족.** 라벨 과정 동일. **모든 표준 지표가 3배 안**(최대 2.90; 이 연구에서 처음). 가맹점 구조(새 가맹점 1.85배, 고객당 가맹점 수 1.22배, 공유 풀 2.50배), 간격 구조(1.16 / 1.25), 속성 일관성 유지,
  `_RARE_` 비율 .016(실제 .029와 차이 .013 ≤ .02).
- **표기 규칙의 몫**(`rarefix_named`): 고객당 가맹점 수 5.25 → 1.28배, 효용 .458 → .474. 업종 분포는 그대로(4.81배) — 업종 분포를 고친 것은 방문율 커널이다.
- **채택.** 등록 규칙(M1·M2·M4 모두 충족)에 따라 **"가맹점 속성 일관성 + 방문율 보정" 스택을 모델로 채택**한다. ibm_merchant_attr_v1의 보류는 이 판정으로 해소된다(그 단계의 공식 기록은 그대로 둠).

## 4. RTF+전이표와의 비교 — 정확한 표현

- 평균 효용 .491 대 .448(+.043), 생성 4개가 모두 .46 이상(RTF는 .37–.55로 fit에 따라 갈림), 표준편차 .02 대 .09. 행 단독·조기 탐지율·구간 재현율도 근소하게 높다.
- 그러나 **fit 2개 × 생성 2개로는 유의성을 말할 수 없다**: RTF의 fit 08 두 생성(.549, .497)은 ARGN의 어느 생성보다 높다. 로지스틱 탐지기에서는 +.006, `no_merchant`에서는 −.011.
  쓸 수 있는 문장은 "시험한 것 중 가장 높던 RTF+전이표와 **같거나 조금 높은 수준이며 훨씬 안정적**이고, 충실도(표준 지표 최대 2.9배 대 4.5배, 사기 새 가맹점 1.9배 대 14.4배)는 분명히 낫다"이다.

## 5. 한계와 남은 것

- κ = 8·λ = 1은 등록 격자의 끝값이다. 고객의 1위 가맹점이 고빈도 업종일 비율은 .83으로 실제 .65를 넘고, 상위 1 / 3 가맹점 비중은 .10 / .24로 실제 .13 / .32보다 낮다(종류는 맞추되 집중도는 약함).
- 통행료 방문 수 183은 dev 125보다 크다(train 184에는 맞음 — train으로 추정했기 때문; dev와 train의 차이).
- 나빠진 것(M4 항목 밖, 기록): 사기 구간 내 가맹점 반복 5.6 → 9.9배, 구간 내 행당 가맹점 수 4.8 → 6.5배, 사기 최빈 업종 비중 3.3 → 4.5배, 사기 최빈 가맹점 비중 2.5 → 3.5배. 사기 구간 **안**의 가맹점
  선택 구조는 여전히 못 잡는다(RTF도 8.6배).
- 24h 구간 수 9.6배(라벨 과정의 배분)는 그대로다.
- 희귀 가맹점 행은 1.6%로 실제 2.9%보다 적다(같은 희귀 가맹점 재방문을 내지 않음). 표기 규칙의 자리표시 이름은 실제 가맹점 정체가 아니다.
- 모의실험기는 업종 안 가맹점 선택과 사기 행을 모의하지 않는다. 이번에는 예측이 맞았지만(업종 TV .078 → .082) 일반적 보증은 아니다.
- IBM 한 데이터, dev 기준, fit 2개. 봉인 test·Sparkov 미확인.
