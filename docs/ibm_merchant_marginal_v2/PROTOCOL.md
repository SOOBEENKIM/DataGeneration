# ibm_merchant_marginal_v2 — 가맹점 종류별 방문율 보정: 모의실험 먼저, 통과할 때만 생성 (등록 2026-11-10, 실행 전)

사용자 지시(2026-11-10): "모의실험 시도". [v1](../ibm_merchant_marginal_v1/RESULTS.md)은 실패했다(표준 업종 TV 3.25 → 4.8–6.8배). 원인: 반복 행의 업종 구성이 자유 생성의 동역학으로 어긋난다 —
실제에서는 가맹점 종류가 방문율을 정하는데 생성에서는 누가 횟수를 쌓는지가 초반 우연으로 정해진다. 이번에는 **가맹점 선택 과정만 CPU로 모의실험**해 후보를 거르고, 관문을 통과할 때만 GPU 생성을 한다.
한 번의 시도이며, 관문을 못 넘으면 생성 없이 종료한다.

## 1. 모의실험기 (정상 행의 가맹점 과정만; 다른 열·backbone 없음)

- 고객별 길이 T(실제 열 길이)만큼: 위치 n에서 게이트 g(정상, 위치 구간)(ibm_merchant_memory_v1의 표)로 새로움/반복을 정한다. 새로움이면 업종을 표 Q[위치 구간]에서 뽑아 그 업종의 **새 가맹점**을
  만든다(업종 안 가맹점 선택은 모의하지 않음). 반복이면 그 고객의 과거 가맹점에서 후보 커널로 뽑는다. `_RARE_`는 v1의 각 팔 규칙대로(하나의 코드로 누적 / 반복 제외).
- 행의 실제 업종: 알려진 가맹점은 그 종류의 업종, `_RARE_`는 train의 P(업종 | 희귀 가맹점, 정상)에서 행마다.
- **검증(먼저)**: 이미 GPU로 생성한 v1의 세 설정(`novelcat`, `novelcat_pos`, `novelcat_pos_rarefix`)을 모의실험기로 재현한다. 통과 기준: 모의 표준 업종 TV가 실측(.369 / .272 / .261)의 ±.04 안이고 순서가
  같으며, `_RARE_` 행 비율이 실측(.143 / .089 / .016)의 ±.02 안. 통과하지 못하면 모의실험기를 신뢰하지 않고 **여기서 종료**한다.

## 2. 후보 (모두 위치 구간 업종 표 + 희귀 묶음 반복 제외 위에서; 종류별 상대 방문율 ρ_c = train의 (고객, 가맹점)당 평균 방문 수 / 전체 평균)

- 곱셈형: 반복 가중 ∝ [λ·빈도 + (1−λ)·최근성] · ρ_c^β, β ∈ {0, .25, .5, .75, 1}.
- 가산형(사전 의사횟수): 빈도 항을 (횟수 + κ·ρ_c)로 — 횟수가 작을 때만 종류가 작용. κ ∈ {.5, 1, 2, 4, 8}.
- λ ∈ {.75, 1}. 총 20개 설정(β = 0은 v1의 `novelcat_pos_rarefix`와 같음).
- **선택(train만)**: train 고객 240명 표본(seed 20261110)의 길이로 모의(seed 3개 평균) → 같은 고객의 실제 통계와 비교. 고객당 가맹점 수 상대차 ≤ .12이고 1위 가맹점 비중이 실제의 0.5–1.5배인 설정 중
  표준 업종 TV가 가장 작은 것. dev는 선택에 쓰지 않는다.

## 3. 희귀 가맹점 표기 규칙 (v1에서 드러난 측정 문제)

v1에서 고객당 가맹점 수가 84 → 74로 줄어 M4를 넘은 이유: 실제 처음 방문의 18.8%는 희귀 가맹점인데 생성기는 그것을 `_RARE_` 한 문자열로만 낸다(고객당 1개로 세어짐). 희귀 묶음을 반복에서 제외하면
`_RARE_` 행은 모두 "새 희귀 가맹점"이므로, 출력에서 **각 `_RARE_` 행에 고유한 자리표시 이름**(`_RARE_<일련번호>`)을 준다(표기 규칙; 가맹점의 실제 정체는 원래 보호·병합된 값). 먼저 v1의 기존
`novelcat_pos_rarefix` 4 생성에 이 규칙을 적용한 파생물로 1단계·효용을 CPU 재평가해(새 생성 0) 고객당 가맹점 수가 3배 안으로 돌아오는지 확인하고 기록한다.

## 4. 관문과 이후

- **관문(dev, 모의)**: 선택된 설정으로 dev 고객 길이를 모의(seed 3개)했을 때 표준 업종 TV ≤ **.159**(바닥 중앙값 .053의 3배), 고객당 가맹점 수 상대차 ≤ .12. 통과하지 못하면 GPU 생성 없이 종료하고,
  "일관성을 지키는 모델의 업종 분포 3.25배"는 한계로 남는다(기준 변경은 별도 사용자 결정).
- **통과 시**: 그 설정 하나를 `attr_all` 스택 위에 구현해 4 생성(fit 2 × seed 2) + §3 표기 규칙. 판정은 v1의 M1·M2·M4 그대로(표준 업종 TV ≤ 3배, 효용 ≥ .425, 라벨 과정·가맹점 구조·간격 구조·
  속성 일관성·모든 표준 지표 ≤ 3배, `_RARE_` 비율 |차이| ≤ .02). 모두 충족하면 "가맹점 속성 일관성 + 방문율 보정" 스택을 채택한다.

## 5. 선행·주장 범위

v1과 같다(Anderson et al. 2014의 최근성 × 항목 품질, Benson et al. 2016, 중첩 로짓). 가산형 의사횟수는 Dirichlet-multinomial(Pólya 항아리)의 사전 질량으로 표준적이다. **새로움 주장 없음** — 보정이다.
train 모의 통계에 맞춰 초매개변수를 고르는 것은 모의 적률법(simulated method of moments)에 해당하며 dev·test는 쓰지 않는다.
