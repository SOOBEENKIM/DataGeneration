## 5. 이 단계에서 새로 확인한 것

1. **채택 모델의 dev 효용은 .491이 아니라 .450 ± .050이다.** seed를 fit마다 달리한 독립 생성 8개의 값이다. 이전의 .491 ± .021은 seed가 겹친 생성 4개(라벨에 대해 독립 표본 약 2개)에서 나온 값으로, 평균은 운이 좋았고
   표준편차는 과소였다. RTF + 전이표의 dev 값 .448 ± .090(같은 방식의 생성 4개)과 차이가 없다. "RTF + 전이표와 같거나 조금 높은 수준, 훨씬 안정적"이라는 dev 서술 중 **"훨씬 안정적"은 철회**하고 "같은 수준"만 남긴다.
   봉인 test의 `argn_final` .254 ± .029 대 `rtf_table` .214 ± .064도 같은 seed 겹침 아래의 값이다(판정 S3는 "같은 수준"이었으므로 그대로 성립하나 표준편차 비교는 믿을 수 없다).
2. 머무름은 구조를 가장 크게 고치지만 효용에는 기여가 없다(−.003 ± .007). 효용의 이득은 금액 단계에서 오고(+.020), 머무름이 있을 때 조금 더 크다(+.020 대 +.005) — 모의에서 본 것과 같은 모양이나 표준오차 안이다.
3. 머무름을 넣으면 사기 구간 안의 금액 변동이 2.4 → 5.2배로 나빠진다(사기 출력층이 달라진 이력을 본 결과). 등록 항목은 아니었으나 기록한다.
4. 생성 간 효용의 표준편차가 .05–.08이다. 생성 8개로는 ± .03 이하의 차이를 가를 수 없다.
