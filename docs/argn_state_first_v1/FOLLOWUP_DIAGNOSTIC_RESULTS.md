# D0/D1 후속 진단 완료

2026-09-27. **6개 저장 모델의 진단을 완료했다. 지금 우선 겨냥할 문제는
생성 누적 오차만이 아니라, 학습된 조건부 사기 전환의 실패다.**
이는 현재 Sparkov 전체 이력 설정의 진단이며 ARGN 원형의 표현력 한계나
새 방법의 기여를 입증한 결과가 아니다. 새 학습은 하지 않았다.

[실행 전 프로토콜](FOLLOWUP_DIAGNOSTIC_PROTOCOL.md),
[조건별 집계](followup/conditional_summary.csv), [고객 구성](followup/cohorts.csv),
[실행 및 해시 기록](followup/RUN_MANIFEST.json).

## 실행 범위

- B, B+S, B_event_weighted 각각 학습 seed 2개, 총 6개 체크포인트.
- 실제 개발 자료 147명·177,997건 전체에서 teacher 조건부 분포/NLL 평가.
- 사전 고정한 1,922개 시점: 첫 거래 전부, 실제 사기 및 직전 사기 거래 전부,
  나머지 정상 거래 고객당 최대 4개. 같은 실제 과거에서 현재 거래를 16회씩
  생성하고 금액·간격·가맹점·업종을 하나씩 실제 값으로 고정하는 대조를 수행.
- 기존 자유 생성 12개 자료를 고객 구성과 전이 지표로 재집계.
- GPU 2·3에서 실행, 각 모델 진단 약 8초(자료 준비·초기 기동 제외). 완료 후
  작업 프로세스 종료. 첫 시도는 일부 native LSTM 층의 CPU 배치 때문에 결과
  생성 전에 실패했다. `model.to(device)` 수정 후 같은 조건으로 재실행했고
  실패 로그·이전 소스 해시를 `attempts/cpu_recurrent_placement_failure`에 보존했다.

## D0: 전처리에서 정상 이력이 사라졌는가

아니다. 허용된 train/development의 **835명·1,094,564건**을 raw CSV와
canonical, 준비 데이터 사이에서 ID·정렬·시간·간격·금액·가맹점·업종·라벨까지
정확히 대조했다. 원본 CSV는 ID 열을 먼저 읽고, test 고객 행은 두 번째 속성
파싱에서 건너뛰었다. 개발 과정에서 test 이벤트 속성을 읽지 않았다.

| 개발 고객 구성 | 고객 수 | 거래 수 | 사기 거래 수 | 관측 특징 |
|---|---:|---:|---:|---|
| 정상 전용 | 33 | 47,639 | 0 | 긴 정상 거래열 |
| 정상·사기 혼합 | 102 | 130,226 | 1,014 | 고객마다 사기 구간 한 번 |
| 사기 전용 | 12 | 132 | 132 | 길이 7–19건, 중앙값 10건 |

학습 자료에도 사기 전용 고객 52명·507건이 원래 존재하며, 혼합 고객 481명은
각각 한 개 사기 구간을 갖는다. 이 관측은 Sparkov 모의 자료의 특성이다.
현재 upstream 생성기의 특정 코드 버전이 로컬 CSV를 만들었다고 확정하지 않는다.
이처럼 단순한 구간 구조를 복원했다는 것만으로 현실 금융 전반의 기여를 주장할 수 없다.

인코딩된 내부 학습/검증은 619/69명, 총 916,509건·사기 5,214건이다. 준비
학습 자료보다 정상 58건이 적으며, 길이 상한 3,106을 넘는 다섯 고객의 정상
꼬리 58건과 일치한다. native encoding의 보호된 최대 길이 절단도 확인했다.
인코딩 단계에서 ID는 제거되므로 이번에는 길이·라벨 집계 대조까지 했고,
ID별 인코딩 역변환을 완료했다고 주장하지 않는다.
D1은 실제 개발 거래를 절단하지 않았고 학습 길이 상한 밖 정상 18건도 포함한다.

## D1: 실제 과거를 줘도 사기를 이어가는가

직전 거래가 사기이고 다음 거래가 관측된 **1,133건·114명**에서 실제 다음
사기 비율은 **91.09%**다. 동일한 시점에서의 예측 사기 확률 평균은 다음과 같다.
범위는 두 학습 seed의 최솟값–최댓값이며 신뢰구간이 아니다.

| 모델 | 실제 과거 + 실제 현재 다른 필드 | 실제 과거 + 현재 필드 생성 |
|---|---:|---:|
| 전체 이력 B | 67.70–71.31% | 62.75–64.30% |
| B+S | 77.48–81.94% | 70.67–77.95% |
| 거래별 가중치 B | **1.16–4.37%** | **0.84–2.26%** |

거래별 가중치 모델은 이미 **실제 과거와 현재 필드를 모두 줬을 때부터** 사기
지속을 재현하지 못한다. 따라서 자유 생성의 누적 오차만 제거하면 해결된다고
볼 수 없다. 혼합 고객만 보아도 실제 90.03%에 대해 teacher 확률이 1.01–3.87%로
낮다. 짧은 사기 전용 고객을 제외해도 같은 문제가 남는다.

이것은 ‘이력이 표현 불가능하다’는 증명이 아니다. 현재 목적 함수, 학습량,
checkpoint 선택, 희귀 전환의 유효 학습 신호가 함께 남은 원인 후보다.

## S와 현재 필드의 영향

S는 사기 지속 확률을 올렸지만 **끝나야 할 경우까지 함께 올렸다**.
실제로 정상으로 돌아온 101건·101명에서 teacher 사기 확률은 B 68.95–69.57%,
B+S 73.76–81.54%다. 상태를 명시적으로 넣었다는 사실만으로 지속/종료를
구분하도록 학습된 것은 아니다. 모든 실제 종료 시점을 결정적으로 맞히라는
목표는 아니며, 이러한 결과는 조건별 확률·NLL과 함께 평가한다.

이전 사기 조건에서 금액만 실제 값으로 고정하면 다음과 같이 변한다.

| 모델 | 현재 필드 모두 생성 | 금액만 실제 값으로 고정 |
|---|---:|---:|
| B | 62.75–64.30% | 65.24–68.51% |
| B+S | 70.67–77.95% | 74.76–79.88% |
| 거래별 가중치 B | 0.84–2.26% | 0.97–3.08% |

금액 생성도 영향을 주지만 실제 금액을 줘도 문제가 크게 남는다. 이 표는 금액
head 교체가 충분하다는 근거가 아니다. 행 앞부분을 생성하면서 뒤의 한 필드를
관측값으로 고정한 민감도 실험이므로 완전한 관측 조건부 분포로도 해석하지 않는다.

라벨 NLL도 문제를 보여준다. 실제 사기 지속 1,032건에서 B는 0.665–0.770,
B+S는 0.257–0.355, 거래별 가중치는 **3.423–4.587**이다. 정상으로 종료된
101건의 NLL은 반대로 B 1.428–1.441, B+S 1.637–2.035, 거래별 가중치
0.007–0.023이다. 한 방향의 전환만 잘하는 상태를 전체 점수로 가리면 안 된다.
금액 digit NLL 역시 실제 사기 지속에서 거래별 가중치 13.20–13.44로 B
11.72–11.94보다 크다. 이는 같은 codec에서의 조건부 digit 오차이고 원 단위
금액 거리나 금액 head 변경의 효과를 직접 측정한 수치는 아니다.

## 첫 거래와 자유 생성은 별도 문제

첫 거래의 실제 사기 비율은 8.16%다. 실제 길이와 현재 다른 필드까지 줬는데도
teacher 평균은 B 68.40–77.34%, B+S 69.41–76.86%, 거래별 가중치
21.03–32.60%다. **과거가 아예 없는 첫 거래 실패를 이력 encoder만 키워서
해결할 수는 없다.** 기존 첫 거래 손실의 가중 질량 분석과 함께 초기 상태의
학습·보정 여부를 별도로 점검할 근거다.

기존 자유 생성에서는 B/B+S가 사기를 너무 오래 잇고 거래별 가중치는 거의
한 건씩 끊는다. [이전 결과](EVENT_WEIGHT_CONTROL_RESULTS.md)와 일치한다.
그러나 teacher/한 단계 진단은 실제 전체 길이를 알고, 자유 생성은 길이도
생성한다. 따라서 두 조건 차이를 순수한 exposure bias의 크기로 부르지 않는다.

## 다음 개발 결정

**현재 S를 그대로 확대하거나 diffusion·새 금액 head를 동시에 붙이는 단계로
가지 않는다.** 먼저 아래 대조를 명시한 다음 학습 프로토콜을 만든다.

1. 초기 사기 비율과 정상→사기·사기→정상·사기 지속을 분리해서 평가하고,
   단순 Markov/지속 기간 모형이 학습 자료만으로 어느 수준까지 설명하는지
   최소 기준을 확보한다. 이 라벨 전용 모형을 전체 거래 생성기로 순위 매기지 않는다.
2. 같은 ARGN 구조에서 전환 조건별 학습 신호와 checkpoint 선택을 대조한다.
   단순 손실 가중치 중간값 탐색에 그치지 않고, 각 조건의 유효 표본·오차와
   자연 발생 비율의 보존을 함께 확인한다. 결과가 설정 수정으로 설명되면
   구조 기여가 아니라 기준 모델 수정으로 기록한다.
3. 구조 후보를 시험한다면 **초기 상태 → 과거에 따른 전환 → 그 상태에서의
   거래 속성**을 구분하는 것이 현재 증거와 연결된다. 그러나 라벨 우선 순서,
   명시적 상태, 조건부 금액 생성은 각각 이미 알려진 구성이다. 단순 생성 순서
   변경과 동일 조건의 S 없는 모형을 먼저 대조해 추가 구조의 필요성을 판단한다.
   이 후보는 아직 구현·우월성·신규성이 확정된 제안 모델이 아니다.

## 문헌과의 연결 및 주장 범위

- [Seq2Synth 2026 v3 §4, Appendix C](https://arxiv.org/html/2607.15606v3)는
  정적 품질과 시간·경로 품질이 다를 수 있음을 이미 평가한다. 전체 사기 비율이
  맞아도 흐름이 틀릴 수 있다는 관찰 자체를 새 기여로 삼지 않는다.
- [TabCascade 2026 v3 §4, §5.3](https://arxiv.org/html/2601.22816v3)는
  범주·저해상도 구조를 먼저 만들고 수치를 조건부로 정교화하며, 단순 factorization과
  추가 latent 구조를 분리해 제거실험한다. 조건부 금액 head나 라벨 우선 순서만으로
  신규성을 주장하지 않는다. 원문 해당 절은 이번 진단 시 다시 확인했다.
- ARGN/CPAR/TabDiT의 같은 과제 비교와 가장 가까운 지속 기간·명시적 상태
  생성 방법 검토는 계속 필요한 조건이다. 이번 진단이 그 비교를 대체하지 않는다.

## 검증과 제한

7개 검증 테스트 통과: 과거 상태의 미래/현재 라벨 비누출, native teacher와
실제 prefix 순차 계산의 일치, 한 단계 캐시 계산의 일치, native 희귀 토큰 억제 등.
실제 6개 checkpoint에서도 teacher-캐시 확률을 추가 대조했다. 모든 모델 가중치와
기존 12개 정규화 생성물 해시는 변하지 않았다. 16회 반복은 현재 필드 생성의
Monte Carlo 오차만 줄이며 독립 고객/학습 반복을 늘리지 않는다. 선택된 시점은
사기를 많이 포함하므로 그 전체 평균을 모집단 사기 비율로 사용하지 않는다.

원시 한 단계 파일의 `label_nll`, `amount_digit_nll`, `raw_fraud_probability`는
동일 prefix의 teacher 참조값이다. 한 단계 생성 분포의 새 NLL로 해석하지 않으며
집계 CSV도 해당 값을 one-step NLL로 보고하지 않는다. 반복 사용한 개발 자료의
탐색 진단이며, 최종 독립 평가나 최신 baseline 대비 우월성은 아직 아니다.
