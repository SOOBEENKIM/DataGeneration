**전체 사기 과생성은 크게 줄었지만, 사기 거래가 거의 한 건씩 끊겨 나왔다.
손실 가중치 변경만으로 고객별 사기 흐름이나 금액 관계가 보존되지는 않았다.**

## 비교 범위

이번 모델은 상태 S가 없는 `B_event_weighted`다. 직전 전체 이력 B와 같은
데이터·codec·모델·초기화 seed·학습 예산을 사용하며 거래 손실 가중치만 바꾼다.
따라서 아래 B는 원문 Berka 재현이나 최초 100행 window Sparkov 결과가 아니다.
원래 고객별 평균 손실과 전체 이력 설정을 함께 사용한 직전 기준 모델이다.
[등록 프로토콜](EVENT_WEIGHT_CONTROL_PROTOCOL.md), [직전 비교](RESULTS.md).

범위는 2개 학습 × 2개 생성의 관측 최솟값·최댓값이다. 신뢰구간이 아니며,
독립 학습 4회로 해석하지 않는다. 사기 종료는 고객 거래열 끝과 구분한다.
관측 구간 평균에는 경계 구간이 포함되므로 완료 구간별 원시 지표도 함께 보존한다.

## 해석

- 이 Sparkov 설정에서는 학습 손실 가중치가 사기 발생량과 연속성에 큰 영향을 준다.
  기존 실패를 이력 encoder의 구조적 한계만으로 설명할 수 없다는 근거다.
- 전체 사기 비율은 실제 값에 가까워졌지만 관측 사기 구간은 대부분 한 건이다.
  종료 확률이 실제보다 크게 높고, 생성 구간의 최대 길이도 2–3건에 그친다.
- 첫 거래의 과대 사기 확률은 감소했지만 남는다. 개인 이력 대비 금액 관계도
  일관되게 개선되지 않는다. 이 결과를 전체 생성 품질 개선 또는 문제 해결로 부르지 않는다.
- 학습 목적이 달라지면서 선택되는 checkpoint도 달라진다. 각 목적의 validation
  loss 절댓값을 직접 비교하지 않는다. 거래별 가중치가 보편적으로 최선이라는
  결론이나 최신 모델보다 우수하다는 결론도 내리지 않는다.
