# 새 학습 시작 기록

2026-09-27 12:42 KST에 Sparkov 사기 라벨을 포함한 새 B/B+S 학습을 시작했다.
이 문서는 시작·검증 기록이며 생성 품질 결과 보고가 아니다.

| 항목 | B | B+S |
|---|---|---|
| 모델 | 설정을 정돈한 ARGN | 같은 ARGN + 과거 상태 요약 |
| GPU | RTX 3090, GPU 1 | RTX 3090, GPU 2 |
| 첫 학습 seed | 20260930 | 20260930 |
| 후속 학습 seed | 20261001 | 20261001 |
| 파라미터 수 | 4,815,662 | 4,815,662 |
| 상태 projection 8,320개 파라미터 | 입력 0, 데이터 gradient 0 | 과거 상태 입력으로 학습 |

실제 첫 optimizer update가 두 모델 모두 로그에 기록되었다. 초기 loss는
학습 동작 확인에만 사용하며 성능 우위의 근거로 삼지 않는다. 각 queue는 두
seed를 순차 학습한 뒤 체크포인트별 두 생성 seed로 자유 생성을 수행한다.
총 4회 새 학습과 8개 생성 데이터셋이 예정되어 있으며 시작 시점에는 완료되지 않았다.

두 모델에 동일한 DIGIT 전처리·열 순서·고객 이력 범위·학습 예산을 적용했다.
이전 100행 window 실험과 구분하여 이번에는 공식 encoding이 남긴 고객 거래열
전체를 사용한다. 기존 encoding의 최대 길이 처리로 제외된 학습용 58행을 공개하고,
B와 B+S 모두 동일한 816,283개 optimization / 100,226개 내부 검증 이벤트를 사용한다.
619/69 고객 분할을 보존했다. 외부 development는 147명이며 최종 test 거래는 읽지 않았다.

검증: 6개 테스트 통과. 현재·미래 정보 비사용, 거래별/일괄 상태 일치,
사기 종료 후 정상 상태 갱신, 전체 이력 전달, 원래 ARGN과 B의 출력 일치,
S gradient·체크포인트 재로딩, 생성 batch 축소 시 고객 상태 보존,
수치 decoder의 tail 처리와 상태 요약 일치를 확인했다.
GPU에서 두 모델 모두 실제 학습·저장·재로딩·생성 통합 검사도 통과했다.

상태 입력은 직전 라벨과 연속 건수·경과 시간, 개인 금액 요약, 최근 간격 요약이다.
금액 출력 head 변경 A는 포함하지 않았다. 생성 라벨·사기 비율·사기 구간 길이를
수정하는 후처리도 포함하지 않았다. [프로토콜](PROTOCOL.md)과
[시작 증거](start_evidence.json)에 설정·버전·해시를 보존했다.

실행 로그: `artifacts/argn_state_first_v1/logs/{B,B_S}.log`.
현재 상태: `artifacts/argn_state_first_v1/queue_{B,B_S}.json`.
첫 실행의 재현 코드와 기존 실험 결과는 서로 다른 브랜치·폴더에 보존한다.
