# 가중치 대조 이후의 다음 실험 판단

2026-09-27. 완료된 결과를 본 뒤 작성한 탐색 계획이다. 새 학습을 시작했다는 기록이나 사전등록된 성공 기준은 아니다.

후속 기록: 아래 D0/D1은 같은 날 실행·완료했다.
[실제 진단 결과와 다음 개발 판단](FOLLOWUP_DIAGNOSTIC_RESULTS.md).
아래 계획은 작성 당시 내용으로 보존하며, 새 구조 학습이 완료됐다는 뜻은 아니다.

## 지금 결론

고객별 평균 손실을 쓰는 전체 이력 B는 사기를 너무 많이, 너무 길게 생성했다.
거래별 동일 가중치 B는 전체 사기 비율을 크게 개선했지만 연속 구간을 거의 한 건으로 쪼갰다.
S의 첫 비교 역시 조건부 거래 관계의 일관된 개선을 입증하지 못했다.
[완료 결과](EVENT_WEIGHT_CONTROL_RESULTS.md).

따라서 ‘연구 불가능’도 ‘ARGN 구조의 한계를 해결했다’도 현재 결론이 아니다.
고객/거래 가중 방식과 조건부 관계 학습·생성이 상호작용한다는 진단 결과다.
단순 가중치 중간값을 계속 탐색하거나 S·금액 head·diffusion을 한꺼번에 추가하지 않는다.

## 1. 새 학습 없이 원인 범위를 먼저 줄인다

### D0: 데이터와 관측 단위

- 개발에 허용된 학습/validation 고객에서 짧은 사기 전용 거래열과 정상·사기 혼합 거래열을 구분해 전이·지속·금액 지표와 지지 표본 수를 다시 본다. 주 전체 평가는 유지하며 편한 고객만 제거하지 않는다.
- 기존 준비 데이터의 짧은 사기 전용 고객이 원래부터 그런지, ID 처리·분할·정렬 과정에서 정상 이력이 유실됐는지 출처와 변환 코드를 대조한다. test 이벤트는 읽지 않는다.
- Sparkov는 모의 생성 자료다. 공개 생성기 코드의 profile/fraud 주입 방식과 로컬 자료의 정확한 출처 버전은 별도 확인하며, 현재 upstream 코드만으로 로컬 이상 패턴의 원인을 단정하지 않는다. [원 생성기](https://github.com/namebrandon/Sparkov_Data_Generation).
- 오류가 자료 처리에서 발생했다면 이를 수정하고 영향을 받는 기준을 다시 만든다. 모델 구조의 새 기여로 기록하지 않는다.

### D1: 같은 저장 모델에서 실제 과거와 생성된 과거를 구분

완료된 B·B+S·B_event_weighted 체크포인트를 사용한다. 전환 지표는 이전 정상/사기, 연속 건수, 고객 이력 길이별로 나누고, 현재 필드와 실제 미래 길이를 얼마나 제공했는지 명시한다.

| 조건 | 확인할 내용 | 해석 범위 |
|---|---|---|
| 실제 과거 + 실제 현재 다른 필드에서 라벨 분포 | 사기 지속/종료를 가장 유리한 관측 조건에서도 학습했는가 | 정답 현재 필드를 제공한 조건부 진단. 자유 생성이나 탐지 효용 점수가 아님 |
| 실제 과거 + 현재 거래 필드 전체를 생성 | 과거가 정확해도 현재 금액·간격·가맹점과 라벨을 함께 만들 때 어긋나는가 | 행 내부 필드 생성/분포 차이를 조사. 전 단계와 차이를 곧바로 한 가지 원인의 증명으로 부르지 않음 |
| 생성된 과거 + 현재 거래 필드 전체를 생성 | 앞선 두 조건보다 오류가 커지는가 | 생성 과정에서 방문하는 이력 분포의 차이를 조사 |

계좌 전체 길이 같은 미래 정보는 주 자유 생성에 주지 않는다. 진단에서 실제 길이를 쓸 경우 별도로 표기하고 같은 길이 조건끼리 비교한다. 사기 구간의 종료와 고객 거래열의 종료를 구분한다.

아울러 총 validation loss뿐 아니라 사기 지속/종료 조건의 라벨 오차와 금액 오차를 분리한다. 현재 checkpoint에서 학습이 약한 것이 확인돼도 즉시 표현력 한계라고 하지 않는다. 학습량·checkpoint 선택·희귀 조건의 유효 샘플 수를 먼저 대조한다.

## 2. 최신 문헌과 강한 비교군을 개발 전에 연결

| 역할·후속 후보 | 선행 근거 | 이번 연구에서 아직 필요한 것 |
|---|---|---|
| 시간·고객별 흐름의 평가 | [Seq2Synth 2026 v3, §3–4](https://arxiv.org/html/2607.15606v3) | 기존 지표를 재사용한 부분과 사기·개인 이력 조건에서 추가한 부분의 구분. 비율과 흐름이 다를 수 있다는 관찰 자체는 새 기여가 아님 |
| 직접적인 전체 거래열 생성 비교 | [TabDiT v2](https://arxiv.org/html/2504.07566v2), ARGN, CPAR | 동일한 Sparkov 라벨·필드·context·분할·생성 조건과 학습 충분성. 기존 단발 CPAR 결과를 최적 성능으로 두지 않음 |
| 간단한 전이·지속 기간 대조 | 기존 Markov/semi-Markov 상태 모형 | 학습 자료에서 확률과 지속 분포를 추정해 발생·지속·종료의 최소 기준 확보. 실제 validation 비율·최대 길이를 강제하지 않음. 전체 거래 필드가 없는 라벨 전용 대조는 완전한 생성기로 순위를 매기지 않음 |
| 명시적 상태/지속 정보를 쓰는 새 구조 후보 | 기존 상태 모형, ARGN의 이력 표현, 사기 거래열 생성 문헌 | 가장 가까운 duration-aware/explicit-state 학습 생성기와의 방법 차이 검토가 아직 부족함. 제목·연도 검색만으로 신규성을 승인하지 않음 |
| 조건부 금액 head | [TabCascade 2026 v3](https://arxiv.org/html/2601.22816v3) | 조건부 수치 복원 자체와 구별되는 변경. S와 분리한 대조. 현재는 미구현 |
| 생성 경로·블록 변경 | [LBDTPP 2026 v1](https://arxiv.org/html/2606.24982v1), [ADiff4TPP 읽은 원고](https://arxiv.org/html/2504.20411v1) | D1에서 생성 이력 문제가 주요하게 남는 경우에만 검토. 블록 생성/오차 누적 감소 자체는 선행됨 |

2026-09-27 표적 검색은 financial transaction sequence generation, duration/semi-Markov, sequential tabular를 확인했다. STG-DGR(WWW 2026)은 출판사 초록상 거래 그래프의 생성 replay를 통한 탐지 학습이므로 전체 고객 거래열 생성과 같은 실험으로 간주하지 않는다. 논문 전부/전체 부록 독해를 이번 검색으로 새로 완료했다고 주장하지 않는다. 관련 방법 검색과 원문 대조는 다음 구조 결정까지 보완해야 한다.

## 3. 진단에 따라 다음 학습을 선택

- D0에서 자료 문제가 확인되면 수정된 기준 실험부터 수행한다.
- D1에서 실제 과거에서도 지속/종료가 틀리면 해당 조건의 학습·모델 선택·상태 표현을 한 가지씩 대조한다. 기존 S를 다시 시험한다면 같은 학습 목적의 상태 없는 B와 다시 짝을 맞춘다. 서로 다른 가중치의 B와 S를 비교하지 않는다.
- 실제 과거와 현재 필드가 주어질 때는 맞고 행 전체 생성부터 틀리면, 필드 생성 순서·현재 거래 분포를 먼저 대조한다. 과거 encoder를 키우는 것이 자동 해법은 아니다.
- 실제 과거에서 행 전체 생성은 맞는데 자유 생성에서만 악화되면 생성 이력의 누적 영향을 겨냥한다. 원래 정상→사기→정상 조건과 충분한 지지 표본이 있는 조건부터 비교한다.
- 단순 전이·지속 모형과 강한 직접 비교군을 먼저 확보한다. 현재 S가 그보다 추가 정보를 보존하는 근거가 없으면 해당 S 설계를 확대하지 않는다.

## 계속할 기준과 방향을 바꿀 기준

계속할 근거는 전처리·학습 설정을 정돈한 비교군에도 남는 구체적 조건부 오류,
그 오류를 겨냥한 선행 방법과 구별되는 변경, 반복 학습에서 재현되는 개선이다.
전체 사기 비율·지속/종료·개인 이력 대비 금액을 함께 보고 정상 품질·다양성 손실도 확인한다.

데이터/설정 수정만으로 해결되거나, 단순/기존 방법이 같은 효과를 내거나,
최신 선행과 방법·실증 차이가 없다면 현재 기여 후보를 수정하거나 폐기한다.
그 판단은 전체 데이터 생성 연구가 불가능하다는 결론과 구별한다. Sparkov만의
모의 패턴에 한정되면 주장 범위를 제한하고 추가 자료에서의 검증을 검토한다.

현재 결과는 반복 사용한 개발 validation의 탐색 결과다. 새 확인 실험에서는
실제 자료의 변동 규모로 허용 오차와 정상 품질 기준을 먼저 정하고, 독립 반복과
분리된 최종 평가를 사용한다. 아직 새 기여·논문화 가능성을 보장할 근거는 없다.
