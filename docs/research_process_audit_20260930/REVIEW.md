## 3. 무엇이 실제로 보존돼 있는가

아래는 동일한 **기존 부모 2개 × 생성 난수 4개**, 모델별 8개 결과의 평균이다. 오차는 작을수록 좋다. 이것을 새로운 시간 head의 독립 학습 8회로 해석하면 안 된다.

|---|---:|---:|---:|---:|---:|

`init_only`는 `clock_prefix`보다 초반·전체·후반이 모두 좋고, `current`의 초반 비용을 크게 줄였다. `current`가 전체 점수에서 더 낮은 것은 사실이다. `init_handoff`는 `init_only`보다 전체·중반이 낮고 초반은 높다. **여러 후보가 서로 다른 장점을 가진다.** 각 열의 최솟값만 조합한 가상의 모델을 만들지 않는다.

기존 일반 이력 head는 전체 정상 .093009 / 개인 onset .143340, 알려진 GMR은 .137295 / .116780이었다. `init_only`의 .069124 / .099303은 이 두 목표의 평균에서 둘보다 좋다. 단, 일반 이력 대비 부모별 정상 시간은 .113002→.065536과 .073016→.072711이다. 두 번째 차이는 매우 작아 우월성의 강한 증거로 보기는 어렵다. `HISTORICAL_PER_PARENT.csv`와 `HISTORICAL_PAIRED_EFFECTS.csv`에 부모/난수별 범위를 남겼다.

최신 잔차 후보는 **한 부모 × 두 생성 난수**에서 비교해야 한다. 이 조건의 `init_only` 정상/중반은 .062183/.162140, `mixture_marginal`은 .077133/.337191이다. 위 8개 평균과 직접 빼면 안 된다. 최신 후보의 고객 균등 정상 시간 .198498→.129775는 실제 장점이지만 전체 정상 시간 목표와 다른 측정량이다.

‘개인 대비’는 엄격한 과거 20개 거래의 중앙값(최소 5개)에 대한 비율이다. 평생 정상 거래 평균, 고객의 진정한 위험 성향, 특정 고객의 미래 정답을 재현했다는 뜻이 아니다. 고객 균등 W1도 고객별 W1의 산술평균과 구별한다.

## 4. 수정이 반복돼도 일관되게 좋아지지 않은 이유

**학습 목표와 주장하려는 품질이 완전히 같지 않았다.** 거래 전체 가중, 고객 균등 가중, 위치별 평균, 최악 구간, 개인 대비 관계는 서로 다른 분포를 평가한다. 초기 gain 실험은 총 목적이 일부 구간의 악화를 다른 이득으로 상쇄했다. 현재의 공동 목적도 유한 표본·근사 분위수·배치에서 계산하므로 보호 항이 있다고 자동 보존되는 것이 아니다.

**‘반복 생성 학습’의 범위를 더 명확히 말했어야 했다.** 최신 실험은 생성 gap에서 clock을 갱신했지만 ARGN 표현과 라벨/현재 조건은 실제 기록에서 가져왔다. 전체 자유 생성에서는 그 표현도 생성된 거래로 바뀐다. 최근 입력 1322차원은 static context256 + strict-past LSTM832 + 현재 사용 가능 열234다. 전부가 ‘과거 이력’은 아니다. 최신 진단은 그중832만 교체했다.

**출력 학습의 문제도 남았다.** 최신 후보는 실제 이력·실제 조건에서도 초반 오류 .108298로, `init_only` .071390보다 나빴다. 따라서 이력 분포 차이만 고치면 모든 비용이 없어진다고 할 수 없다.

**최적화 결과를 구조의 실패와 혼동하면 안 된다.** 최신 선택은 `mixture_marginal`의 likelihood 400step이며 이어진 재귀 학습 160update는 선택되지 않았다. 나머지 세 팔은0step이다. 이는 제한된 학습/선택 절차에서 개선이 없었다는 뜻이다. 새 용량이 본질적으로 무의미하다거나 모든 공동 학습이 실패한다는 뜻은 아니다. 선택되지 않은 중간 가중치는 저장되지 않아 모든 단계의 native 생성까지 소급 검증할 수는 없다.

**진단 결과와 새 모델 성능은 다르다.** 실제 이력을 넣은 최신 고정 조건 진단에서 정상 전체 .076206→.063948, 중반 .310670→.288887로 줄었지만, 개인 onset .105674→.110846과 사기 간격 .194752→.271853은 악화했다. 실제/생성 사기가 같은 위치에서 시작한 표본은0개다. 후자의 onset 평가는 집단 분포 비교이며 동일 사기 사건에 대한 예측 교정이 아니다.

**검증보다 내부 수정이 너무 오래 앞섰다.** 과거 보고서마다 충분한 CPAR, 최신 직접 비교, 독립 head 재학습을 남은 일로 기록했지만 뒤로 밀렸다. CPAR는128epoch 단일 fit이며 적정 길이·학습을 확인한 최종 비교군이 아니다. 최근 문서의 ‘128update’는 epoch와 혼용한 표현으로 이 감사에서 정정한다. 원본 기록은 변경하지 않는다. LBDTPP는 실제 학습·생성했지만 사기율58–64%의 적용 실패 상태라 강한 최신 비교군으로 간주할 수 없다.

이 문제들은 ‘잘 나온 모델을 망가뜨려 복구 불가능하다’는 뜻은 아니다. **좋은 결과를 보존한 점은 맞지만, 그 결과의 연구 가치를 검증하는 작업과 다음 개선 후보 탐색의 균형이 좋지 않았다.**

## 5. 원문을 다시 대조한 판단

## 6. 연구 진행 판단의 수정

**먼저 보존된 모델의 기여 후보를 검증한다.** `init_only`를 실험 비교 기준으로 고정하고 `current/init_handoff`를 비용 비교 후보로 유지한다. 활성 설정을 자동 교체하지 않는다. 동일한 데이터/길이·조건 정보/학습 선택 기준에서 일반 이력 출력, 단순 phase GMM, GMR 및 초기 출력·위치 보정 제거 대조를 구성한다. 전체 거래 생성기 비교(ARGN/충분히 학습한 CPAR/검증된 최신 적용)와 시간 모듈 비교를 구별한다. 이는 실패 후보가 새로 성공해야만 시작할 수 있는 일이 아니다.

**생성 이력을 반영하는 학습은 한 개의 원인 대조로 제한한다.** 같은 구조·손실·예산을 유지한다는 방향은 합리적이지만 구현 전 고정할 항목이 있다. likelihood는 실제 prefix–실제 next event 쌍에 두고, 생성 경로에는 분포 목표를 적용한다. 생성 이력/개인 clock/현재 조건의 출처와 위치·phase 지원집합을 명시한다. 실제 거래열과 생성 거래열을 단순히 같은 행 번호로 붙여 정답 학습하지 않는다. 현재 구현은 실제/생성에 같은 mask를 쓰므로 완전한 자유 조건으로 바꿀 때는 지원집합 처리를 양쪽 대조에 동일하게 바로잡아야 한다. 이것이 확정되지 않은 상태에서 ‘이력만 바꾼 동일 목적 실험’이라며 시작하면 안 된다.

시간만 생성한 이력을 쓰는 대조와 모든 필드를 자유 생성한 이력을 쓰는 대조도 다르다. 전자는 시간 피드백만 분리하지만 전체 입력 차이를 해결했다고 주장할 수 없다. 후자는 조건 구성까지 달라져 원래 대조와의 차이를 별도 통제해야 한다. **따라서 이전 다음 단계 제안은 아직 완성된 학습 프로토콜이 아니다.** 추가 보정식이나 더 큰 네트워크를 덧붙일 근거도 현재 없다.

**판정 목표를 고정한다.** 핵심 질문은 ‘사기 시작 시 개인 대비 시간 관계를 유지/개선하면서 정상 시간 분포의 왜곡을 줄이는가’다. 새 후보에 사용했던 기준은 두 핵심 지표 중 하나10% 개선, 다른 하나 절대+.01 이내, 위치 구간+.02 이내, 금액/가맹점 관계+.01 이내, 다양성5% 이내 비용이었다. 이는 탐색 진입 기준이며 통계적 유의성/논문 가능성의 정의는 아니다. 모든 지표가 완벽해야 한다는 기준도 아니다. 새 후보가 핵심 효과를 주지 못하면 후보를 종료하고 `init_only` 검증을 계속한다. 실패마다 새 보정의 개발을 자동 예약하지 않는다.

**독립 반복과 미사용 자료를 남긴다.** 기존 두 부모×네 생성 난수는 새 shared time head의 독립 반복이 아니다. 비교군과 시간 head를 독립적으로 다시 적합한 결과가 필요하다. 반복해서 본 development에서 방법을 계속 선택했으므로 현재 수치는 탐색 결과다. 설계와 비교 기준을 고정한 뒤 미개봉 평가와 두 번째 자료로 확인한다. Berka는 사기 라벨이 없으므로 정상 시간/개인 속도 일반화는 볼 수 있어도 fraud-onset 효과의 두 번째 증거가 되지는 않는다.

현재 확보한 것은 작동하는 ARGN 기반 생성기, 실제로 개선된 시간 출력 후보, 그리고 초기 속도 형성·구간 상쇄·입력 차이를 구분한 진단이다. 아직 확보하지 않은 것은 충분히 강한 최신 방법 대비 재현되는 추가 효과와 그 방법의 차별성이다. **연구를 끝낼 근거는 없지만, 새 오류를 하나씩 계속 고쳐야만 논문 단계로 갈 수 있다는 진행 방식은 바꿔야 한다.**

이번 감사 종료 시점에는 새 학습이 실행 중이지 않다. 원본 체크아웃 HEAD는 `0d620a97bd91e4cd34a246a6ca8557782c07f470`으로 유지한다. 앞으로의 진행 판단은 이 감사와 앞선 개별 실험의 비용을 함께 사용한다.
