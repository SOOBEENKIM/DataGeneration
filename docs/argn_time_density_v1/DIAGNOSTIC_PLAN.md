# 출력 효과와 반복 생성 효과의 분리 — 2026-09-27 UTC

6개 학습이 끝난 뒤, 자유 생성 전체 결과를 보기 전에 다음 해석 절차를 기록한다.
history_only/clock은 두 부모 모두100step, relative는 두 부모 모두0step이 내부
검증에서 선택됐다. 선택을 변경하지 않는다. 상대 출력의 NN 마지막층이 실제로0인지
확인한다. 그 경우 결과를 '이력 신경망 추가 학습의 개선'이라 부르지 않는다.

실제-prefix conditional.csv와 자유 생성 personal_gap.csv를 나란히 비교한다.
상대 모델이 실제 과거에서는 개인 관계를 맞춰도 반복 생성에서 전체 gap이 틀리는지
분리한다. 관측만으로 유일한 원인이라고 하지 않는다.

시간 진행 진단은 실제/생성 모두1000거래 이상인 같은 고객 집합에서 각 고객의
strict-past20 gap median의 log1p를 계산한다. 6–49번 거래의 고객별 중앙값을
평가용 초기 기준으로 삼고, [6,50),[50,200),[200,500),[500,1000) 구간별 평균
차이와 절댓값을 고객별→고객균등 평균한다. 해당 기준은 모델에 입력하지 않는다.
실제/생성 길이가 다른 전체 모집단 비교에서 생기는 고객 구성 효과를 줄이는
기술 진단이며 인과 실험이나 정상성 검정은 아니다.

현재 scalar 상대 출력의 선택값은 clock + phase별 residual mixture다. 잔차
분포가 개인 clock에 어떻게 의존하는지 보정하는 NN이0이면, 속도가 달라져도
동일 phase 잔차를 반복한다. clock과 절대 gap의 공동 보존을 자동으로 보장하지 않는다.
실제 학습 자료에서 clock과 잔차 상관관계도 계산하여 이 조건이 타당한지 점검한다.

[2026 normalization 분석 §4.2](https://arxiv.org/html/2603.11869v1)의 조건부 변화
문제는 같은 방향의 참고다. 이를 Sparkov의 원인을 입증한 논문처럼 말하지 않는다.
[RRN2026 §4.1–4.4](https://arxiv.org/html/2604.15838v1)도 확인했다. 그 논문의
graph residual transform 가역성 조건은 우리 autoregressive clock의 장기 안정성
보장이 아니다. 이름이 residual/normalization이라는 이유로 그 구조를 추가하지 않는다.
