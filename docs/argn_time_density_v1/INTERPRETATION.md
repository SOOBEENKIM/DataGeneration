# 단일 시간 출력 실험: 결과와 다음 판단

**검증한 개인 기준 재표현은 채택하지 않는다. 알려진 clock 조건부 GMR은
개인 시작 관계·전체 사기 간격을 함께 개선했지만 정상 간격의 전체 분포 비용이
남는다. 원래 onset_fit 최종 후보를 덮어쓰지 않고 GMR을 강한 비교군으로 추가한다.**

## 완료한 범위

- 고정 ARGN 부모2개에서 동일 용량 신경 시간 출력3팔, 작은 head6학습.
- 새 신경 출력24거래열/4,745,268행, 추가 GMR8거래열/1,581,756행.
- 기존 boundary/phase GMM의 새 GPU 확인8거래열/1,554,322행도 완료.
  이번 회차 총40개 새 전체 거래열/7,881,346행이다. native ARGN40학습이 아니다.
- 같은 GPU·2부모·4생성 seed의7모델, 전체56개 원본 결과를 비교했다.
  각 변경 모델의 전체 고객 길이·라벨 순서는 대응 frozen 결과와 정확히 같다.
- 독립 raw 수치 재계산, 모델/소스 hash, 실제 native 첫 gap/재정렬/축소 clock,
  정수 likelihood/극단 tail gradient와 GMR 조건부 식을 검사했다. 최종 test 미사용.

## 핵심 수치

아래는2부모×4GPU draw 평균, W1은 작을수록 좋다. 선택은 내부 검증으로만 했고
이 표는 development 결과다. 자세한 부모별 값과 사전 screen은
[전체 표](../argn_clock_regression_v1/RESULTS.md), [비용 판정](screen.csv)에 있다.

| 모델 | 개인 대비 사기 시작 gap | 전체 사기 gap | 전체 정상 gap | 정상 개인 gap |
|---|---:|---:|---:|---:|
| 고정 개선본 | .4555 | .1368 | .1259 | .0310 |
| 경계 head | .1302 | .2088 | .1250 | .0305 |
| 단순 phase GMM | .2287 | .1329 | .0743 | .0677 |
| 일반 이력 밀도 | .1433 | .1391 | .0930 | .0540 |
| 이력 + clock 입력 | .1473 | .1405 | .0944 | .0539 |
| clock 대비 상대 출력 | .1468 | 1.9004 | 2.5970 | .0285 |
| 알려진 clock 조건부 GMR | **.1168** | **.0998** | .1373 | **.0123** |

일반 밀도만으로도 기존 경계 head의 전체 사기 gap 비용은 상당히 줄어든다.
clock을 명시적으로 추가한 것의 추가 이득은 확인되지 않았다. 상대 출력도 일반
밀도보다 onset 개인 관계가 좋아지지 않았고 전체 시간 분포를 크게 악화시켰다.
일반 두 팔은 한 부모에서 정상 개인 관계/정상 주변 gap 비용 screen을 실패했다.
따라서 평균 하나만 보고 두 부모에서 모두 개선됐다고 하지 않는다.

GMR은 두 부모 각각에서도 단순 phase GMM과 일반 신경 밀도보다 onset 개인
관계가 좋았다. 전체 사기 gap, 정상 개인 gap도 개선했다. 개인 대비 사기 금액은
frozen .1141→.1046, 정상 금액 .0630→.0618, merchant 다양성537.875→538.250으로
기존 개선을 대체로 유지했다. 사기율/고객 구성은 고정 label열이므로 바뀌지 않는다.
그러나 phase GMM 대비 정상 gap .0743→.1373은 허용 증가 .03을 **두 부모 모두**
넘는다. 사기 onset의 절대 gap도 .3141→.5140으로 나빠졌다. 개인 대비 onset
관계의 개선을 모든 onset 시간 품질의 개선이라고 하지 않는다.

## 실패 원인을 어디까지 분리했는가

상대 head는 등록된100step 간격 후보 중 두 부모 모두0step을 선택했다.
마지막 NN층이 실제로0이므로 선택된 출력은 clock + 전환별 잔차 분포다.
성공해도 신경망 추가 학습의 효과라고 부를 수 없는 상태였다.

실제 prefix에서는 상대 모델의 정상 gap W1 .0916/정상 개인 gap .0100이었다.
반복 자유 생성에서 전체 정상 gap은2.5970으로 악화했다. 개인 관계만 맞아도
개인의 기준 속도 자체가 잘못 변하면 전체 시간 분포는 맞지 않는다.

이를 더 분리하기 위해105고객의 같은 실제25prefix·다음500개의 같은 실제label·
같은 난수를 고정하고 **clock의 입력 출처만** 바꿨다. 상대 모델의 전체 gap W1은
actual-clock .0941→recursive-clock1.0615로 악화했다. GMR은 .0822→.2883이었다.
이 조건부 실험 내에서는 생성 gap을 다시 clock에 넣는 과정이 차이를 만들었다.
이는 full free-generation 점수나 ARGN 전체의 유일한 원인이라는 주장이 아니다.
[조건부 개입 설계](CLOCK_INTERVENTION_PROTOCOL.md), [수치](clock_intervention/means.csv).

같은 실제/생성 장기 고객 집합의 기술 진단에서도 상대 모델은 초반 대비
500–999번 거래의 평균 log-clock 변화가−2.354였고 실제는−.422였다. GMR은
거의0으로 안정적이지만 실제 초반의 느린 거래 속도/이후 변화까지 재현한 것은
아니다. 초반6–49거래 gap 중앙값은 실제 약25675초/GMR15399초였고,
500–999거래에서는 실제15958초/GMR15222초였다. 이것은 남은 정상 시간 비용을
초기 수준과 진행 중 변화로 나눠 진단할 구체적인 단서이며 인과 원인 확정은 아니다.

## 선행 대비 결론과 바로 다음 단계

history/mark 조건부 mixture, 고객 통계로 정규화한 뒤 복원하는 발상,
Gaussian-mixture regression 모두 선행이다. 이번 GMR 효과는 **강한 비교군 확보와
원인 분리**이지 새 모델 기여의 입증이 아니다. 최신 LBDTPP 등 전체 생성기와의
동일 과제 직접 재학습, 다른 dataset, 독립 학습 반복/최종 test 검증도 아직 남는다.

다음에 바꿀 대상은 시간 출력 하나를 유지한다. 큰 공유 상태나 diffusion을
덧붙이기 전에 **개인 기준 속도가 반복 생성 중 어떻게 변하는지**까지 맞춰야 한다.

1. frozen/phase GMM/일반 이력 밀도/clock GMR을 함께 고정한다. GMR이 얻은
   개인 시작·사기 gap·정상 개인 gap 개선이 다음의 보존 대상이다.
2. 남은 정상 gap 비용을 초기 거래와 진행 구간으로 나누고 실제 clock 제공과
   생성 clock 제공을 대조한다. 위 개입/진행 진단이 이 분리의 첫 결과다.
3. 실제 clock에서도 남는 출력 오차와 반복 clock 갱신 오차를 구분한 뒤,
   개인 속도 수준과 변화를 함께 보존하도록 단일 조건부 출력을 개발한다.
   간단한 진행 시점 조건이나 낮은 차원 보정으로 해결되면 그 방법을 다시
   강한 대조로 삼는다. 그런 효과를 새로운 복잡한 구조의 기여로 포장하지 않는다.
4. 추가 효과가 있는 경우에만 제거 대조·독립 반복·최신 동일 과제 비교로 확장한다.

새 기여 후보는 '개인 기준을 넣었다'가 아니라 **개인 기준으로는 맞지만 반복
생성에서 전체 시간 분포가 변하는 문제를, 두 관계를 함께 학습해 줄이는 방법**이다.
그 방법의 신규성과 우월성은 이번 결과로 확정되지 않았다.
