## 다음 모델의 범위와 구별 대조

다음 구현 후보는 **고객의 직전 거래 속도 대비 변화로 시간 분포를 학습하는
단일 조건부 출력**이다. 현재 ARGN의 고객·사기 구성/금액 모듈을 고정한다.
여러 전문가를 덧붙이거나 diffusion·공유 상태를 동시에 붙이지 않는다.

1. 먼저 전환 조건만의 GMM(완료), 같은 ARGN 이력을 입력하는 일반 조건부
   lognormal mixture, 개인 기준으로 재표현한 동일 용량 출력의 순서로 비교한다.
2. 개인 기준은 현재 거래를 제외한 과거에서만 계산한다. 학습은 실제 과거,
   자유 생성은 생성 과거로 계산한다. 짧은 이력의 결측·0간격은 학습 자료에
   근거한 fallback으로 처리하며 실제 고객 미래 median/길이는 쓰지 않는다.
3. 개인 기준 제거 대조와 같은 용량·샘플링·학습 예산을 사용한다. 일반 조건부
   LNM으로 같은 효과가 나면 ‘개인 기준 재표현의 추가 기여’ 가설을 버린다.
4. 개발 기준은 단순 GMM의 경계/전체 시간 분포 개선과 이력 모델의 개인 대비
   간격 보존을 동시에 얻는 것이다. 사기/정상 금액·라벨 구성·merchant 다양성의
   기존 개선도 함께 보고한다. 상대 후보 하나의 약점만 골라 주장하지 않는다.

현재는 이 출력 형태의 **후보와 구별 실험**을 정한 단계다. 구현·학습·효과와
신규성은 아직 미확정이다. 추가 seed 확인과 최신 동일 과제 대조 결과에 따라
다음 프로토콜을 확정한다. 참고 논문을 읽었다는 이유만으로 답이 보장되지는 않는다.

MoTPP의0간격 처리를 검토한 뒤 실제 학습 지지 범위도 점검했다.
[time_support_audit.csv](time_support_audit.csv)에서 optimization의 후속
정상 거래810,543건 중0간격은10건이며, 시작433/복귀431/사기 지속4,257건에는
없다. 따라서0간격은 보존할 데이터 조건이지만 이번 경계 오류의 주원인이라는
근거는 없다. 원문을 읽었다고 zero-inflation head를 자동으로 추가하지 않는다.
