# 전환 경계의 시간 분포와 개인 거래 속도 — 2026-09-27

**현재 결정:** 기존 onset_fit 최종 후보는 그대로 보존한다. 새로운 경계 head와
단순 phase GMM을 추가 대조로 보존한다. 다음 개발 범위는 고객의 과거 거래
속도를 반영하는 **단일 시간 출력**으로 좁힌다. 큰 공유 상태 구조의 필요성이
확인됐다고 주장하지 않는다.

## 실제로 확인한 문제

고정 최종 후보에 실제 과거·현재 label/category를 제공해도 사기 시작과 정상
복귀 gap log-W1은 각각1.221,1.383이었다. 실제 시작 gap 중앙값57,328초에
대해19,253초, 복귀41,621초에 대해11,670초가 나왔다. 따라서 자유 생성의
누적 오차만으로 설명되지 않는다. 개발 시작102건/102고객, 복귀101건/101고객의
작은 조건이므로 전체 ARGN·모든 데이터의 구조적 불가능성으로 일반화하지 않는다.
[전체 prefix 진단](../argn_residual_v1/INTERPRETATION.md).

시간 출력만 바꾸었으며 실제 거래의 라벨을 생성 결과에 붙인 것이 아니다.

## 왜 전체 사기 간격만 보면 판단이 달랐는가

고정 후보는 시작 간격을 너무 짧게, 지속/처음부터 사기인 거래의 간격을 너무
길게 생성했다. 실제 phase 비중으로 표준화한 CDF를 정확히 적분하면 다음과 같다.

| 모형 | 실제 비중 가중 조건부 W1 합 | 표준화한 전체 W1 | 반대 방향 CDF 오차의 상쇄량 |
|---|---:|---:|---:|
| 고정 후보 |0.4192|0.1620|0.2572|
| 경계 head |0.3427|0.2632|0.0795|
| 전환 GMM |0.2119|0.1452|0.0667|

조건별 오차 합이 줄어도 기존의 상쇄가 사라져 전체 W1이 커질 수 있다. 이 표는
**W1의 가산 분해가 아니다.** 동일 실제 phase 비중에서 조건 CDF 차의 절댓값을
먼저 합한 값과 CDF 차를 먼저 합한 값의 차이를 적분했다.64회 SciPy 독립
계산과 일치했다. 실제 비중과 생성 비중 차이는 별도이며, 인과적 rollout 개입의
증거로 해석하지 않는다. 계산은 [cdf_cancellation.csv](cdf_cancellation.csv),
[phase 방향과 지지 수](cdf_phase_contributions.csv)에 있다.

## 채택·기각한 해석

- 경계 head는 전체 사기 gap 비용으로 사전 screen에 실패했다. 최종 후보로
  승격하지 않는다. 다만 개인 대비 시작·복귀 gap에서 단순 GMM보다 우수한
  관측이 있어 이력 조건부 출력의 구별 대조로 보존한다.
- GMM은 사전 screen을 두 부모 모두 통과했다. 그러나 screen 이후 추가
  진단에서 정상 개인 gap 관계 비용이 확인됐다. ‘모든 관계 보존 성공’으로
  말하지 않고 강한 단순 비교군으로 채택한다. 이 알려진 분포를 새 구조라고
  하지 않는다.
- GMM clipping은 총26/1,151,367 내부 sampling positions였다. 내부 sampling은
  나중에 제거되는 padding 위치도 포함하므로 최종 거래행 수와 같지 않다.
- 현재 결과로 ‘최신 모델보다 우수하다’ 또는 ‘논문 기여가 확정됐다’고 하지
  않는다. 그 대신 **전체 시간 분포와 개인의 시간 변화가 함께 맞는가**라는
  구체적인 비교 질문과 효과의 위치가 확보됐다.

## 추가 확인 완료와 목표의 최종 축소

CPU에서도 기준4회와 두 시간 후보8회를 모두 새로 생성했다. 총12회
2,279,190행이며 이번 회차 GPU/CPU 전체는24회4,692,975행이다.
CPU 안에서 비교했을 때 경계 평균 W1은 기준1.4157, 경계 head0.3091,
GMM0.2481이다. 개인 대비 onset gap은0.4826/0.1139/0.2421로 **시작
거래에서 이력 모형이 단순 GMM보다 낫다는 방향이 반복됐다**.

복귀의 개인 gap은 경계 head0.1604, GMM0.1365여서 초기의 우위가 반복되지
않았다. ‘모든 경계에서 이력 모형이 더 좋다’는 주장을 채택하지 않는다.
GMM의 정상 개인 gap 비용은0.0291→0.0667로 다시 확인됐다. 사기 금액 관계는
0.1054→0.0942이고 전체 사기 gap은0.1380→0.1332였다. 경계 head는 전체
사기 gap0.2321로 다시 사전 비용 screen을 실패했다. GMM은 두 부모에서 통과했지만
정상 개인 관계의 비용 때문에 최종 모델 승격 대신 강한 대조로 보존한다.

다음 제안의 중심 질문은 **‘사기 시작 시 개인 거래 속도의 변화와 전체 시간
분포를 함께 보존할 수 있는가’**다. 정상 복귀의 우위를 함께 주장하지 않는다.
