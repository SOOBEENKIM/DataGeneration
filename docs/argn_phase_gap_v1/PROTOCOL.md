# 강한 단순 대조: 전환 조건부 시간 분포 — 2026-09-27

경계 gap 전문가의 자유 생성에서 경계 평균 W1은1.461→0.320으로 좋아졌으나
전체 사기 gap은0.151→0.249로 악화하여 사전 screen을 통과하지 못했다.
전문가를 더 추가하기 전에, **한 개의 조건부 시간 분포 모듈**로 gap 전체를
바꾸는 단순 대조를 실행한다. 현재 최종 개선 기준은 여전히 onset_fit이다.

정상→정상/정상→사기/사기→정상/사기→사기의 네 조건 각각에 log1p(gap)
Gaussian mixture를 적합한다. 각각 K=1,2,3, optimization만 학습하고
internal-validation NLL로 K를 선택한다. 큰 셀은 고정 seed20261115로 최대
50,000개 optimization 행을 균일 추출한다. 20행 미만 조건은 K=1만 허용한다.
고객 history/context/category/금액을 쓰지 않는 가장 단순한 비교다.

[CIKM2022 §3.2의 mark 조건부 LNM](https://arxiv.org/html/2210.15294v2)이 직접
방법 근거다. 이번 mark는 (직전label,현재label) 조합이며 원래 신경 TPP의 재현은
아니다. [LBDTPP2026 §V-A](https://arxiv.org/html/2606.24982v1)도 LNM을
기본 시간 생성 비교로 둔다. 최신 복잡한 생성기와 비교하기 전에 이 단순한
설명으로 충분한지를 먼저 분리한다.

두 부모×생성 seed20261011/12 = 4개의 전체 거래열. 기존 최종 모델의 label,
길이,category/merchant,amount 학습 가중치는 고정한다. 첫 거래 gap은 원래대로
생성하고 평가에서 제외한다. 이후 gap을 네 분포에서 샘플링하여 원래 digit
codec으로 입력한다. codec 보호 범위 clipping을 기록한다. 별도 RNG를 사용해
native 라벨/길이 RNG를 바꾸지 않는다. 실제 자유 생성의 label열/길이 완전일치를
검증한다. gap 변경에 따른 후속 금액/merchant/이력 영향은 측정한다.

원래 frozen, 동일용량 전체학습, 경계전문가, 이 단순한 전체 gap 모듈을 함께
비교한다. 기존 screen 수치를 그대로 적용하며 소급 변경하지 않는다. 개인의
과거 간격 대비 현재 간격을 추가 보고하되, 원래 금액 관계·정상 품질을 대체하지
않는다. 단순 모형이 이기면 그것을 강한 비교군으로 채택하고, 신경망 복잡성의
기여를 보류한다. 이 통계 대조를 새로운 구조/최신 모델 대비 우위라고 하지 않는다.
