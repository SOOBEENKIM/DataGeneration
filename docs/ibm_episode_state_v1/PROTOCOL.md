# ibm_episode_state_v1 — 사기 묶음(에피소드) 상태 과정 (등록 2026-11-11, 실행 전)

사용자 지시(2026-11-11): "사기 묶음부터". 근거 [진단 D1](../ibm_gap_diag_v1/RESULTS.md), 선행 대조 [PRIOR_WORK](../ibm_design_v2/PRIOR_WORK.md)(상태 모형 자체는 표준 준마르코프 — **새로움 주장 없음**), 평가 틀
[ibm_eval_frame_v2](../ibm_eval_frame_v2/PROTOCOL.md). 개발은 **2013 train·dev만** 쓴다. 2013 test와 확인 연도 test는 읽지 않는다. backbone·출력층·다른 부품은 그대로 두고 **라벨 과정의 표만** 바꾼다.

## 1. 무엇을 바꾸는가

현재 표: P(사기 | 이전 라벨, 이전 구간 나이 1–21, 이전에 사기가 있었는가). 문제: "이전 사기 있음"이 영구 상태이고 21사건 이후가 한 칸이라 자유 생성에서 두 번째·세 번째 묶음이 생긴다(사기 1.33–1.6배, 고객당 최대 133건).

후보(모두 train에서만 추정, Jeffreys 평활 0.5; 복잡도 순):

| 후보 | 사기 없던 고객의 진입 위험률 | 사기 뒤 정상 행의 재진입 위험률 | 구간 지속 |
|---|---|---|---|
| `A0` (현재, 기준) | 정상 구간 나이별(1–20은 바닥값) | 정상 구간 나이 1–21(21 이상 한 칸) | 구간 나이 1–21 |
| `A1` 거리 확장 | 상수 하나 | **마지막 사기 이후 사건 수**: 1, 2, 3, 4, 5, 6–10, 11–20, 21–50, 51–100, 101–200, 201 이상 | A0과 같음 |
| `A2` + 달력 | **달력 구간별**(직전 사건까지의 누적 시간, 30.44일 단위 12칸) | A1과 같음 | A0과 같음 |
| `A4` + 누적 건수 | A2와 같음 | 거리 × **지금까지의 사기 건수**(1–3, 4–6, 7–10, 11–15, 16 이상) | 구간 나이 × 같은 건수 구간 |

"마지막 사기 이후 사건 수"는 현재 표의 정상 구간 나이와 같은 양이며 상한만 21에서 201 이상으로 늘린 것이다. 묶음의 종료는 먼 거리 칸의 낮은 위험률로 표현된다(따로 흡수 상태를 두지 않는다).
달력 구간은 생성 시 모델이 낸 간격의 누적으로 계산한다(창이 1월 1일에 시작하므로 누적 시간 ≈ 달력 위치).

내부 선행과의 차이: `ibm_state_first_v1` M1은 같은 정보를 **학습 분류기**로 넣었다가 자유 생성에서 악화돼 기각됐다. 이번에는 표이고, **생성 전에 자유 모의로 거른다**.

## 2. 1단계 — CPU 자유 모의 (`scripts/sim_episode_state.py`; GPU·생성 없음)

각 후보로 train 고객의 실제 길이·실제 시간 경로 위에서 라벨 사슬을 자유 모의(200회)하고 실제 train과 비교한다.

- **통과 기준(train, 모의 평균; 모두 충족):**
  - 사기 건수 1,303 ± 10%, 구간 수 490 ± 10%, 사기 고객 수 116 ± 10%.
  - 고객당 사기 수의 25 / 50 / 75 / 90% 분위가 실제(7 / 11 / 14 / 19)의 ± 3 안.
  - 사기 고객 중 27건(실제 최대)을 넘는 비율 ≤ 5%.
  - 첫 사기의 상대 위치 중앙값이 실제(.73)의 ± .10 안.
  - 사기 고객당 묶음 수(50사건 넘게 떨어진 재진입을 새 묶음으로 셈)가 실제의 ± .15 안.
- **선택 규칙:** A1 → A2 → A4 순으로 **처음 통과하는** 후보를 택한다(dev는 선택에 쓰지 않는다). 아무것도 통과하지 못하면 GPU 생성 없이 끝내고 실패로 기록한다.
- **dev 확인(선택 뒤, 형태만):** 택한 후보로 dev 고객의 길이·시간 경로를 모의해 **사기 고객 조건부** 통계(고객당 사기 수 분위, 묶음 수, 첫 사기 위치)를 dev 실제와 비교한다. 수준(건수·고객 수)은 판정하지 않고 보고만 한다 —
  분할마다 사기 고객 비율이 크게 다르기 때문이다(train 11.6%, dev 16.3%, 개봉한 2013 test 7.9%). 대신 train의 240명 부분표본 200개가 주는 범위를 함께 적는다.

## 3. 2단계 — 생성 (1단계 통과 시에만; `benchmarks/argn_episode_state.py`)

채택 모델(`visitrate` 스택)의 전이표만 택한 후보로 바꿔 dev 문맥으로 4 생성(fit 2 × seed 2). 새 학습 0. 비교 대상은 같은 fit·seed의 채택 모델 dev 생성물.

- **E1 (대상 구조).** 생성 사기율이 **train 사기율 .00116의 ± 15%** 안(현재 .00193), 240명당 사기 고객 수가 train 부분표본 95% 범위 안, 고객당 최대 사기 수 ≤ 54(실제 최대의 2배; 현재 74–83).
  dev 사기율(.00181)은 train보다 높으므로 dev 기준 사기율 배수는 나빠질 수 있다 — 그 수치는 보고만 하고 판정하지 않는다.
- **E2 (위치).** 사기 행의 상대 위치 평균이 train(.73)의 ± .10 안(현재 .53).
- **E3 (구간 구조 유지).** 지속률·구간 길이·구간 내 간격이 dev 바닥의 3배 안.
- **E4 (효용 비열화).** 등록 탐지기 효용 ≥ 채택 모델 − .03(= .461).
- **E5 (나머지 유지).** 사기율·진입률 외의 표준 지표와 가맹점 구조가 채택 모델 대비 +.3배 넘게 나빠지지 않음.
- E1–E5를 모두 충족하면 v2의 라벨 과정으로 채택한다. 일부만 충족하면 그대로 기록하고 채택하지 않는다.

## 4. 한계(미리 적음)

- 표는 train의 사기 고객 116명·구간 490개에서 추정한다. 칸이 많은 A4는 과적합 위험이 커서 순서상 마지막이다.
- 달력 구간별 진입률은 "그 해의 사기 물결"을 그대로 담는다. 같은 해의 다른 고객에게는 타당하나 다른 해로 옮겨지는 구조는 아니다(확인 연도에서는 그 해 train으로 다시 추정).
- 누가 사기를 당하는가(고객 수준 위험)는 이 단계의 대상이 아니다.
- dev는 이미 여러 번 썼다. 여기의 dev 수치는 탐색용이며 확인은 봉인된 연도에서 한다.

## 수정안 1 (2026-11-11, 1단계 첫 모의 결과를 본 뒤 · 실행 전 등록)

**첫 모의 결과(그대로 기록, `SIM.json`): 등록한 규칙으로는 세 후보 모두 탈락 → GPU 생성 없음.**

| | 실제 train | `A0`(현재) | `A1` | `A2` | `A4` |
|---|---:|---:|---:|---:|---:|
| 사기 건수 | 1,303 | 1,715 | 1,351 | 1,392 | **1,444** (+10.8%, 탈락) |
| 구간 수 | 490 | 649 | 511 | 527 | **555** (+13.4%, 탈락) |
| 사기 고객 수 | 116 | 120 | 111 | 120 | 119 |
| 고객당 사기 수 25 / 50 / 75 / 90% | 7 / 11 / 14 / 19 | 5 / 10 / 20 / 32 | **4 / 9 / 17 / 27** (탈락) | **4 / 8 / 16 / 26** (탈락) | 7 / 11 / 15 / 20 |
| 27건 초과 비율 | 0 | .138 | **.100** (탈락) | **.087** (탈락) | .027 |
| 첫 사기 상대 위치(중앙값) | .735 | .448 | **.485** (탈락) | .739 | .737 |
| 사기 고객당 묶음 수 | 1.05 | 1.38 | 1.11 | 1.08 | 1.14 |

- 거리 확장(`A1`)만으로 건수 초과는 +32% → +4%로 줄고, 달력(`A2`)으로 위치가 맞는다. 그러나 고객당 사기 수가 실제보다 넓게 퍼진다(실제는 7–19건으로 좁다 — 묶음에 "크기 한도"가 있다).
- 누적 건수(`A4`)는 분포를 맞추지만 건수·구간 수가 10% 기준을 근소하게 넘는다. `A4`의 172칸 중 92칸이 20사건 미만, 63칸이 0사건이다. Jeffreys 평활은 표본이 적은 칸을 .5 쪽으로 끌어당기므로(예: 4사건 중 3건 → .70),
  실제에서는 드물지만 자유 생성에서 도달하는 상태의 위험률이 부풀려진다. 교사 강제 기대도 1,325.5건으로 +22건이다.
- 표에서 읽히는 구조: 누적 건수가 늘수록 재진입 위험률이 떨어진다(거리 5에서 .149 → .043, 거리 21–50에서 .013 → .003). 실제 묶음은 건수가 쌓이면 끝난다.

**수정안의 후보 `A5` = `A4` + 계층 수축.** 누적 건수로 나눈 칸의 추정을 .5가 아니라 **같은 거리(또는 같은 구간 나이)의 건수 통합 추정** 쪽으로 수축한다: (k + m·p_통합) / (n + m). 통합 추정은 `A2`의 칸(Jeffreys)이다.
희소한 집단을 상위 집단으로 묶는 계층 수축은 표준 기법이며(2509.18414도 같은 목적의 계층 풀링을 쓴다) 새로움 주장은 없다.

- **m의 선택(모의 기준과 독립):** m ∈ {2, 5, 10, 20, 50}에서 train 고객 5겹 교차검증의 라벨 로그 우도가 가장 높은 값. 모의 통계를 보고 고르지 않는다.
- **판정:** §2의 통과 기준을 **그대로** 적용한다(수치 변경 없음). `A5`가 통과하면 §3의 생성 단계로 간다. 통과하지 못하면 이 단계는 실패로 끝내고, 묶음 크기를 명시적으로 뽑는 설계(명시적 지속 준마르코프)는 별도 등록으로만 한다.
- 한계: 첫 모의 결과를 본 뒤의 수정이므로 train 모의 기준에 대한 사후 적합 위험이 있다. 그래서 m은 우도로 고르고, 통과 기준은 바꾸지 않으며, 확인은 봉인된 연도에서 한다.
- 기록: `A4` 표의 "거리 1" 칸은 정의상 비어 있다(직전 행이 사기이면 지속 표가 쓰인다). 재진입 표의 실제 첫 칸은 거리 2다. 진단 문서의 "1–5사건" 표기는 2–5사건에 해당한다.
