# 고정 제거 실험의 해석 범위

프로토콜과 실행 조건을 바꾸지 않는 구현 설명이다.

초기 분포 대체 I와 위치 보정 C는 정상 유지 상태의 시간 출력에만 직접 적용된다. 사기 시작·지속·복귀의 출력 법칙은 같은 입력에서 그대로다. 하지만 자유 생성에서는 앞서 생성한 시간이 바뀌면 뒤의 ARGN 이력 표현과 현재 조건도 달라질 수 있다. 따라서 사기 시작 시점의 생성 시간까지 간접적으로 달라질 수 있다.

또한 개인 대비 간격 지표는 현재 간격을 자체 생성한 strict-past 중앙값으로 나눈다. 앞선 정상 거래시간이 달라지면 이 분모도 바뀐다. 사기 시작 개인 지표가 좋아졌다고 해서 사기 출력의 가중치가 개선됐거나, 이력 표현 한 가지가 유일한 원인이라고 결론 낼 수 없다. 이번에는 등록한 구성 요소의 총 생성 효과를 비교한다.

`전체 정상 시간`과 `정상 유지의 개인 대비 시간`은 별개다. 예를 들어 평소 거래간격이 각각 1시간과 12시간인 두 고객에게 다음 간격을 12시간과 1시간으로 바꾸어 배정하면, 전체 간격 목록은 같아도 개인 속도와의 관계는 달라진다. 실제 평가는 모든 거래열의 분포에 대해 수행하며, 이 예시는 지표 차이를 설명하기 위한 것이다.

오차 척도에서 두 처리의 상호작용을 계산하더라도, W1의 비선형성과 생성 이력의 변화가 함께 들어간다. 음의 상호작용만으로 새로운 구조적 시너지나 안정성 정리를 주장하지 않는다. 고정된 처리의 제거 효과와, 제거 후 다시 최적화했을 때의 최고 성능도 구별한다. 이번에는 새 적합 없이 전자만 확인한다.
