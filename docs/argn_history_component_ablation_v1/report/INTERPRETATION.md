# 이력 모델의 초기 처리·보정 분리 검증 결과

2026-09-30 23:22 KST 평가 완료. 사전에 고정한 `PROTOCOL.md`의 네 조합을 모두 비교했다. **이 이력 모델의 두 주요 지표 개선은 대부분 보정만으로 설명된다. 초기 처리를 추가해야만 그 개선을 얻는다는 주장은 지지되지 않았다.** 초기 처리는 초반 구간에서 작은 추가 이득이 있지만, 주 지표의 일관된 추가 개선은 아니다.

## 무엇을 실행했는가

직전 연구의 시간 학습 시드 3개 × 고정 ARGN 부모 2개를 그대로 사용했다. 각 조건에서 생성 시드 2개를 대응시켰다. 새 신경망·혼합분포·보정·ARGN 학습은 **0회**다. 같은 이력 모델의 초기 처리 또는 보정만 꺼서 이미 학습된 구성 요소의 효과를 분리했다. 제거 후 다시 학습한 모델들의 최적 성능을 비교한 실험은 아니다.

- 초기 처리만: 새 전체 거래열 생성 12회.
- 보정만: 새 전체 거래열 생성 12회.
- 둘 다 없음·둘 다 적용·기존 GMR 기반 `init_only`: 기존 출력 36개 재사용.
- 새 생성 24회 / 4,827,570행, 총 평가 60개 출력 / 12,068,925행.

GPU 작업 12개가 모두 정상 종료했고 평가도 끝났다. 독립 평가의 기존·실행 지표 대조 768개 최대 차이는 `9.71e-17`이었다. 이전 파일 해시 529개, 출력 60개의 라벨·길이 대응, 새 작업 12개의 네이티브 생성 경로 검증을 통과했다. 기존 개발 자료를 재사용했으며 봉인한 테스트는 읽지 않았다. 24회 생성은 24회 독립 재학습이 아니다.

## 같은 조건의 결과

아래는 기존 시간 학습 3개 × 부모 2개 × 생성 시드 2개의 평균이다. 모두 오차이며 작을수록 좋다. `정상 개인`은 정상 유지 상태에서 개인의 과거 속도 대비 간격 관계다. `사기 시작 개인`과 서로 다른 지표다.

|---|---:|---:|---:|---:|---:|---:|
| 없음 H | 0.123082 | 0.099052 | 0.033969 | 0.316533 | 0.182406 | 0.082123 |
| 초기만 I | 0.122188 | 0.100582 | 0.033640 | 0.310201 | 0.182520 | 0.081822 |
| 보정만 C | 0.052605 | 0.079223 | 0.036049 | 0.105010 | 0.089122 | 0.077265 |
| 초기+보정 IC | 0.052395 | 0.080343 | 0.035996 | 0.097851 | 0.088986 | 0.077573 |
| 별도 기준: GMR 기반 init_only | 0.063958 | 0.120572 | 0.006468 | 0.084596 | 0.099827 | 0.074017 |

시드별·부모별 수치와 모든 부가지표는 `FIT_MEANS.csv`, `PARENT_FIT_MEANS.csv`, `ALL_DRAWS.csv`, `PAIRED_EFFECTS.csv`에 있다. 도표 `FACTORIAL_COMPARISON.png`/`.pdf`의 괄호는 기존 시간 학습 3개 평균의 최솟값–최댓값이며 신뢰구간이 아니다. 과거 다른 생성 시드에서 계산한 8회 평균과 혼합하지 않는다.

## 어떤 요소가 효과를 냈는가

**보정의 주 효과가 반복됐다.** H→C에서 전체 정상 시간은 0.123082→0.052605로, 사기 시작 개인 관계는 0.099052→0.079223으로 개선됐다. 두 지표 모두 시간 학습 3개의 평균에서 개선됐다. 대응 생성 12개에서는 각각 12개, 9개에서 개선됐다. 초반 시간도 0.316533→0.105010으로 12개 모두 개선됐다. 다만 부모×시간 학습 6개 단위에서 사기 시작 개선은 4개이며, 모든 조건에서 좋아졌다는 뜻은 아니다.

**초기 처리의 추가 효과는 작고 지표마다 다르다.** C→IC에서 전체 정상 시간은 0.052605→0.052395로 거의 같았다. 시간 학습 평균 3개 중 1개, 대응 생성 12개 중 5개에서만 더 낮았다. 사기 시작 개인 오차는 0.079223→0.080343으로 조금 악화했고, 시간 학습 평균 3개 모두 같은 방향이었다. 초반 시간은 0.105010→0.097851로 낮아졌지만, 시간 학습 평균 3개 중 2개·생성 12개 중 9개에서 개선된 제한된 효과다. 초기만 적용한 I 역시 H보다 주 지표가 확실히 좋아졌다고 보기 어렵다.

따라서 등록한 주 지표 기준으로 IC는 H와 I에 비해 개선되지만, C 대비 추가 효과 기준을 충족하지 않는다. `초기+보정이 반드시 함께 필요하다`거나 새로운 구조적 시너지가 입증됐다고 주장하지 않는다. W1의 비선형성, 초기 다섯 간격에서의 분포 대체, 재귀 생성 효과가 함께 있으므로 오차의 2×2 상호작용을 이론적 보장으로 해석할 수도 없다.

## 비용과 해석 범위

정상 개인 관계의 비용은 남았다. H→C에서 0.033969→0.036049로 악화했으며 시간 학습 평균 3개 모두 같은 방향이다. 그러나 GMR 기반 `init_only`의 0.006468과 차이가 컸던 것은 이미 H의 0.033969부터다. 이번 보정이 그 차이 전체를 만들었다고 설명하면 틀리다. 정상 개인 관계는 사전에 정한 보조지표로 유지하고, 결과를 본 뒤 이를 새 주 지표로 바꾸지 않는다.

C와 IC는 `init_only`보다 두 주요 지표의 평균이 낮지만, 초반 오차는 각각 0.105010/0.097851로 기준 0.084596보다 높다. 등록한 위치별 허용 차이 +0.02에서 C는 초반 비용으로 판정되고 IC는 이 평균 기준을 통과한다. 이 경계 통과가 결합 구조의 필요성이나 신규성을 증명하지 않는다.

후반 평균만 보면 비용이 작아 보이지만 부모에 따라 다르다. 부모 20260930에서 `init_only` 후반은 0.069061, C는 0.104506, IC는 0.104726이다. 부모 20261001에서는 각각 0.078972, 0.050024, 0.050420으로 반대 방향이다. H의 첫 부모 후반도 이미 0.104541이므로 초기 처리만의 문제로 돌리지 않는다.

금액도 함께 봤다. C→IC에서 개인 대비 사기 금액 오차는 0.099157→0.105156, 정상 금액 오차는 0.063400→0.064108로 조금 악화했고 시간 학습 평균 3개 모두 같은 방향이었다. 가맹점·다양성의 전체 표도 저장했다. 시간만 낮춰 나머지가 모두 유지됐다고 주장하지 않는다.

초기 처리와 보정이 직접 바꾸는 것은 정상 유지 상태의 시간 법칙이다. 사기 시작 관계의 변화에는 앞선 생성 시간, ARGN 표현, 개인 속도 분모의 변화가 함께 들어갈 수 있다. 사기 전환이나 사기 출력 가중치를 새로 학습한 실험이 아니다. 자세한 설명은 `SCOPE_NOTES.md`에 있다.

## 보존 결정과 다음 순서

활성 `clock_prefix`와 GMR 기반 `init_only`, 이력 모델의 네 조합을 모두 보존한다. 자동 교체·commit·push를 하지 않았다. 이제 C를 간단하고 강한 비교 후보로 포함하고, IC는 초반 이득을 가진 대안으로 함께 보존한다. 하나가 모든 지표에서 우세하다고 선택하지 않는다.

다음 비교를 또 다른 보정식의 성공에 종속시키지 않는다. 다음 우선순위는 보존한 후보들과 **충분한 학습량·공통 고객/길이/조건을 맞춘 CPAR 및 적용 가능한 최신 전체 생성기 비교**를 구체화하는 것이다. 해당 새 비교 학습은 이번에 실행하지 않았다. 예전 CPAR 128 epochs 및 문제가 남은 LBDTPP 적용 결과만으로 최신 모델보다 우수하다고 결론 내릴 수 없다. 기존 개발 자료를 반복 사용한 이번 결과를 독립 테스트 확인으로 표현하지 않는다.

이번 검증으로 제거된 것은 `두 요소의 결합 자체가 핵심 기여`라는 주장이다. 연구 전체를 부정하는 결과가 아니다. 알려진 보정 효과를 인정한 상태에서 어떤 조건부 관계에 추가 이득이 있는지 강한 비교군으로 판단해야 한다. 모든 한계가 없어야만 논문이 된다는 기준도 적용하지 않는다.

이번 프로토콜에서 다시 확인한 선행 범위는 [MoTPP 2026 §4.2](https://arxiv.org/html/2609.21382v1)의 조건부 시간 출력과 [Seq2Synth 2026 §3](https://arxiv.org/html/2607.15606v3)의 평가 구분이다. 알려진 이력 조건부 혼합분포·평가 개념을 근거로 삼았으며, 두 논문 전체 모델을 이번에 재현했거나 신규성을 인정받았다는 의미는 아니다.
